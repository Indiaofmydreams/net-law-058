About this question set

This set has 19 multiple-choice questions on Online Databases and Repositories from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.
