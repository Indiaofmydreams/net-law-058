About this question set

This set has 25 multiple-choice questions on Experimental Method from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

25 practice questions with answers

1Which combination defines a true experimental design?

  1. Observation, interview and survey
  2. Manipulation of the independent variable, control and random assignment
  3. Document analysis only
  4. Case history only
Show answer

Answer: B. Manipulation of the independent variable, control and random assignment

Report this question

2Experimental research is best suited to:

  1. Describing opinions
  2. Tracing past events
  3. Interpreting meanings
  4. Establishing cause-effect relationships
Show answer

Answer: D. Establishing cause-effect relationships

Report this question

3The statistician associated with the development of modern experimental design and ANOVA is:

  1. R. A. Fisher
  2. Karl Pearson
  3. Francis Galton
  4. W. S. Gosset
Show answer

Answer: A. R. A. Fisher

Report this question

4The group that receives the treatment is the:

  1. Experimental group
  2. Control group
  3. Placebo-only group
  4. Reference population
Show answer

Answer: A. Experimental group

Report this question

5The control group:

  1. Serves as a baseline and does not receive the treatment
  2. Receives the special treatment
  3. Is the researcher's team
  4. Is selected after the experiment
Show answer

Answer: A. Serves as a baseline and does not receive the treatment

Report this question

6Random assignment mainly:

  1. Increases the sample size
  2. Makes the groups equivalent on average, reducing selection bias
  3. Removes the dependent variable
  4. Guarantees generalisability
Show answer

Answer: B. Makes the groups equivalent on average, reducing selection bias

Report this question

7Matching in experimental research means:

  1. Giving all participants the same treatment
  2. Using only one group
  3. Pairing participants on a relevant variable and distributing them across groups
  4. Avoiding randomisation
Show answer

Answer: C. Pairing participants on a relevant variable and distributing them across groups

Report this question

8A placebo is:

  1. An active drug
  2. A type of sample
  3. An inert treatment used to control expectation effects
  4. A statistical test
Show answer

Answer: C. An inert treatment used to control expectation effects

Report this question

9In a double-blind experiment:

  1. Only participants are unaware of group assignment
  2. Neither participants nor experimenters know who receives the treatment
  3. Two observers record data
  4. There are two control groups
Show answer

Answer: B. Neither participants nor experimenters know who receives the treatment

Report this question

10Internal validity refers to:

  1. Generalisation to other populations
  2. Consistency of scores
  3. Representativeness of the sample
  4. The extent to which changes in the dependent variable are due to the independent variable
Show answer

Answer: D. The extent to which changes in the dependent variable are due to the independent variable

Report this question

11External validity refers to:

  1. Accuracy of the instrument
  2. Control of variables
  3. The extent to which findings can be generalised to other settings and people
  4. Ethical approval
Show answer

Answer: C. The extent to which findings can be generalised to other settings and people

Report this question

12The Hawthorne effect is a change in behaviour because:

  1. Participants drop out
  2. The pretest sensitises them
  3. Participants know they are being studied
  4. Extreme scores regress
Show answer

Answer: C. Participants know they are being studied

Report this question

13The "history" threat to internal validity refers to:

  1. Natural growth of participants
  2. Loss of participants
  3. External events, other than the treatment, occurring between pretest and posttest
  4. Familiarity with the test
Show answer

Answer: C. External events, other than the treatment, occurring between pretest and posttest

Report this question

14The "maturation" threat refers to:

  1. Changes in the instrument
  2. Dropout of participants
  3. Pretest effects
  4. Natural biological or psychological changes in participants over time
Show answer

Answer: D. Natural biological or psychological changes in participants over time

Report this question

15The "testing" threat means that:

  1. The treatment is too long
  2. The sample is biased
  3. The pretest itself affects scores on the posttest
  4. The tool is unreliable
Show answer

Answer: C. The pretest itself affects scores on the posttest

Report this question

16The "instrumentation" threat means:

  1. Participants leave the study
  2. Events occur outside the lab
  3. Changes in the measuring instrument or observers alter the results
  4. Participants mature
Show answer

Answer: C. Changes in the measuring instrument or observers alter the results

Report this question

17Statistical regression is the tendency of:

  1. Scores to increase after the pretest
  2. Extreme scores to move toward the mean on retesting
  3. Groups to become unequal
  4. The treatment to wear off
Show answer

Answer: B. Extreme scores to move toward the mean on retesting

Report this question

18Experimental mortality (attrition) means:

  1. Death of the researcher
  2. Loss of participants during the study
  3. Termination of the funding
  4. Failure of the equipment
Show answer

Answer: B. Loss of participants during the study

Report this question

19The pretest-posttest control group design with random assignment is symbolised as:

  1. X O
  2. O X O
  3. X O1 O2
  4. R O1 X O2 / R O3 O4
Show answer

Answer: D. R O1 X O2 / R O3 O4

Report this question

20The Solomon four-group design is mainly used to control:

  1. Sampling frame errors
  2. Historical bias
  3. Observer drift
  4. The effect of pretesting (testing effect)
Show answer

Answer: D. The effect of pretesting (testing effect)

Report this question

21A quasi-experimental design:

  1. Has no independent variable
  2. Has no dependent variable
  3. Lacks random assignment of participants to groups
  4. Is always qualitative
Show answer

Answer: C. Lacks random assignment of participants to groups

Report this question

22The one-shot case study (X O) is a:

  1. Pre-experimental design
  2. True experimental design
  3. Factorial design
  4. Quasi-experimental design
Show answer

Answer: A. Pre-experimental design

Report this question

23A factorial design allows the researcher to study:

  1. Only one independent variable
  2. Two or more independent variables and their interaction effects
  3. Past events
  4. Only descriptive data
Show answer

Answer: B. Two or more independent variables and their interaction effects

Report this question

24In a within-subjects (repeated measures) design:

  1. Each participant experiences only one condition
  2. There is no independent variable
  3. Each participant experiences all conditions
  4. Only a control group is used
Show answer

Answer: C. Each participant experiences all conditions

Report this question

25A main risk in within-subjects designs is:

  1. No data
  2. Absence of a dependent variable
  3. No randomisation possible
  4. Carryover or order effects
Show answer

Answer: D. Carryover or order effects
