About this question set

This set has 25 multiple-choice questions on Plagiarism and Academic Integrity from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

25 practice questions with answers

1Plagiarism is:

  1. Using another person's ideas, words or work without proper acknowledgement and presenting it as one's own
  2. Citing a source correctly
  3. Paraphrasing with a citation
  4. Quoting with permission
Show answer

Answer: A. Using another person's ideas, words or work without proper acknowledgement and presenting it as one's own

Report this question

2The word "plagiarism" comes from the Latin plagiarius, meaning:

  1. Teacher
  2. Writer
  3. Honest copyist
  4. Kidnapper
Show answer

Answer: D. Kidnapper

Report this question

3Copying text word for word without quotation marks and citation is:

  1. Self-plagiarism
  2. Paraphrasing
  3. Verbatim (direct) plagiarism
  4. Summarising
Show answer

Answer: C. Verbatim (direct) plagiarism

Report this question

4Mosaic (patchwork) plagiarism involves:

  1. Citing every source
  2. Using only one's own ideas
  3. Borrowing phrases or passages from several sources and weaving them together without proper attribution
  4. Translating a text with credit
Show answer

Answer: C. Borrowing phrases or passages from several sources and weaving them together without proper attribution

Report this question

5Unintentional plagiarism often results from:

  1. Deliberate copying
  2. Careless note-taking and ignorance of citation conventions
  3. Hiring a ghostwriter
  4. Buying a thesis
Show answer

Answer: B. Careless note-taking and ignorance of citation conventions

Report this question

6Translating another author's work into a different language and presenting it as one's own without credit is:

  1. Acceptable
  2. Paraphrasing
  3. Translation plagiarism
  4. A form of citation
Show answer

Answer: C. Translation plagiarism

Report this question

7Using another person's original idea or concept without credit, even though no words are copied, is:

  1. Common knowledge
  2. Fair dealing
  3. Idea plagiarism
  4. Peer review
Show answer

Answer: C. Idea plagiarism

Report this question

8A researcher who presents a junior colleague's results as his or her own commits:

  1. Fair dealing
  2. Misappropriation of work, which is misconduct
  3. Authorised data sharing
  4. Acceptable mentoring
Show answer

Answer: B. Misappropriation of work, which is misconduct

Report this question

9Consider the following statements:
I. Plagiarism can involve ideas as well as words.
II. Self-plagiarism is considered unethical.
III. Copying text word for word is acceptable if the source appears in the reference list.

  1. I and II only
  2. I and III
  3. II and III
  4. I, II and III
Show answer

Answer: A. I and II only

Report this question

10Match the following:
List I: (i) Fabrication, (ii) Falsification, (iii) Plagiarism
List II: (P) appropriating others' work without credit, (Q) inventing data, (R) manipulating or omitting data

  1. i-P, ii-Q, iii-R
  2. i-Q, ii-R, iii-P
  3. i-R, ii-P, iii-Q
  4. i-Q, ii-P, iii-R
Show answer

Answer: B. i-Q, ii-R, iii-P

Report this question

11Acceptable paraphrasing requires:

  1. Replacing a few words with synonyms
  2. Changing only the order of sentences
  3. Restating the idea in one's own words and sentence structure, and citing the source
  4. Using a paraphrasing tool and omitting the citation
Show answer

Answer: C. Restating the idea in one's own words and sentence structure, and citing the source

Report this question

12A direct quotation must be given:

  1. Quotation marks (or block format) together with a citation
  2. Without any marks
  3. Only in the reference list
  4. Only in the acknowledgements
Show answer

Answer: A. Quotation marks (or block format) together with a citation

Report this question

13Common knowledge, such as "Delhi is the capital of India":

  1. Must always be cited
  2. Must be quoted
  3. Must be placed in an appendix
  4. Generally does not need citation
Show answer

Answer: D. Generally does not need citation

Report this question

14A summary differs from a paraphrase in that a summary:

  1. Needs no citation
  2. Condenses the main points of the source in the writer's own words, and still needs a citation
  3. Is longer than the original
  4. Copies the source exactly
Show answer

Answer: B. Condenses the main points of the source in the writer's own words, and still needs a citation

Report this question

15A citation is NOT required for:

  1. Another author's statistics
  2. The researcher's own original findings from the present study
  3. A direct quotation
  4. A figure borrowed from a paper
Show answer

Answer: B. The researcher's own original findings from the present study

Report this question

16Assertion (A): Paraphrasing someone's idea without citing the source is plagiarism.
Reason (R): Ideas, and not just exact words, are the intellectual property of the original author.

  1. Both A and R are true, and R explains A
  2. Both are true, but R does not explain A
  3. A is true, R is false
  4. A is false, R is true
Show answer

Answer: A. Both A and R are true, and R explains A

Report this question

17The Copyright Act in India was enacted in:

  1. 1947
  2. 1957
  3. 1976
  4. 2000
Show answer

Answer: B. 1957

Report this question

18Section 52 of the Indian Copyright Act, 1957 deals with:

  1. Penalties for plagiarism
  2. Registration of patents
  3. Acts that do not constitute infringement, such as fair dealing
  4. Journal indexing
Show answer

Answer: C. Acts that do not constitute infringement, such as fair dealing

Report this question

19To reuse a figure from another author's published paper in a thesis, one should:

  1. Redraw it without credit
  2. Assume it is common knowledge
  3. Change the colours only
  4. Obtain permission where required and cite the source
Show answer

Answer: D. Obtain permission where required and cite the source

Report this question

20A "CC BY" Creative Commons licence requires users to:

  1. Pay royalties
  2. Keep the work private
  3. Give appropriate credit to the creator
  4. Never modify the work
Show answer

Answer: C. Give appropriate credit to the creator

Report this question

21Exclusive rights granted for a limited period for an invention are protected by a:

  1. Patent
  2. Trademark
  3. Copyright
  4. Geographical indication
Show answer

Answer: A. Patent

Report this question

22Under the UGC (Promotion of Academic Integrity and Prevention of Plagiarism in Higher Educational Institutions) Regulations, 2018, similarity above 10% and up to 40% is:

  1. Level 0
  2. Level 1
  3. Level 2
  4. Level 3
Show answer

Answer: B. Level 1

Report this question

23Similarity above 40% and up to 60% is:

  1. Level 0
  2. Level 1
  3. Level 2
  4. Level 3
Show answer

Answer: C. Level 2

Report this question

24Similarity above 60% is:

  1. Level 0
  2. Level 1
  3. Level 2
  4. Level 3
Show answer

Answer: D. Level 3

Report this question

25For a student whose thesis falls in Level 1, the UGC 2018 Regulations provide that the student:

  1. Is expelled
  2. Is imprisoned
  3. Faces no action at all
  4. Must submit a revised script within a stipulated period not exceeding six months
Show answer

Answer: D. Must submit a revised script within a stipulated period not exceeding six months
