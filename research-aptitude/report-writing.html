About this question set

This set has 10 multiple-choice questions on Report Writing from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

10 practice questions with answers

1The preliminary pages of a research report usually include:

  1. Title page, certificate, acknowledgements and contents
  2. Only the references
  3. Only the findings
  4. Only the appendices
Show answer

Answer: A. Title page, certificate, acknowledgements and contents

Report this question

2The conventional chapter scheme of a thesis is:

  1. Conclusion first, then introduction
  2. Only appendices
  3. Introduction, review, methodology, analysis and results, conclusions
  4. Only a bibliography
Show answer

Answer: C. Introduction, review, methodology, analysis and results, conclusions

Report this question

3An abstract is:

  1. A brief summary of the problem, method, findings and conclusions
  2. A list of references
  3. A questionnaire
  4. An acknowledgement
Show answer

Answer: A. A brief summary of the problem, method, findings and conclusions

Report this question

4The appendix contains:

  1. The conclusions
  2. The title
  3. Supplementary material, such as tools, raw data and permission letters
  4. The acknowledgements
Show answer

Answer: C. Supplementary material, such as tools, raw data and permission letters

Report this question

5A list of "References" includes:

  1. All books in the library
  2. Books the researcher intends to read
  3. Only the sources actually cited in the text
  4. Sources the researcher found irrelevant
Show answer

Answer: C. Only the sources actually cited in the text

Report this question

6A footnote appears:

  1. At the bottom of the page
  2. At the end of the thesis
  3. On the title page
  4. In the abstract
Show answer

Answer: A. At the bottom of the page

Report this question

7"Ibid." is used to:

  1. Refer to a new source
  2. Refer to the same source as the immediately preceding citation
  3. Refer to an unpublished source only
  4. Indicate an error
Show answer

Answer: B. Refer to the same source as the immediately preceding citation

Report this question

8The language of a research report should be:

  1. Emotional and persuasive
  2. Full of slang
  3. Ambiguous
  4. Simple, precise and objective
Show answer

Answer: D. Simple, precise and objective

Report this question

9Which of the following should NOT appear in the conclusion chapter?

  1. New data not presented earlier in the report
  2. A summary of findings
  3. Implications of the study
  4. Suggestions for further research
Show answer

Answer: A. New data not presented earlier in the report

Report this question

10Recommendations in a report are:

  1. New raw data
  2. The title
  3. Suggested actions or further research based on the findings
  4. The list of references
Show answer

Answer: C. Suggested actions or further research based on the findings
