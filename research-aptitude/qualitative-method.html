About this question set

This set has 20 multiple-choice questions on Qualitative Method from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

20 practice questions with answers

1Qualitative research aims mainly at:

  1. Statistical generalisation
  2. Hypothesis testing with large samples
  3. Precise numerical prediction
  4. In-depth understanding of meanings, experiences and context
Show answer

Answer: D. In-depth understanding of meanings, experiences and context

Report this question

2Qualitative analysis is generally:

  1. Strictly deductive
  2. Free of interpretation
  3. Based on fixed numeric formulas
  4. Inductive, with patterns and themes emerging from data
Show answer

Answer: D. Inductive, with patterns and themes emerging from data

Report this question

3Which of the following is NOT typically a qualitative method?

  1. Ethnography
  2. Case study
  3. A randomised controlled trial with statistical tests
  4. Narrative inquiry
Show answer

Answer: C. A randomised controlled trial with statistical tests

Report this question

4The sampling most commonly used in qualitative research is:

  1. Simple random
  2. Purposive
  3. Stratified random
  4. Cluster random
Show answer

Answer: B. Purposive

Report this question

5Data saturation is reached when:

  1. New data stop yielding new themes or insights
  2. The sample reaches 1,000
  3. The funding ends
  4. The questionnaire is complete
Show answer

Answer: A. New data stop yielding new themes or insights

Report this question

6A focus group discussion:

  1. Uses group interaction around a topic, guided by a moderator
  2. Is a one-to-one interview
  3. Is a postal survey
  4. Is a laboratory experiment
Show answer

Answer: A. Uses group interaction around a topic, guided by a moderator

7Field notes are:

  1. Statistical tables
  2. Written records of observations and reflections made in the field
  3. Sampling lists
  4. Questionnaires

Answer: B. Written records of observations and reflections made in the field

8A semi-structured interview:

  1. Has no guide at all
  2. Uses only closed questions
  3. Is a postal survey
  4. Uses a flexible guide, with scope for probing and follow-up questions

10In grounded theory, open coding is:

  1. The first stage of breaking data into discrete concepts and categories
  2. The last step of analysis
  3. A sampling technique
  4. A statistical test

11Reflexivity means:

  1. Repeating the study
  2. The researcher's critical reflection on their own role, assumptions and influence on the research
  3. Using a larger sample
  4. Using only numbers

12Member checking involves:

  1. Counting the members of a group
  2. Checking the sample size
  3. Returning findings to participants to verify accuracy and interpretation
  4. Verifying citations

13Lincoln and Guba's criteria of trustworthiness are:

  1. Validity, reliability, objectivity and norms
  2. Mean, median, mode and range

  1. External validity

  1. Internal validity
