20 practice questions with answers

1The principle of parsimony in research means:

  1. Using the most expensive method
  2. Using the largest possible sample
  3. Preferring the simplest adequate explanation
  4. Avoiding hypotheses
Show answer

Answer: C. Preferring the simplest adequate explanation

Report this question

2Scientific attitude includes:

  1. Dogmatism
  2. Blind faith in authority
  3. Open-mindedness and healthy scepticism
  4. Resistance to change
Show answer

Answer: C. Open-mindedness and healthy scepticism

Report this question

3Serendipity in research refers to:

  1. A planned deduction
  2. Plagiarism
  3. A sampling method
  4. An unexpected discovery made by chance while seeking something else
Show answer

Answer: D. An unexpected discovery made by chance while seeking something else

Report this question

4The variable manipulated by the researcher is the:

  1. Dependent variable
  2. Extraneous variable
  3. Independent variable
  4. Intervening variable
Show answer

Answer: C. Independent variable

Report this question

5The outcome variable is called the:

  1. Independent variable
  2. Moderator variable
  3. Dependent variable
  4. Control variable
Show answer

Answer: C. Dependent variable

Report this question

6An uncontrolled variable that may influence the dependent variable is called:

  1. Extraneous variable
  2. Criterion
  3. Constant
  4. Parameter
Show answer

Answer: A. Extraneous variable

Report this question

7A moderator variable:

  1. Affects the strength or direction of the relationship between the independent and dependent variables
  2. Is manipulated by the researcher
  3. Is the outcome variable
  4. Never changes
Show answer

Answer: A. Affects the strength or direction of the relationship between the independent and dependent variables

Report this question

8An intervening variable is:

  1. Directly manipulated
  2. A hypothetical process through which the independent variable influences the dependent variable
  3. Always the dependent variable
  4. A type of sampling error
Show answer

Answer: B. A hypothetical process through which the independent variable influences the dependent variable

Report this question

9A control variable is:

  1. A variable deliberately held constant so it does not influence the results
  2. The variable manipulated
  3. The outcome
  4. Random error
Show answer

Answer: A. A variable deliberately held constant so it does not influence the results

Report this question

10A theory is:

  1. A guess
  2. A set of interrelated concepts and propositions explaining a phenomenon
  3. Raw data
  4. A personal opinion
Show answer

Answer: B. A set of interrelated concepts and propositions explaining a phenomenon

Report this question

11An operational definition:

  1. Gives the dictionary meaning of a term
  2. States the final conclusion
  3. Is a legal definition
  4. Defines a concept in terms of measurable procedures
Show answer

Answer: D. Defines a concept in terms of measurable procedures

Report this question

12A null hypothesis states that:

  1. A significant difference exists
  2. The theory is always true
  3. The sample is biased
  4. There is no significant relationship or difference
Show answer

Answer: D. There is no significant relationship or difference

Report this question

13A good hypothesis should be:

  1. Clear, specific and testable
  2. Untestable
  3. Based on value judgments
  4. Too broad to measure
Show answer

Answer: A. Clear, specific and testable

Report this question

14A major function of a theory is to:

  1. Increase the sample size
  2. Replace data collection
  3. Explain and predict phenomena
  4. Avoid hypotheses
Show answer

Answer: C. Explain and predict phenomena

Report this question

15Research begins with:

  1. Data analysis
  2. Identification of a problem
  3. Report writing
  4. Sampling
Show answer

Answer: B. Identification of a problem

Report this question

16A good research problem should NOT be:

  1. Researchable
  2. Feasible
  3. Significant
  4. So vague that variables cannot be defined
Show answer

Answer: D. So vague that variables cannot be defined

Report this question

17A pilot study is:

  1. A small-scale preliminary study to test procedures
  2. The final study
  3. A literature review
  4. A research report
Show answer

Answer: A. A small-scale preliminary study to test procedures

Report this question

18The review of literature primarily helps to:

  1. Increase the sample size
  2. Replace data collection
  3. Write the abstract
  4. Avoid duplication and refine the research problem
Show answer

Answer: D. Avoid duplication and refine the research problem

Report this question

19Primary data are:

  1. Taken from a census report
  2. Taken from journal articles
  3. Taken from encyclopaedias
  4. Collected first-hand by the researcher for the study
Show answer

Answer: D. Collected first-hand by the researcher for the study

Report this question

20Secondary data are:

  1. Collected by the researcher through interviews
  2. Collected earlier by others and reused by the researcher
  3. Gathered by direct observation
  4. Generated through the researcher's own experiment
Show answer

Answer: B. Collected earlier by others and reused by the researcher
