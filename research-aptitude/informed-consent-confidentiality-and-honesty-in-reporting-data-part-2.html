About this question set

This set has 25 multiple-choice questions on Informed Consent, Confidentiality and Honesty in Reporting Data from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

25 practice questions with answers

1Privacy refers to:

  1. A type of data analysis
  2. A citation style
  3. A person's right to control access to information about themselves
  4. A sampling frame
Show answer

Answer: C. A person's right to control access to information about themselves

Report this question

2In focus group discussions, the researcher:

  1. Can guarantee complete confidentiality
  2. Cannot fully guarantee confidentiality because other group members hear the discussion, and should ask members to respect it
  3. Need not mention confidentiality
  4. Publishes names of members
Show answer

Answer: B. Cannot fully guarantee confidentiality because other group members hear the discussion, and should ask members to respect it

Report this question

3Which of the following violates confidentiality?

  1. Using codes in place of names
  2. Locking data files
  3. Reporting grouped results
  4. Discussing a participant's identifiable information with outsiders
Show answer

Answer: D. Discussing a participant's identifiable information with outsiders

Report this question

4Reporting group-level or aggregated data, rather than individual-level data, helps in:

  1. Fabrication
  2. Plagiarism
  3. Protecting participants' identities
  4. Coercion
Show answer

Answer: C. Protecting participants' identities

Report this question

5Consider the following statements:
I. Anonymity and confidentiality are identical.
II. In confidentiality, the researcher knows the identity of participants but protects it.
III. Anonymity means that responses cannot be linked to identities.

  1. I and II only
  2. I and III only
  3. I, II and III
  4. II and III only
Show answer

Answer: D. II and III only

Report this question

6Which Indian law enacted in 2023 deals with the protection of digital personal data?

  1. The Copyright Act, 1957
  2. The Right to Education Act, 2009
  3. The Digital Personal Data Protection Act, 2023
  4. The Patents Act, 1970
Show answer

Answer: C. The Digital Personal Data Protection Act, 2023

Report this question

7The General Data Protection Regulation (GDPR) is a data protection law of the:

  1. USA
  2. India
  3. Australia
  4. European Union
Show answer

Answer: D. European Union

Report this question

8Publishing identifiable photographs or recordings of participants requires:

  1. No permission
  2. Only the supervisor's permission
  3. Specific consent from the participants
  4. Only the editor's permission
Show answer

Answer: C. Specific consent from the participants

Report this question

9Using previously collected data for a new purpose (secondary use) should:

  1. Be subject to ethical review and consent or de-identification as appropriate
  2. Never be done
  3. Be done secretly
  4. Need no review
Show answer

Answer: A. Be subject to ethical review and consent or de-identification as appropriate

Report this question

10Research data should be retained:

  1. For one day only
  2. Forever on public servers
  3. Only on the researcher's phone
  4. For as long as institutional or funder policies require, and then disposed of securely
Show answer

Answer: D. For as long as institutional or funder policies require, and then disposed of securely

Report this question

11In online research, data from public social media posts:

  1. Can still raise privacy and consent issues, which should be considered
  2. Raise no privacy concerns at all
  3. May belong to anyone
  4. Can always be quoted with names
Show answer

Answer: A. Can still raise privacy and consent issues, which should be considered

Report this question

12Honesty in reporting requires that researchers:

  1. Report only positive results
  2. Omit unexpected results
  3. Adjust data to fit the hypothesis
  4. Report findings accurately, including negative or null results
Show answer

Answer: D. Report findings accurately, including negative or null results

Report this question

13Publication bias is the tendency to:

  1. Publish too many reviews
  2. Reject all long papers
  3. Cite only old papers
  4. Publish mainly studies with significant or positive results
Show answer

Answer: D. Publish mainly studies with significant or positive results

Report this question

14Selective reporting of outcomes means:

  1. Reporting all outcomes
  2. Reporting limitations
  3. Reporting only favourable outcomes and leaving out others
  4. Registering a trial
Show answer

Answer: C. Reporting only favourable outcomes and leaving out others

Report this question

15Removing outliers from a dataset is ethically acceptable if:

  1. It makes the result significant
  2. It is done silently
  3. The supervisor prefers it
  4. It is done on a justified, pre-stated basis and disclosed in the report
Show answer

Answer: D. It is done on a justified, pre-stated basis and disclosed in the report

Report this question

16Reporting only statistically significant results from many tests performed, without disclosing the other tests, is:

  1. Good practice
  2. Required
  3. A citation style
  4. Misleading and unethical
Show answer

Answer: D. Misleading and unethical

Report this question

17Acknowledging the limitations of one's study in the report shows:

  1. Honesty and transparency
  2. Weakness that must be hidden
  3. A mistake in design
  4. Plagiarism
Show answer

Answer: A. Honesty and transparency

Report this question

18Assertion (A): Reporting only favourable results is acceptable in research.
Reason (R): Negative results are of no scientific value.

  1. Both are true
  2. A is true, R is false
  3. Both A and R are false
  4. A is false, R is true
Show answer

Answer: C. Both A and R are false

Report this question

19Pre-registration of a study involves:

  1. Registering after the results are known
  2. Registering the participants' names publicly
  3. Registering the hypotheses and methods before data collection, which helps reduce HARKing and selective reporting
  4. Registering the thesis in a library
Show answer

Answer: C. Registering the hypotheses and methods before data collection, which helps reduce HARKing and selective reporting

Report this question

20In India, registration of clinical trials is done with the:

  1. Press Council
  2. UGC
  3. National Library
  4. Clinical Trials Registry – India (CTRI)
Show answer

Answer: D. Clinical Trials Registry – India (CTRI)

Report this question

21Making raw data available for verification, subject to privacy safeguards, supports:

  1. Secrecy
  2. Plagiarism
  3. Fabrication
  4. Transparency and reproducibility
Show answer

Answer: D. Transparency and reproducibility

Report this question

22Funding sources should be:

  1. Hidden
  2. Disclosed only to friends
  3. Disclosed in the publication
  4. Mentioned only after retirement
Show answer

Answer: C. Disclosed in the publication

Report this question

23If a researcher discovers a serious error in a published paper, he or she should:

  1. Stay silent
  2. Delete the paper from the internet secretly
  3. Blame the reviewer
  4. Notify the journal promptly so that a correction (erratum) or retraction can be issued
Show answer

Answer: D. Notify the journal promptly so that a correction (erratum) or retraction can be issued

Report this question

24An erratum differs from a retraction in that an erratum:

  1. Corrects an error in a published article, whereas a retraction withdraws the whole article
  2. Withdraws the entire article
  3. Is the same as a retraction
  4. Is a type of plagiarism
Show answer

Answer: A. Corrects an error in a published article, whereas a retraction withdraws the whole article

Report this question

25Honest error differs from misconduct in that honest error:

  1. Is deliberate
  2. Is unintentional and, when discovered, is corrected openly
  3. Is the same as fabrication
  4. Is the same as plagiarism
Show answer

Answer: B. Is unintentional and, when discovered, is corrected openly
