About this question set

This set has 13 multiple-choice questions on Data Analysis and Interpretation from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

13 practice questions with answers

1Coding of data means:

  1. Writing the report
  2. Assigning numerical or symbolic categories to responses for analysis
  3. Selecting a sample
  4. Hiding the identity of the researcher
Show answer

Answer: B. Assigning numerical or symbolic categories to responses for analysis

2Editing of data is done to:

  1. Increase the sample
  2. Write the abstract
  3. Check for errors, omissions and inconsistencies
  4. Select a design
Show answer

Answer: C. Check for errors, omissions and inconsistencies

Report this question

3Tabulation is the:

  1. Arrangement of data in rows and columns
  2. Selection of a topic
  3. Citation of sources
  4. Design of tools
Show answer

Answer: A. Arrangement of data in rows and columns

Report this question

4For a highly skewed distribution, the best measure of central tendency is usually the:

  1. Mean
  2. Mode
  3. Range
  4. Median
Show answer

Answer: D. Median

5In a positively skewed distribution:

  1. Mode < median < mean
  2. Mean < median < mode
  3. Mean = median = mode
  4. Median < mean < mode
Show answer

Answer: A. Mode < median < mean

Report this question

6Inferential statistics are used to:

  1. Only list the data
  2. Only draw graphs
  3. Only code the data
  4. Generalise from a sample to a population
Show answer

Answer: D. Generalise from a sample to a population

7A non-parametric alternative to the independent-samples t-test is the:

  1. Mann-Whitney U test
  2. Pearson r
  3. ANOVA
  4. Z-test for proportions
Show answer

Answer: A. Mann-Whitney U test

8For a chi-square test on a 3 × 4 contingency table, the degrees of freedom are:

  1. 12
  2. 7
  3. 3
  4. 6
Show answer

Answer: D. 6

9Pearson's product-moment correlation is appropriate for:

  1. Nominal data only
  2. Ordinal data only
  3. Qualitative data only
  4. Interval or ratio data showing a linear relationship
Show answer

Answer: D. Interval or ratio data showing a linear relationship

Report this question

10Spearman's rank-order correlation is used for:

  1. Interval data with a normal distribution only
  2. Nominal data only
  3. Ordinal (ranked) data
  4. Qualitative data only
Show answer

Answer: C. Ordinal (ranked) data

Report this question

11Regression analysis is used to:

  1. Predict the value of a dependent variable from one or more independent variables
  2. Compute the mode
  3. Select a sample
  4. Code responses
Show answer

Answer: A. Predict the value of a dependent variable from one or more independent variables

Report this question

12A high correlation between ice-cream sales and drowning incidents shows that:

  1. Ice cream causes drowning
  2. Drowning causes ice-cream sales
  3. The data must be wrong
  4. Both may be influenced by a third factor, such as hot weather, and correlation does not prove causation
Show answer

Answer: D. Both may be influenced by a third factor, such as hot weather, and correlation does not prove causation

  1. Only copying tables into the report
  2. Drawing inferences and relating findings to the hypotheses, theory and earlier studies
  3. Only checking spellings
