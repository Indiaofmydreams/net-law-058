About this question set

This set has 24 multiple-choice questions on Plagiarism and Academic Integrity from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

24 practice questions with answers

1For a student in Level 2, the penalty is that the student:

  1. Is given a warning only
  2. Gets a bonus
  3. Is registered for a new programme
  4. Is debarred from submitting a revised script for one year
Show answer

Answer: D. Is debarred from submitting a revised script for one year

Report this question

2For a student whose thesis has similarity above 60%, the registration for that programme:

  1. Is cancelled
  2. Continues unchanged
  3. Is extended
  4. Is transferred
Show answer

Answer: A. Is cancelled

Report this question

3Which of the following is excluded from the similarity check under the UGC 2018 Regulations?

  1. Copied paragraphs
  2. Self-plagiarised content
  3. Unattributed ideas
  4. Quoted work with attribution, references, bibliography, table of contents, preface, acknowledgements, generic terms and standard symbols or equations
Show answer

Answer: D. Quoted work with attribution, references, bibliography, table of contents, preface, acknowledgements, generic terms and standard symbols or equations

Report this question

4The UGC 2018 Regulations require every institution to set up:

  1. A Plagiarism Court
  2. A Journal Ranking Board
  3. A Departmental Academic Integrity Panel and an Institutional Academic Integrity Panel
  4. A Citation Committee
Show answer

Answer: C. A Departmental Academic Integrity Panel and an Institutional Academic Integrity Panel

Report this question

5Which of the following is NOT one of the fundamental values of academic integrity identified by the International Center for Academic Integrity?

  1. Secrecy
  2. Honesty
  3. Trust
  4. Fairness
Show answer

Answer: A. Secrecy

Report this question

6Contract cheating means:

  1. Signing a research contract
  2. Hiring a third party to complete academic work and submitting it as one's own
  3. Breaking a funding contract
  4. Citing a contract
Show answer

Answer: B. Hiring a third party to complete academic work and submitting it as one's own

Report this question

7Getting a ghostwriter to write a thesis is unethical because it:

  1. Saves time
  2. Misrepresents authorship and the researcher's own competence
  3. Uses a computer
  4. Needs a citation style
Show answer

Answer: B. Misrepresents authorship and the researcher's own competence

Report this question

8Collusion in academic work refers to:

  1. Citing many authors
  2. Group study with permission
  3. Unauthorised cooperation with others in work that is meant to be individual
  4. Peer review
Show answer

Answer: C. Unauthorised cooperation with others in work that is meant to be individual

Report this question

9Altering a microscopy or gel image to improve the appearance of results in a way that misrepresents the data is:

  1. Acceptable enhancement
  2. A citation error
  3. A sampling method
  4. Research misconduct (image manipulation)
Show answer

Answer: D. Research misconduct (image manipulation)

Report this question

10Padding a reference list with sources that were never used or read is:

  1. Unethical, as it misrepresents the scholarship behind the work
  2. An ethical practice
  3. Required by journals
  4. A citation style
Show answer

Answer: A. Unethical, as it misrepresents the scholarship behind the work

Report this question

11Coercive citation refers to:

  1. Citing sources by force of habit
  2. Citing only classical works
  3. Citing without a reference list
  4. An editor or reviewer pressuring authors to cite particular journal articles to inflate citation metrics
Show answer

Answer: D. An editor or reviewer pressuring authors to cite particular journal articles to inflate citation metrics

Report this question

12Paper mills are:

  1. Factories that produce paper
  2. Organisations that sell fabricated manuscripts or authorships for payment
  3. Libraries
  4. Peer review services
Show answer

Answer: B. Organisations that sell fabricated manuscripts or authorships for payment

13Excessive self-citation done mainly to inflate one's own citation count is:

  1. Required
  2. Always good practice
  3. Ethically questionable
  4. A statistical method
Show answer

Answer: C. Ethically questionable

14A typical feature of predatory journals is:

  1. Rigorous double-blind review
  2. Free access with no fees
  3. Inclusion in all major indexes
  4. Aggressive solicitation, publication fees and minimal or no genuine peer review
Show answer

15The acknowledgements section is meant for:

  1. Listing the findings
  2. Listing the references
  3. Thanking people and institutions who helped but may not meet authorship criteria
  4. Describing the sample

16In a dispute over authorship, the first step should usually be:

  1. Going to the press
  2. Removing co-authors secretly
  3. Ignoring the dispute
  4. Resolving it through institutional procedures and guidelines such as those of COPE or the journal
Show answer

Answer: D. Resolving it through institutional procedures and guidelines such as those of COPE or the journal

17Likely consequences of proven plagiarism or fabrication include:

  1. Promotion only
  2. Retraction of papers, denial of degrees or increments, and disciplinary action
  3. Free publication
  4. No consequence ever
Show answer

Answer: B. Retraction of papers, denial of degrees or increments, and disciplinary action

18Retraction Watch is:

  1. A citation style
  2. A blog and database that tracks retractions of scientific papers
  3. A reference manager
  4. A journal ranking agency
Show answer

19The 1998 Lancet paper by Andrew Wakefield linking the MMR vaccine to autism was fully retracted because of:

  1. Ethical violations and misrepresentation of data
  2. A change in the journal's name
  3. Language errors
  4. A printing mistake
Show answer

Answer: A. Ethical violations and misrepresentation of data

Report this question

20Diederik Stapel, a social psychologist, became known in research ethics for:

  1. Founding the Nuremberg Code
  2. Writing the Belmont Report
  3. Designing the h-index
  4. Fabricating data in many studies
Show answer

Answer: D. Fabricating data in many studies

Report this question

21A similarity report generated by plagiarism-detection software mainly indicates:

  1. Textual overlap with other sources, not the intent of the writer
  2. The quality of the research
  3. The author's honesty
  4. The impact factor
Show answer

Answer: A. Textual overlap with other sources, not the intent of the writer

Report this question

22Submitting AI-generated text as one's own work without any disclosure, where the institution or journal requires disclosure, is:

  1. Mandatory
  2. A form of citation
  3. A sampling technique
  4. A violation of academic integrity norms
Show answer

Answer: D. A violation of academic integrity norms

Report this question

23Citing references that do not exist, such as fake references produced by AI tools, amounts to:

  1. Fair dealing
  2. Paraphrasing
  3. Fabrication
  4. Peer review
Show answer

Answer: C. Fabrication

Report this question

24Journals and institutions often use similarity-checking software and also rely on:

  1. Human judgement to decide whether similarity amounts to plagiarism
  2. Random decisions
  3. Only the impact factor
  4. Only the author's declaration
Show answer

Answer: A. Human judgement to decide whether similarity amounts to plagiarism
