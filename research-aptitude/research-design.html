About this question set

This set has 12 multiple-choice questions on Research Design from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

12 practice questions with answers

1The purpose of a research design is to:

  1. Publish findings
  2. Select the topic
  3. Provide a plan to answer the research questions while controlling variance
  4. Write the abstract
Show answer

Answer: C. Provide a plan to answer the research questions while controlling variance

Report this question

2Kerlinger's MAXMINCON principle means:

  1. Maximise sample size, minimise cost and control time
  2. Maximise bias and minimise validity
  3. Maximise systematic variance, minimise error variance and control extraneous variance
  4. Maximise error and minimise control
Show answer

Answer: C. Maximise systematic variance, minimise error variance and control extraneous variance

Report this question

3Which of the following is NOT part of a research design?

  1. Sampling plan
  2. The researcher's biography
  3. Plan for data collection tools
  4. Plan for data analysis
Show answer

Answer: B. The researcher's biography

Report this question

4A research proposal normally includes:

  1. Only references
  2. Only findings
  3. Only appendices
  4. Objectives, methodology and timeline
Show answer

Answer: D. Objectives, methodology and timeline

Report this question

5An exploratory research design is characterised by:

  1. Rigid structure
  2. Final hypothesis testing
  3. Flexibility, aimed at gaining insights and ideas
  4. Large probability samples only
Show answer

Answer: C. Flexibility, aimed at gaining insights and ideas

Report this question

6In the explanatory sequential mixed-methods design:

  1. Qualitative data are collected first, with no quantitative phase
  2. Both are collected without any relation
  3. Quantitative data are collected first, followed by qualitative data to explain the results
  4. Only documents are used
Show answer

Answer: C. Quantitative data are collected first, followed by qualitative data to explain the results

Report this question

7The time-series design:

  1. Makes repeated measurements before and after the treatment on one group
  2. Has only a single observation
  3. Has no treatment
  4. Is purely historical
Show answer

Answer: A. Makes repeated measurements before and after the treatment on one group

Report this question

8The non-equivalent control group design is:

  1. True experimental
  2. Pre-experimental
  3. Quasi-experimental
  4. Non-experimental
Show answer

Answer: C. Quasi-experimental

Report this question

9A Latin square design controls:

  1. One source of variation
  2. Two sources of extraneous variation, arranged in rows and columns
  3. No source of variation
  4. Only sampling error
Show answer

Answer: B. Two sources of extraneous variation, arranged in rows and columns

Report this question

10In a randomised block design:

  1. There is no randomisation
  2. Homogeneous units are grouped into blocks and treatments are randomly assigned within each block
  3. Only one block is used
  4. Treatments are fixed in advance
Show answer

Answer: B. Homogeneous units are grouped into blocks and treatments are randomly assigned within each block

Report this question

11Construct validity refers to:

  1. The speed of a test
  2. How well a tool measures the theoretical construct it is intended to measure
  3. Its cost
  4. The size of the sample
Show answer

Answer: B. How well a tool measures the theoretical construct it is intended to measure

Report this question

12Which of the following is a discrete variable?

  1. Number of children in a family
  2. Height
  3. Weight
  4. Time
Show answer

Answer: A. Number of children in a family
