About this question set

This set has 22 multiple-choice questions on Positivism and Post-Positivism from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

22 practice questions with answers

1In post-positivism, objectivity is pursued through:

  1. Ignoring researcher bias
  2. Acknowledging bias and using critical scrutiny and triangulation
  3. Relying on authority
  4. Using only intuition
Show answer

Answer: B. Acknowledging bias and using critical scrutiny and triangulation

Report this question

2In the post-positivist view, a hypothesis:

  1. Can be conclusively proven
  2. Is never rejected
  3. Cannot be conclusively proven, only supported or falsified
  4. Is unnecessary
Show answer

Answer: C. Cannot be conclusively proven, only supported or falsified

Report this question

3Assertion (A): Post-positivists reject the idea that absolute truth can be fully known.
Reason (R): They regard knowledge as conjectural and open to revision.

  1. Both true, and R explains A
  2. Both true, but R does not explain A
  3. A true, R false
  4. A false, R true
Show answer

Answer: A. Both true, and R explains A

Report this question

4Consider the following statements:
I. Positivism assumes an objective reality.
II. Post-positivism accepts that reality can be known only imperfectly.
III. Post-positivism rejects empirical evidence entirely.

  1. I and II only
  2. II and III only
  3. I and III only
  4. I, II and III
Show answer

Answer: A. I and II only

Report this question

5Post-positivism developed mainly as:

  1. A rejection of all science
  2. A critique and modification of positivism
  3. A form of theology
  4. A statistical technique
Show answer

Answer: B. A critique and modification of positivism

Report this question

6Post-positivists argue that observation is:

  1. Influenced by theory and the observer's background
  2. Completely theory-neutral
  3. Unnecessary in research
  4. Always identical across observers
Show answer

Answer: A. Influenced by theory and the observer's background

Report this question

7Consider the following statements:
I. Post-positivism accepts that a researcher's theories and values can influence observation.
II. Post-positivists try to reduce bias through multiple measures and critical scrutiny.
III. Positivism is explicitly value-laden.

  1. I and II
  2. II and III
  3. III only
  4. I and III
Show answer

Answer: A. I and II

Report this question

8The positivist ontological position holds that:

  1. Reality is socially constructed
  2. There are multiple subjective realities
  3. Reality is objective and exists independent of the observer
  4. Reality cannot be known
Show answer

Answer: C. Reality is objective and exists independent of the observer

Report this question

9Positivist epistemology holds that knowledge comes from:

  1. Revelation
  2. Intuition
  3. Observation and empirical verification
  4. Authority
Show answer

Answer: C. Observation and empirical verification

Report this question

10On values, positivism assumes that research should be:

  1. Value-laden
  2. Value-free
  3. Politically driven
  4. Based on emotions
Show answer

Answer: B. Value-free

Report this question

11The post-positivist ontological stance is commonly called:

  1. Critical realism
  2. Naive realism
  3. Idealism
  4. Nihilism
Show answer

Answer: A. Critical realism

12Ontology in research concerns:

  1. Methods of sampling
  2. Citation style
  3. Statistical formulas
  4. The nature of reality
Show answer

Answer: D. The nature of reality

13Epistemology concerns:

  1. The role of values
  2. Data storage
  3. The nature and sources of knowledge
  4. Sampling frames
Show answer

Answer: C. The nature and sources of knowledge

Report this question

14Axiology concerns:

  1. Tools of measurement
  2. Logic of deduction
  3. Data coding
  4. The role of values and ethics in research
Show answer

Answer: D. The role of values and ethics in research

Report this question

15Constructivism or interpretivism holds that:

  1. Multiple realities are constructed by individuals
  2. There is a single objective reality
  3. Only experiments give truth
  4. Values are irrelevant
Show answer

Answer: A. Multiple realities are constructed by individuals

Report this question

16The paradigm that stresses social change and the empowerment of marginalised groups is the:

  1. Positivist paradigm
  2. Post-positivist paradigm
  3. Naive realist paradigm
  4. Critical or transformative paradigm
Show answer

Answer: D. Critical or transformative paradigm

Report this question

17Hermeneutics is concerned with:

  1. Laboratory measurement
  2. Random sampling
  3. Interpretation of meaning, especially of texts and human action
  4. Statistical testing
Show answer

Answer: C. Interpretation of meaning, especially of texts and human action

Report this question

18The main contrast between positivism and interpretivism is that:

  1. Positivism seeks understanding of meanings, interpretivism seeks laws
  2. Both reject empirical evidence
  3. Both are identical
  4. Positivism seeks explanation and prediction through laws, interpretivism seeks understanding of meanings
Show answer

Answer: D. Positivism seeks explanation and prediction through laws, interpretivism seeks understanding of meanings

Report this question

19Which approach is most consistent with interpretivism?

  1. Qualitative methods such as in-depth interviews
  2. Controlled experiments only
  3. Large-scale statistical modelling only
  4. Randomised trials only
Show answer

Answer: A. Qualitative methods such as in-depth interviews

Report this question

20In research, "paradigm" refers to:

  1. A statistical test
  2. A sampling technique
  3. A worldview or set of beliefs guiding inquiry
  4. A citation style
Show answer

Answer: C. A worldview or set of beliefs guiding inquiry

Report this question

21Which paradigm most strongly supports mixed-methods research?

  1. Pragmatism
  2. Logical positivism
  3. Naive realism
  4. Dogmatism
Show answer

Answer: A. Pragmatism

Report this question

22Triangulation means:

  1. Using three researchers only
  2. Using multiple methods, sources or theories to cross-check findings
  3. Selecting three samples
  4. Using three hypotheses
