About this question set

This set has 13 multiple-choice questions on Formulating Hypotheses from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Research Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

13 practice questions with answers

1A directional hypothesis:

  1. Predicts the direction of the difference or relationship
  2. States no difference
  3. Is untestable
  4. Is a conclusion
Show answer

Answer: A. Predicts the direction of the difference or relationship

Report this question

2A non-directional hypothesis:

  1. Predicts that group A will score higher
  2. States no relationship
  3. Is a statistical error
  4. States that a difference or relationship exists, without specifying direction
Show answer

Answer: D. States that a difference or relationship exists, without specifying direction

Report this question

3A directional hypothesis is tested with a:

  1. One-tailed test
  2. Two-tailed test only
  3. Qualitative test only
  4. No test
Show answer

Answer: A. One-tailed test

Report this question

4A simple hypothesis relates:

  1. Many independent variables to many dependent variables
  2. One independent variable and one dependent variable
  3. No variables
  4. Only moderators
Show answer

Answer: B. One independent variable and one dependent variable

Report this question

5A statistical hypothesis is a statement about:

  1. The researcher's feelings
  2. A literature gap
  3. A population parameter
  4. The report format
Show answer

Answer: C. A population parameter

Report this question

6"Students taught by the activity method will score higher than those taught by the lecture method" is a:

  1. Null hypothesis
  2. Non-directional hypothesis
  3. Directional hypothesis
  4. Statistical error
Show answer

Answer: C. Directional hypothesis

Report this question

7The alternative hypothesis is usually symbolised as:

  1. H1 or Ha
  2. H0
  3. Hn
  4. Hx
Show answer

Answer: A. H1 or Ha

Report this question

8The null hypothesis is usually symbolised as:

  1. H1
  2. H0
  3. Ha
  4. Hn
Show answer

Answer: B. H0

Report this question

9If the p-value is less than the chosen significance level, the researcher:

  1. Fails to reject H0
  2. Accepts the sample
  3. Rejects H0
  4. Proves H1 absolutely
Show answer

Answer: C. Rejects H0

Report this question

10"There is no significant difference in achievement between rural and urban students" is a:

  1. Null hypothesis
  2. Directional hypothesis
  3. Research hypothesis
  4. Complex hypothesis
Show answer

Answer: A. Null hypothesis

Report this question

11Hypotheses may be derived from:

  1. Theory
  2. Previous research
  3. Observation of events
  4. All of the above
Show answer

Answer: D. All of the above

Report this question

12Hypotheses are generally NOT formulated in:

  1. Experimental studies
  2. Correlational studies
  3. Exploratory or many qualitative studies
  4. Causal-comparative studies
Show answer

Answer: C. Exploratory or many qualitative studies

Report this question

13In hypothesis-testing studies, hypotheses are formulated:

  1. Before data collection
  2. After data analysis
  3. After report writing
  4. Only after drawing conclusions
Show answer

Answer: A. Before data collection
