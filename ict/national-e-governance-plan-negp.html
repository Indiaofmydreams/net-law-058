About this question set

This set has 9 multiple-choice questions on National e-Governance Plan (NeGP) from the UGC NET Paper 1 syllabus, unit 8, Information and Communication Technology (ICT). Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the ICT notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

9 practice questions with answers

1The National e-Governance Plan (NeGP) was approved by the Union Cabinet in:

  1. 2015
  2. 2020
  3. 1996
  4. 2006
Show answer

Answer: D. 2006

Report this question

2NeGP initially comprised how many Mission Mode Projects (MMPs)?

  1. 10
  2. 15
  3. 27
  4. 100
Show answer

Answer: C. 27

3SWAN stands for:

  1. Secure Web Access Node
  2. State Wide Area Network
  3. South Wide Access Network
  4. Standard Wide Area Net
Show answer

Answer: B. State Wide Area Network

4SDC in the NeGP infrastructure stands for:

  1. Secure Digital Cloud
  2. State Data Centre
  3. System Data Card
  4. Standard Data Chip
Show answer

Answer: B. State Data Centre

5NeGP aimed to deliver government services through:

  1. Common service delivery outlets
  2. Post offices only
  3. Only urban offices
  4. Only mobile apps
Show answer

Answer: A. Common service delivery outlets

6e-Kranti is:

  1. A TV channel
  2. An examination
  3. A payment app
  4. NeGP 2.0, focusing on electronic delivery of services under Digital India
Show answer

Answer: D. NeGP 2.0, focusing on electronic delivery of services under Digital India

7The guiding principle of e-Kranti is:

  1. "Translation, not transformation"
  2. "Offline first"
  3. "Paper first"
  4. "Transformation, not translation"
Show answer

Answer: D. "Transformation, not translation"

8NeGP was implemented by:

  1. NITI Aayog
  2. SEBI
  3. DeitY (now MeitY) and DARPG
  4. RBI

(a) NeGP (i) 2006

(d) NAD (iv) 2017

  1. a-i, b-iii, c-ii, d-iv

  3. a-iii, b-i, c-ii, d-iv
  4. a-ii, b-iii, c-i, d-iv
