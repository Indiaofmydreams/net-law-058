About this question set

This set has 14 multiple-choice questions on E-learning Modes, LMS and MOOCs from the UGC NET Paper 1 syllabus, unit 8, Information and Communication Technology (ICT). Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the ICT notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

14 practice questions with answers

1E-learning means learning:

  1. Only through radio
  2. Only through books
  3. Only in a classroom
  4. Through electronic media and the Internet
Show answer

Answer: D. Through electronic media and the Internet

Report this question

2Blended learning:

  1. Is only TV-based
  2. Combines face-to-face and online learning
  3. Is fully offline only
  4. Is fully online only
Show answer

Answer: B. Combines face-to-face and online learning

Report this question

3In a flipped classroom:

  1. Content is studied at home (e.g., videos) and class time is used for practice and discussion
  2. Lectures happen in class and homework is done at home
  3. There are no lectures at all
  4. Classes are held only on weekends
Show answer

Answer: A. Content is studied at home (e.g., videos) and class time is used for practice and discussion

Report this question

4The flipped classroom model was popularised by:

  1. Jonathan Bergmann and Aaron Sams
  2. Skinner
  3. Piaget
  4. Bloom
Show answer

Answer: A. Jonathan Bergmann and Aaron Sams

Report this question

5M-learning refers to:

  1. Learning only in labs
  2. Learning through mobile devices such as smartphones and tablets
  3. Learning only on desktops
  4. Learning only on TV
Show answer

Answer: B. Learning through mobile devices such as smartphones and tablets

Report this question

6Asynchronous e-learning is one in which:

  1. Learners access content at their own convenience, not simultaneously
  2. Classes are held in a classroom
  3. Everyone learns in real time
  4. No Internet is used
Show answer

Answer: A. Learners access content at their own convenience, not simultaneously

Report this question

7Which of the following is an example of synchronous e-learning?

  1. An e-mail
  2. A live online class on a video-conferencing platform
  3. A printed module
  4. A recorded video
Show answer

Answer: B. A live online class on a video-conferencing platform

Report this question

8A Learning Management System (LMS) is:

  1. An e-mail client
  2. A hardware device
  3. A search engine
  4. A software platform to deliver, manage and track courses
Show answer

Answer: D. A software platform to deliver, manage and track courses

Report this question

9Moodle is:

  1. A MOOC provider
  2. A Google tool
  3. An open-source LMS created by Martin Dougiamas
  4. A Microsoft LMS
Show answer

Answer: C. An open-source LMS created by Martin Dougiamas

Report this question

10Google Classroom is:

  1. A free tool from Google for assignments and class communication
  2. A social network
  3. An offline tool
  4. A paid hardware product
Show answer

Answer: A. A free tool from Google for assignments and class communication

Report this question

11MOOC stands for:

  1. Mobile Open Online Content
  2. Massive Open Online Course
  3. Massive Offline Open Class
  4. Multiple Online Open Class
Show answer

Answer: B. Massive Open Online Course

Report this question

12The term "MOOC" was coined in 2008 by:

  1. Tim Berners-Lee
  2. Andrew Ng
  3. Dave Cormier and Bryan Alexander
  4. Bill Gates
Show answer

Answer: C. Dave Cormier and Bryan Alexander

Report this question

13A cMOOC is:

  1. Video only
  2. A paid course only
  3. Based on connectivism, with networked and collaborative learning
  4. Based on instructor lectures only
Show answer

Answer: C. Based on connectivism, with networked and collaborative learning

14An xMOOC is:

  1. Not Internet-based
  2. Offline
  3. Based on peer networks only
  4. Content-based, with instructor-led video lectures and assessments (e.g., Coursera, edX)
