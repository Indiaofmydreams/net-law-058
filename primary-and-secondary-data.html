About this question set

This set has 20 multiple-choice questions on Primary and Secondary Data from the UGC NET Paper 1 syllabus, unit 7, Data Interpretation. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Data Interpretation notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

20 practice questions with answers

1Data collected first-hand by the researcher for a specific purpose is called:

  1. Primary data
  2. Secondary data
  3. Tertiary data
  4. Derived data
Show answer

Answer: A. Primary data

Report this question

2A researcher uses an NSS report on household consumption to study spending patterns. For this researcher the data is:

  1. Secondary
  2. Primary
  3. Experimental
  4. Purely qualitative
Show answer

Answer: A. Secondary

Report this question

3Data collected by the Census Office is ___ for the Census Office and ___ for a scholar who later uses the published tables.

  1. Secondary, primary
  2. Primary, primary
  3. Secondary, secondary
  4. Primary, secondary
Show answer

Answer: D. Primary, secondary

Report this question

4A teacher administers a test to her own students as part of her research. The data so generated is:

  1. Secondary
  2. Primary
  3. Published
  4. Administrative
Show answer

Answer: B. Primary

Report this question

5A researcher downloads data from the Open Government Data Platform (data.gov.in). The data is:

  1. Primary
  2. Experimental
  3. Observational
  4. Secondary
Show answer

Answer: D. Secondary

Report this question

6Which of the following is NOT an advantage of primary data?

  1. It is cheap and quickly available
  2. It is specific to the research problem
  3. The researcher controls its quality
  4. It is up to date
Show answer

Answer: A. It is cheap and quickly available

Report this question

7The main limitation of secondary data is that:

  1. It is always costly
  2. It cannot be analysed statistically
  3. It is never published
  4. It may not exactly fit the objectives of the present study
Show answer

Answer: D. It may not exactly fit the objectives of the present study

Report this question

8Consider the statements:
I. Primary data is original in nature.
II. Secondary data has already been collected by someone else.
III. Secondary data is always more accurate than primary data.
Which of the statements are correct?

  1. II and III only
  2. I and III only
  3. I, II and III
  4. I and II only
Show answer

Answer: D. I and II only

Report this question

9Before using secondary data, a researcher should check its:

  1. Cost only
  2. Suitability, reliability and adequacy
  3. Colour and layout
  4. Place of publication only
Show answer

Answer: B. Suitability, reliability and adequacy

Report this question

10Primary data collection is most justified when:

  1. Existing data fully answers the research problem
  2. The researcher has very little time
  3. The required information is not available in existing sources
  4. The researcher has no budget
Show answer

Answer: C. The required information is not available in existing sources

Report this question

11Assertion (A): Secondary data is economical.
Reason (R): It has already been collected and compiled by others.

  1. Both A and R are true and R is the correct explanation of A
  2. Both A and R are true but R is not the correct explanation of A
  3. A is true but R is false
  4. A is false but R is true
Show answer

Answer: A. Both A and R are true and R is the correct explanation of A

  2. Researcher's own questionnaire
  3. Direct observation
  4. Census report published by the government
