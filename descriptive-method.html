About this question set

This set has 20 multiple-choice questions on Descriptive Method from the UGC NET Paper 1 syllabus, unit 2, Research Aptitude. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

1The descriptive method primarily:

  1. Manipulates variables
  2. Studies only past events
  3. Tests drugs
  4. Describes existing conditions, status or relationships as they are
Show answer

Answer: D. Describes existing conditions, status or relationships as they are

2A normative survey:

  1. Studies one person
  2. Compares existing status with established standards or norms
  3. Is a laboratory study
  4. Uses only historical data

Answer: B. Compares existing status with established standards or norms

3A panel study:

  1. Uses a different sample each time
  2. Measures the same individuals repeatedly over time
  3. Studies a single case
  4. Is based only on documents

Answer: B. Measures the same individuals repeatedly over time

4A main limitation of the mailed questionnaire is:

  1. Low response rate
  2. High cost per respondent
  3. Inability to reach scattered respondents
  4. Need for trained interviewers
Show answer

Answer: A. Low response rate

5A structured interview:

  1. Has no fixed questions
  2. Uses predetermined questions in a fixed order
  3. Is purely conversational
  4. Is conducted only by telephone

Answer: B. Uses predetermined questions in a fixed order

6In participant observation the researcher:

  1. Stays outside the group
  2. Uses only questionnaires
  3. Takes part in the group's activities while observing
  4. Uses only records

Answer: C. Takes part in the group's activities while observing

7A leading question in a questionnaire should be avoided because it:

  1. Suggests the expected answer to the respondent
  2. Is too short
  3. Is too long
  4. Is open-ended

8A pilot test of a questionnaire is conducted to:

  4. Select the topic

  3. Equal-appearing intervals

  1. Cumulative
  2. Summated
  3. Free response
  4. Interval-based

14In simple random sampling:

  1. Every unit has an equal chance of selection
  2. Units are chosen by the researcher's judgement
  3. Units are chosen by quota
  4. Only volunteers are included

15In stratified random sampling:

  1. Only one group is studied
  2. The population is divided into homogeneous subgroups and samples are drawn from each
  3. Respondents choose themselves
  4. Every kth unit is chosen
Show answer

Answer: B. The population is divided into homogeneous subgroups and samples are drawn from each

16Cluster sampling involves:

  1. Selecting by quota
  2. Selecting intact groups, such as schools or villages, at random
  3. Selecting friends
  4. Selecting by referral
Show answer

Answer: B. Selecting intact groups, such as schools or villages, at random

17Systematic sampling means selecting:

  1. Units at random from clusters
  2. Volunteers

18Quota sampling is a:

  2. Cluster technique

  4. Census technique
