25 practice questions with answers

1Vyabhichara refers to:

  1. Invariable concomitance
  2. Similarity of two objects
  3. Verbal expectancy
  4. The presence of the hetu where the sadhya is absent
Show answer

Answer: D. The presence of the hetu where the sadhya is absent

Report this question

2Upadhi is defined as that which is:

  1. Pervasive of the sadhya but not pervasive of the hetu
  2. Absent in the sapaksha
  3. Equal to the paksha
  4. Coextensive with the hetu but not the sadhya
Show answer

Answer: A. Pervasive of the sadhya but not pervasive of the hetu

Report this question

3In "Violence is sinful because it is violence," the upadhi is:

  1. Violence itself
  2. Sacrifice
  3. Prohibition by scripture (nishiddhatva)
  4. Paksha
Show answer

Answer: C. Prohibition by scripture (nishiddhatva)

Report this question

4The presence of an upadhi shows that:

  1. The sapaksha is absent
  2. The vyapti is established
  3. The paksha is absent
  4. The vyapti is not unconditional
Show answer

Answer: D. The vyapti is not unconditional

Report this question

5In Nyaya, tarka (hypothetical reasoning) helps vyapti by:

  1. Establishing the paksha
  2. Removing doubt about the possibility of vyabhichara
  3. Naming the hetu
  4. Replacing perception
Show answer

Answer: B. Removing doubt about the possibility of vyabhichara

Report this question

6Nyaya explains the universality of vyapti through:

  1. Samanyalakshana pratyaksha
  2. Yogaja pratyaksha only
  3. Anupalabdhi
  4. Shabda
Show answer

Answer: A. Samanyalakshana pratyaksha

Report this question

7The Charvaka objection that vyapti cannot be known by inference leads to the charge of:

  1. Chala
  2. Atmashraya (self-dependence) only
  3. Infinite regress (anavastha)
  4. Pratijnahani
Show answer

Answer: C. Infinite regress (anavastha)

Report this question

8"This is a tree because it is a simshapa" illustrates the Buddhist vyapti based on:

  1. Tadutpatti
  2. Tadatmya
  3. Samavaya
  4. Samyoga
Show answer

Answer: B. Tadatmya

Report this question

9"There is fire because there is smoke" illustrates the Buddhist vyapti based on:

  1. Samyoga
  2. Abhava
  3. Tadatmya
  4. Tadutpatti (causal origin)
Show answer

Answer: D. Tadutpatti (causal origin)

Report this question

10The Jain term for the relation equivalent to vyapti is:

  1. Avinabhava
  2. Sannidhi
  3. Yogyata
  4. Akanksha
Show answer

Answer: A. Avinabhava

Report this question

11In Jain logic, the means of grasping vyapti is:

  1. Anupalabdhi
  2. Upamana
  3. Tarka (uha)
  4. Agama
Show answer

Answer: C. Tarka (uha)

Report this question

12A Navya-Nyaya definition of vyapti is:

  1. Equality of paksha and sapaksha
  2. Presence of hetu in vipaksha
  3. Identity of hetu and paksha
  4. Hetu-avritti in the loci of the absence of the sadhya
Show answer

Answer: D. Hetu-avritti in the loci of the absence of the sadhya

Report this question

13Which of the following is NOT a means of grasping vyapti?

  1. Bhuyodarshana (repeated observation)
  2. Upamana
  3. Non-observation of vyabhichara
  4. Tarka
Show answer

Answer: B. Upamana

Report this question

14Gangesha's Tattvachintamani discusses vyapti mainly in its:

  1. Anumana-khanda
  2. Upamana-khanda
  3. Shabda-khanda
  4. Pratyaksha-khanda
Show answer

Answer: A. Anumana-khanda

Report this question

15Assertion (A): Repeated observation alone cannot guarantee a universal vyapti.
Reason (R): A future counter-instance cannot be ruled out by observation alone.

  1. Both A and R are true and R explains A
  2. Both A and R are true but R does not explain A
  3. A is true but R is false
  4. A is false but R is true
Show answer

Answer: A. Both A and R are true and R explains A

Report this question

16Match the school with its view on vyapti:
(i) Charvaka (ii) Nyaya (iii) Buddhism (iv) Jainism
(A) Tadatmya and tadutpatti (B) Cannot be established (C) Avinabhava through tarka (D) Observation, no upadhi, and tarka

  1. i-A, ii-B, iii-C, iv-D
  2. i-C, ii-A, iii-D, iv-B
  3. i-B, ii-D, iii-A, iv-C
  4. i-D, ii-C, iii-B, iv-A
Show answer

Answer: C. i-B, ii-D, iii-A, iv-C

Report this question

17Statements:
I. Vyapti is a universal and invariable relation.
II. Vyapti is merely a psychological association.

  1. Neither is accepted
  2. Only I is accepted by Nyaya
  3. Only II is accepted by Nyaya
  4. Both are accepted
Show answer

Answer: B. Only I is accepted by Nyaya

Report this question

18Which of the following is a necessary condition for vyapti in Nyaya?

  1. Presence of vipaksha only
  2. Presence of upadhi
  3. Absence of the paksha
  4. Absence of upadhi
Show answer

Answer: D. Absence of upadhi

Report this question

19In the Tarkasamgraha, the five hetvabhasas are listed in the order:

  1. Badhita, Asiddha, Satpratipaksha, Viruddha, Savyabhichara
  2. Viruddha, Savyabhichara, Badhita, Asiddha, Satpratipaksha
  3. Savyabhichara, Viruddha, Satpratipaksha, Asiddha, Badhita
  4. Asiddha, Viruddha, Savyabhichara, Satpratipaksha, Badhita
Show answer

Answer: C. Savyabhichara, Viruddha, Satpratipaksha, Asiddha, Badhita

Report this question

20The number of hetvabhasas in Gautama's Nyaya Sutra is:

  1. Four
  2. Five
  3. Three
  4. Six
Show answer

Answer: B. Five

Report this question

21Which of the following is NOT in Gautama's list of hetvabhasas?

  1. Prakaranasama
  2. Savyabhichara
  3. Sadhyasama
  4. Ashrayasiddha
Show answer

Answer: D. Ashrayasiddha

22The Jain logician Manikyanandi adds which hetvabhasa to the three of Dignaga?

  1. Akinchitkara
  2. Anupasamhari
  3. Satpratipaksha
  4. Badhita
Show answer

Answer: A. Akinchitkara

Report this question

23Anupasamhari is a sub-type of:

  1. Asiddha
  2. Badhita
  3. Savyabhichara
  4. Viruddha
Show answer

Answer: C. Savyabhichara

Report this question

24A hetu that is present in both sapaksha and vipaksha is called:

  1. Anupasamhari
  2. Viruddha
  3. Asadharana
  4. Sadharana
Show answer

Answer: D. Sadharana

Report this question

25A hetu that is present neither in sapaksha nor in vipaksha, but only in the paksha, is:

  1. Svarupasiddha
  2. Asadharana
  3. Sadharana
  4. Badhita
Show answer

Answer: B. Asadharana
