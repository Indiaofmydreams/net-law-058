About this question set

This set has 18 multiple-choice questions on Mixed Exam-Pattern Questions on Data Sources and Surveys from the UGC NET Paper 1 syllabus, unit 7, Data Interpretation. 2Assertion (A): Panel data is more informative than cross-sectional data about change at the individual level.
Reason (R): Panel data observes different units at each point in time.

  1. Both A and R are true and R is the correct explanation of A
  2. Both A and R are true but R is not the correct explanation of A
  3. A is true but R is false
  4. A is false but R is true

Answer: C. A is true but R is false

5Consider the statements:

  1. I only

  3. I, II and III
