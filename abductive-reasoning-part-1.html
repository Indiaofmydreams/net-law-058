About this question set

This set has 19 multiple-choice questions on Abductive Reasoning from the UGC NET Paper 1 syllabus, unit 5, Mathematical Reasoning and Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 19 of the 19 questions carry a written explanation.

For the concepts and case law behind these questions, read the Mathematical Reasoning notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

19 practice questions with answers

1The term "abduction" in logic was popularised by:

  1. J.S. Mill
  2. Aristotle
  3. Charles Sanders Peirce
  4. Francis Bacon
Show answer and explanation

Answer: C. Charles Sanders Peirce

Peirce named it as the third type of inference.

Report this question

2Abductive reasoning is best described as:

  1. Validation by truth tables
  2. Deduction from axioms
  3. Generalisation from a sample
  4. Inference to the best explanation
Show answer and explanation

Answer: D. Inference to the best explanation

Choose the hypothesis that best explains the observed facts.

Report this question

3"The lawn is wet. If it had rained, the lawn would be wet. Hence it probably rained." This is:

  1. Deduction
  2. Abduction
  3. Mathematical induction
  4. Analogy
Show answer and explanation

Answer: B. Abduction

Observation, then a hypothesis that would explain it, then a plausible conclusion.

Report this question

4A doctor observes symptoms and concludes the most likely disease. This is:

  1. Abductive reasoning
  2. Syllogistic reasoning
  3. Analogical reasoning
  4. Deductive reasoning
Show answer and explanation

Answer: A. Abductive reasoning

Diagnosis is reasoning from effects to the likeliest cause.

Report this question

5The conclusion of an abductive inference is:

  1. Deduced from axioms
  2. Certain
  3. A tautology
  4. A plausible, tentative hypothesis
Show answer and explanation

Answer: D. A plausible, tentative hypothesis

It is plausible, not guaranteed.

Report this question

6The detective method of Sherlock Holmes, though called "deduction", is mostly:

  1. Pure induction
  2. Analogical reasoning
  3. Abductive reasoning
  4. Mathematical deduction
Show answer and explanation

Answer: C. Abductive reasoning

From clues to the best explanation of the crime.

Report this question

7Which pattern represents abduction?

  1. A resembles B; B has x; so A has x
  2. Fact C is observed; if A then C; hence A is probably true
  3. Many S observed are P; so all S are P
  4. All M are P; S is M; so S is P
Show answer and explanation

Answer: B. Fact C is observed; if A then C; hence A is probably true

(D) is deduction, (C) induction and (A) analogy.

Report this question

8Formally, abduction resembles which deductive fallacy?

  1. Affirming the consequent
  2. Denying the antecedent
  3. Undistributed middle
  4. Four terms
Show answer and explanation

Answer: A. Affirming the consequent

"If A then C; C; so A", which is acceptable only as hypothesis generation.

Report this question

9In choosing the best explanation, which criteria are commonly used?

  1. Authority
  2. Popularity
  3. Length
  4. Simplicity, explanatory power and coherence
Show answer and explanation

Answer: D. Simplicity, explanatory power and coherence

The best hypothesis explains most with the fewest assumptions.

Report this question

10Which of the following is abductive?

  1. Tom resembles Ravi in age and job; Ravi likes cricket; so Tom does
  2. Many observed swans are white; so all swans are white
  3. The patient has fever, cough and loss of smell; the likeliest explanation is a viral infection
  4. All metals conduct; copper is a metal; so copper conducts
Show answer and explanation

Answer: C. The patient has fever, cough and loss of smell; the likeliest explanation is a viral infection

(D) is deduction, (B) induction and (A) analogy.

Report this question

11Peirce's three kinds of inference are:

  1. Perception, memory, imagination
  2. Deduction, induction, abduction
  3. Syllogism, analogy, authority
  4. Analysis, synthesis, evaluation
Show answer and explanation

Answer: B. Deduction, induction, abduction

Three inference modes, each with a different job.

Report this question

12Statement I: Abduction proposes hypotheses that need further testing.
Statement II: Abductive conclusions are guaranteed to be true.

  1. I true, II false
  2. Both false
  3. Both true
  4. I false, II true
Show answer and explanation

Answer: A. I true, II false

Abduction suggests, and testing confirms.

Report this question

13Assertion (A): Abductive reasoning can lead to a false conclusion even when the premises are true.
Reason (R): It selects the most plausible explanation, not the only possible one.

  1. Both true, but R is not the correct explanation
  2. A false, R true
  3. Both A and R true, and R is the correct explanation
  4. A true, R false
Show answer and explanation

Answer: C. Both A and R true, and R is the correct explanation

Plausible does not mean certain.

Report this question

14Which reasoning most directly generates new hypotheses for scientific testing?

  1. Deduction
  2. Syllogism
  3. Tautology
  4. Abduction
Show answer and explanation

Answer: D. Abduction

Abduction is the creative, hypothesis-forming step.

Report this question

15Occam's razor suggests that:

  1. All explanations are equal
  2. The explanation requiring the fewest assumptions is preferred
  3. The more complex explanation is better
  4. Authority decides truth
Show answer and explanation

Answer: B. The explanation requiring the fewest assumptions is preferred

Prefer simplicity among equally good explanations.

Report this question

16Inference to the best explanation is used mainly when:

  1. Several hypotheses could explain the evidence
  2. Premises guarantee the conclusion
  3. The sample is very large
  4. Two cases are analogous
Show answer and explanation

Answer: A. Several hypotheses could explain the evidence

Choose the best among competing explanations.

Report this question

17In Peirce's account of scientific inquiry, the usual order is:

  1. Induction, abduction, deduction
  2. Deduction, induction, abduction
  3. Abduction, deduction, induction
  4. Abduction, induction, deduction
Show answer and explanation

Answer: C. Abduction, deduction, induction

Guess a hypothesis, deduce its consequences, then test them by induction.

Report this question

18A person finds the door lock broken and valuables missing and infers a burglary. This inference is:

  1. Deductive and certain
  2. Mathematical
  3. Analogical and certain
  4. Abductive and plausible
Show answer and explanation

Answer: D. Abductive and plausible

Other causes remain possible, so the conclusion is plausible only.

Report this question

19A key limitation of abduction is that:

  1. It always yields certainty
  2. The best available explanation may still be false
  3. It requires no evidence
  4. It cannot generate hypotheses
Show answer and explanation

Answer: B. The best available explanation may still be false

The best of the available hypotheses may not include the true one.
