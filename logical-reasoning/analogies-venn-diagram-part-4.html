This set has 25 multiple-choice questions on Analogies; Venn Diagram from the UGC NET Paper 1 syllabus, unit 6, Logical Reasoning. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

25 practice questions with answers

1A Venn diagram of "All S is P" with Boolean interpretation:

  1. Does not assert that S has members
  2. Places X in S
  3. Shades P entirely
  4. Asserts that S has members
Show answer

Answer: A. Does not assert that S has members

Report this question

2A syllogism valid only under the Aristotelian (existential import) view is called:

  1. Unconditionally valid
  2. Fallacious by form
  3. Conditionally valid
  4. Unsound
Show answer

Answer: C. Conditionally valid

Report this question

3In a three-circle diagram for a syllogism, the circles represent:

  1. Three premises
  2. Major, minor and middle terms
  3. Three conclusions
  4. Three fallacies
Show answer

Answer: B. Major, minor and middle terms

Report this question

4The middle term appears in:

  1. Major premise only
  2. Conclusion only
  3. Minor premise only
  4. Both premises but not in the conclusion
Show answer

Answer: D. Both premises but not in the conclusion

Report this question

5If a syllogism has one universal and one particular premise, we:

  1. Diagram the universal premise first
  2. Diagram the particular premise first
  3. Diagram neither
  4. Diagram only the conclusion
Show answer

Answer: A. Diagram the universal premise first

6Euler diagrams differ from Venn diagrams in that Euler diagrams:

  1. Use shading only
  2. Are not diagrams
  3. Show only actual relationships, not all possible regions
  4. Use three circles only
