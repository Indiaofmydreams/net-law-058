25 practice questions with answers

1Annambhatta classifies anumana according to the nature of vyapti into how many kinds?

  1. Two
  2. Three
  3. Five
  4. Four
Show answer

Answer: B. Three

Report this question

2A kevalanvayi inference lacks:

  1. Hetu
  2. Paksha
  3. Sapaksha
  4. Vipaksha
Show answer

Answer: D. Vipaksha

Report this question

3In a kevalanvayi inference, the sadhya is:

  1. Present everywhere (universal)
  2. Present nowhere
  3. Present only in the paksha
  4. Absent in the paksha
Show answer

Answer: A. Present everywhere (universal)

Report this question

4A kevalavyatireki inference lacks:

  1. Hetu
  2. Paksha
  3. A positive example (sapaksha)
  4. Vipaksha
Show answer

Answer: C. A positive example (sapaksha)

Report this question

5The vyapti in a kevalavyatireki inference is:

  1. Positive only
  2. Both positive and negative
  3. Absent
  4. Negative only
Show answer

Answer: D. Negative only

Report this question

6Which of the following is an anvayavyatireki inference?

  1. All things are knowable
  2. The hill has fire because it has smoke
  3. The pot is nameable because it is knowable
  4. Earth differs from other elements because it has smell
Show answer

Answer: B. The hill has fire because it has smoke

Report this question

7The five lingas listed in the Vaisheshika Sutra do NOT include:

  1. Paksha
  2. Samyogi
  3. Karana
  4. Karya
Show answer

Answer: A. Paksha

Report this question

8Prashastapada divides anumana into:

  1. Purvavat and Sheshavat
  2. Vita and Avita
  3. Drishta and Samanyatodrishta
  4. Svartha and Parartha
Show answer

Answer: C. Drishta and Samanyatodrishta

Report this question

9The Samkhya Karika describes anumana as:

  1. Fourfold
  2. Threefold
  3. Not a pramana
  4. Twofold
Show answer

Answer: B. Threefold

Report this question

10In Buddhist logic, the division of inference into svartha and parartha is associated with:

  1. Kanada
  2. Gautama
  3. Jaimini
  4. Dignaga
Show answer

Answer: D. Dignaga

Report this question

11Dignaga's Hetucakra (wheel of reasons) has how many cases, of which only two are valid?

  1. Nine
  2. Twelve
  3. Five
  4. Three
Show answer

Answer: A. Nine

Report this question

12The single mark of a valid hetu according to Jain logicians is:

  1. Pakshadharmata
  2. Trairupya
  3. Anyathanupapannatva
  4. Tadatmya
Show answer

Answer: C. Anyathanupapannatva

Report this question

13Which of the following is NOT a kind of inference in Nyaya?

  1. Sheshavat
  2. Upamana
  3. Samanyatodrishta
  4. Purvavat
Show answer

Answer: B. Upamana

Report this question

14In "Sound is non-eternal because it is produced, like a pot," the pot is the:

  1. Paksha
  2. Hetu
  3. Sadhya
  4. Drishtanta
Show answer

Answer: D. Drishtanta

Report this question

15In the same inference, the sadhya is:

  1. Non-eternality
  2. Being produced
  3. Pot
  4. Sound
Show answer

Answer: A. Non-eternality

Report this question

16Svartha anumana is:

  1. Inference by analogy
  2. Inference from testimony
  3. Inference for oneself, needing no formal statement
  4. Inference for others, stated formally
Show answer

Answer: C. Inference for oneself, needing no formal statement

Report this question

17Parartha anumana is formulated mainly for:

  1. Defining pramana
  2. Convincing or instructing others
  3. One's own understanding
  4. Removing doubt in dreams
Show answer

Answer: B. Convincing or instructing others

Report this question

18The Tarkasamgraha defines vyapti as:

  1. Sannidhi (proximity)
  2. Akanksha (expectancy)
  3. Sadrishya (similarity)
  4. Sahacharya-niyama (invariable co-presence)
Show answer

Answer: D. Sahacharya-niyama (invariable co-presence)

Report this question

19In "smoke is pervaded by fire," the vyapya is:

  1. Smoke
  2. Kitchen
  3. Fire
  4. Hill
Show answer

Answer: A. Smoke

Report this question

20In the same statement, the vyapaka is:

  1. Smoke
  2. Hill
  3. Fire
  4. Lake
Show answer

Answer: C. Fire

Report this question

21Which pair is an example of samavyapti (equal extension)?

  1. Smoke and fire
  2. Cow and animal
  3. Fire and heat-producing wet fuel
  4. Abhidheyatva (nameability) and prameyatva (knowability)
Show answer

Answer: D. Abhidheyatva (nameability) and prameyatva (knowability)

Report this question

22In vishamavyapti, the vyapti holds:

  1. In both directions
  2. In one direction only
  3. Only in dreams
  4. In neither direction
Show answer

Answer: B. In one direction only

Report this question

23Inferring smoke from fire is invalid because:

  1. Fire is not always accompanied by smoke (wet fuel being an upadhi)
  2. Fire is absent in the kitchen
  3. Fire is eternal
  4. Smoke is not perceived
Show answer

Answer: A. Fire is not always accompanied by smoke (wet fuel being an upadhi)

Report this question

24"Wherever there is smoke, there is fire" is a statement of:

  1. Upadhi
  2. Vyatireka-vyapti
  3. Anvaya-vyapti
  4. Paramarsha
Show answer

Answer: C. Anvaya-vyapti

Report this question

25"Where there is no fire, there is no smoke" is a statement of:

  1. Pratijna
  2. Vyatireka-vyapti
  3. Anvaya-vyapti
  4. Nigamana
Show answer

Answer: B. Vyatireka-vyapti
