This set has 25 multiple-choice questions on Understanding the Structure of Arguments; Deductive and Inductive Reasoning from the UGC NET Paper 1 syllabus, unit 6, Logical Reasoning. 25 practice questions with answers

1An argument consists of:

  1. Only a conclusion
  2. Questions and answers
  3. Premises and a conclusion
  4. Only premises
Show answer

Answer: C. Premises and a conclusion

Report this question

2In an argument, the statement claimed to follow from the others is called the:

  1. Corollary
  2. Assumption
  3. Premise
  4. Conclusion
Show answer

Answer: D. Conclusion

Report this question

3Words such as "therefore", "hence" and "thus" are:

  1. Quantifiers
  2. Conclusion indicators
  3. Premise indicators
  4. Fallacy indicators
Show answer

Answer: B. Conclusion indicators

Report this question

4Words such as "because", "since" and "for" are:

  1. Premise indicators
  2. Copulas
  3. Connectives of disjunction
  4. Conclusion indicators
Show answer

Answer: A. Premise indicators

Report this question

5Which of the following is NOT an argument?

  1. All birds fly; sparrow is a bird; so sparrow flies
  2. Since it rained, the road is wet
  3. Close the door.
  4. Ram is tall, so he is taller than Shyam
Show answer

Answer: C. Close the door.

Report this question

6A statement is a sentence that is:

  1. A question
  2. A command
  3. An exclamation
  4. Either true or false
Show answer

Answer: D. Either true or false

Report this question

7The truth or falsity of a proposition is called its:

  1. Soundness
  2. Truth value
  3. Strength
  4. Validity
Show answer

Answer: B. Truth value

Report this question

8Validity is a property of:

  1. Arguments
  2. Words
  3. Terms
  4. Propositions
Show answer

Answer: A. Arguments

Report this question

9Truth and falsity are properties of:

  1. Inferences
  2. Arguments
  3. Propositions
  4. Syllogisms
Show answer

Answer: C. Propositions

Report this question

10A deductive argument is one in which the conclusion:

  1. Is always false
  2. Necessarily follows from the premises
  3. Goes beyond the premises
  4. Is probable
Show answer

Answer: B. Necessarily follows from the premises

Report this question

11In a valid deductive argument, if the premises are true, the conclusion:

  1. Is probable
  2. Is irrelevant
  3. May be false
  4. Must be true
Show answer

Answer: D. Must be true

Report this question

12An inductive argument claims that its conclusion is:

  1. Probable
  2. Self-contradictory
  3. Certain
  4. Necessarily true
Show answer

Answer: A. Probable

Report this question

13Inductive arguments are evaluated as:

  1. Valid or invalid
  2. True or false
  3. Strong or weak
  4. Sound or unsound
Show answer

Answer: C. Strong or weak

Report this question

14Deductive arguments are evaluated as:

  1. Probable or improbable
  2. Valid or invalid
  3. Strong or weak
  4. Cogent or uncogent
Show answer

Answer: B. Valid or invalid

Report this question

15A sound argument is one that is:

  1. Strong with false premises
  2. Valid with at least one false premise
  3. Invalid with true premises
  4. Valid with all true premises
Show answer

Answer: D. Valid with all true premises

Report this question

16Can a valid argument have a false conclusion?

  1. Yes, if at least one premise is false
  2. Only in induction
  3. No, never
  4. Yes, if all premises are true
Show answer

Answer: A. Yes, if at least one premise is false

Report this question

17An argument with true premises and a false conclusion is:

  1. Valid
  2. Sound
  3. Invalid
  4. Cogent
Show answer

Answer: C. Invalid

Report this question

18Reasoning from particular instances to a general conclusion is:

  1. Deduction
  2. Induction
  3. Syllogism
  4. Dilemma
Show answer

Answer: B. Induction

Report this question

19Reasoning from a general principle to a particular conclusion is typically:

  1. Analogy
  2. Induction
  3. Abduction
  4. Deduction
Show answer

Answer: D. Deduction

Report this question

20Adding new premises to a valid deductive argument:

  1. Cannot make it invalid
  2. Makes it unsound
  3. Makes it inductive
  4. Can make it invalid
Show answer

Answer: A. Cannot make it invalid

Report this question

21Adding new premises to an inductive argument:

  1. Never changes its strength
  2. Makes it valid
  3. Can strengthen or weaken it
  4. Makes it deductive
Show answer

Answer: C. Can strengthen or weaken it

Report this question

22Which is an inductive argument?

  1. No A is B; all C is A; so no C is B
  2. All men are mortal; Socrates is a man; so Socrates is mortal
  3. If P then Q; P; so Q
  4. The sun has risen every day so far; so it will rise tomorrow
Show answer

Answer: D. The sun has risen every day so far; so it will rise tomorrow

Report this question

23Which is a deductive argument?

  1. It rained yesterday; so it will rain tomorrow
  2. All mammals are warm-blooded; whales are mammals; so whales are warm-blooded
  3. Most swans seen are white; so all swans are white
  4. Ram's cat is black; so all cats are black
Show answer

Answer: B. All mammals are warm-blooded; whales are mammals; so whales are warm-blooded

Report this question

24A categorical proposition relates:

  1. Two classes
  2. Two propositions
  3. Two arguments
  4. Two numbers
Show answer

Answer: A. Two classes

25The four standard-form categorical propositions are:

  1. P, Q, R, S
  2. A, B, C, D
  3. A, E, I, O
  4. S, M, P, Q
