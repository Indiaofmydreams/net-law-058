About this question set

This set has 25 multiple-choice questions on Pramanas: Pratyaksha, Anumana, Upamana, Shabda, Arthapatti and Anupalabdhi from the UGC NET Paper 1 syllabus, unit 6, Logical Reasoning. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

25 practice questions with answers

1Vedanta Paribhasha was written by:

  1. Madhva
  2. Dharmaraja Adhvarindra
  3. Shankaracharya
  4. Ramanuja
Show answer

Answer: B. Dharmaraja Adhvarindra

Report this question

2According to the Nyaya Sutra, anumana is "tatpurvaka", i.e., preceded by:

  1. Shabda
  2. Upamana
  3. Arthapatti
  4. Pratyaksha
Show answer

Answer: D. Pratyaksha

Report this question

3"Where there is no fire, there is no smoke" is an example of:

  1. Vyatireka-vyapti
  2. Anvaya-vyapti
  3. Pratijna
  4. Upadhi
Show answer

Answer: A. Vyatireka-vyapti

Report this question

4"Wherever there is smoke there is fire" is a vyapti of unequal extension, called:

  1. Samavyapti
  2. Upadhi
  3. Vishamavyapti
  4. Hetvabhasa
Show answer

Answer: C. Vishamavyapti

Report this question

5In the inference "the hill has smoke because it has fire," the upadhi is:

  1. The hill
  2. Kitchen
  3. Dry grass
  4. Wet fuel
Show answer

Answer: D. Wet fuel

Report this question

6In Nyaya, doubt about an exception to a vyapti is removed by:

  1. Jalpa
  2. Tarka
  3. Chala
  4. Vitanda
Show answer

Answer: B. Tarka

Report this question

7"Bhuyodarshana" in the context of vyapti means:

  1. Repeated observation of co-presence
  2. Dream cognition
  3. Observation of absence
  4. A single observation
Show answer

Answer: A. Repeated observation of co-presence

Report this question

8Buddhist logicians ground vyapti in:

  1. Akanksha and Yogyata
  2. Svatah and Paratah
  3. Tadatmya and Tadutpatti
  4. Samyoga and Samavaya
Show answer

Answer: C. Tadatmya and Tadutpatti

Report this question

9The trairupya (three characteristics) of a valid hetu in Buddhist logic are:

  1. Akanksha, Yogyata, Sannidhi
  2. Pratijna, Hetu, Udaharana
  3. Samyoga, Samavaya, Visheshana
  4. Pakshadharmata, Sapakshasattva, Vipakshavyavritti
Show answer

Answer: D. Pakshadharmata, Sapakshasattva, Vipakshavyavritti

Report this question

10"Abadhitavishayatva" as a condition of a valid hetu means:

  1. Presence in the paksha
  2. The sadhya is not contradicted by a stronger pramana
  3. Absence from the vipaksha
  4. Presence in the sapaksha
Show answer

Answer: B. The sadhya is not contradicted by a stronger pramana

Report this question

11"Asatpratipakshatva" as a condition of a valid hetu means:

  1. Absence of a counter-hetu of equal strength
  2. Presence in the vipaksha
  3. Absence of the hetu in the paksha
  4. Absence of the sadhya
Show answer

Answer: A. Absence of a counter-hetu of equal strength

Report this question

12Dignaga's three fallacious reasons (hetvabhasa) are:

  1. Sadharana, Asadharana, Anupasamhari
  2. Savyabhichara, Satpratipaksha, Badhita
  3. Asiddha, Viruddha, Anaikantika
  4. Pratijna, Hetu, Udaharana
Show answer

Answer: C. Asiddha, Viruddha, Anaikantika

Report this question

13In Gautama's list of hetvabhasas, "Sadhyasama" corresponds to:

  1. Badhita
  2. Asiddha
  3. Satpratipaksha
  4. Viruddha
Show answer

Answer: B. Asiddha

Report this question

14"Prakaranasama" is another name for:

  1. Badhita
  2. Viruddha
  3. Asiddha
  4. Satpratipaksha
Show answer

Answer: D. Satpratipaksha

Report this question

15"Kalatita" (kalatyayapadishta) is another name for:

  1. Badhita
  2. Savyabhichara
  3. Asiddha
  4. Viruddha
Show answer

Answer: A. Badhita

Report this question

16The anupasamhari hetu is one that:

  1. Is present in both sapaksha and vipaksha
  2. Proves the opposite of the sadhya
  3. Has no sapaksha or vipaksha because the paksha includes everything
  4. Is absent in the paksha
Show answer

Answer: C. Has no sapaksha or vipaksha because the paksha includes everything

Report this question

17"Sound is non-eternal because it is visible" is an example of:

  1. Satpratipaksha
  2. Svarupasiddha
  3. Viruddha
  4. Badhita
Show answer

Answer: B. Svarupasiddha

Report this question

18Inferring smoke on a hill from the presence of fire commits the fallacy of:

  1. Asadharana
  2. Svarupasiddha
  3. Ashrayasiddha
  4. Vyapyatvasiddha
Show answer

Answer: D. Vyapyatvasiddha

Report this question

19Charvakas reject anumana as a pramana because:

  1. Vyapti cannot be established with certainty
  2. Hetu is never present
  3. Sadhya is always absent
  4. Paksha cannot be known
Show answer

Answer: A. Vyapti cannot be established with certainty

Report this question

20The text traditionally associated with the Charvaka school is:

  1. Nyaya Sutra
  2. Yoga Sutra
  3. Brihaspati Sutra
  4. Brahma Sutra
Show answer

Answer: C. Brihaspati Sutra

Report this question

21"This pot is nameable because it is knowable" is a standard example of:

  1. Svartha anumana
  2. Kevalanvayi anumana
  3. Kevalavyatireki anumana
  4. Anvayavyatireki anumana
Show answer

Answer: B. Kevalanvayi anumana

Report this question

22"Earth differs from other elements because it has smell" is a standard example of:

  1. Kevalanvayi anumana
  2. Parartha anumana
  3. Anvayavyatireki anumana
  4. Kevalavyatireki anumana
Show answer

Answer: D. Kevalavyatireki anumana

Report this question

23The Nyaya five-membered syllogism is considered to combine:

  1. Both deductive and inductive elements
  2. Only induction
  3. Neither deduction nor induction
  4. Only deduction
Show answer

Answer: A. Both deductive and inductive elements

Report this question

24The function of Nigamana in the five-membered syllogism is to:

  1. Give the example
  2. Give the reason
  3. Draw and establish the conclusion
  4. State the thesis
Show answer

Answer: C. Draw and establish the conclusion

25The Vaisheshika Sutra was composed by:

  1. Badarayana
