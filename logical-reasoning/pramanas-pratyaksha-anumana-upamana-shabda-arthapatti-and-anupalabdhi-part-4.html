About this question set

This set has 25 multiple-choice questions on Pramanas: Pratyaksha, Anumana, Upamana, Shabda, Arthapatti and Anupalabdhi from the UGC NET Paper 1 syllabus, unit 6, Logical Reasoning. 25 practice questions with answers

1"Gangayam ghoshah" ("the hamlet is on the Ganga") is an example of:

  1. Lakshana, the indicative meaning
  2. Abhidha, the primary meaning
  3. Akanksha
  4. Vyanjana, the suggested meaning
Show answer

Answer: A. Lakshana, the indicative meaning

Report this question

2The three powers (vrittis) of a word are:

  1. Drishta, Adrishta, Shruta
  2. Pratijna, Hetu, Udaharana
  3. Abhidha, Lakshana, Vyanjana
  4. Akanksha, Yogyata, Sannidhi
Show answer

Answer: C. Abhidha, Lakshana, Vyanjana

Report this question

3"Tatparya" in the theory of verbal knowledge refers to:

  1. Mutual expectancy of words
  2. The speaker's intention or purport
  3. Compatibility of meaning
  4. Proximity of words
Show answer

Answer: B. The speaker's intention or purport

Report this question

4The number of lingas (marks) used in Mimamsa and Vedanta to determine the purport of a text is:

  1. Five
  2. Three
  3. Four
  4. Six
Show answer

Answer: D. Six

Report this question

5Abhihitanvayavada, the theory that words first convey their own meanings and then these are related, is associated with:

  1. Bhatta Mimamsa
  2. Buddhism
  3. Prabhakara
  4. Nyaya-Vaisheshika only
Show answer

Answer: A. Bhatta Mimamsa

Report this question

6Anvitabhidhanavada, the theory that words denote meanings already related to one another, is associated with:

  1. Samkhya
  2. Charvaka
  3. Prabhakara Mimamsa
  4. Bhatta Mimamsa
Show answer

Answer: C. Prabhakara Mimamsa

Report this question

7The principle underlying arthapatti is:

  1. Vyapti
  2. Sadrishya
  3. Akanksha
  4. Anyathanupapatti (otherwise inexplicability)
Show answer

Answer: D. Anyathanupapatti (otherwise inexplicability)

Report this question

8Shrutarthapatti is postulation based on:

  1. A perceived fact
  2. A heard (scriptural or verbal) statement
  3. An absence
  4. A similarity
Show answer

Answer: B. A heard (scriptural or verbal) statement

Report this question

9Which of the following accepts arthapatti as an independent pramana?

  1. Prabhakara Mimamsa
  2. Vaisheshika
  3. Buddhism
  4. Charvaka
Show answer

Answer: A. Prabhakara Mimamsa

Report this question

10Unlike anumana, arthapatti rests on:

  1. Vyapti
  2. Pakshadharmata
  3. Inconsistency of a known fact unless something is assumed
  4. Hetvabhasa
Show answer

Answer: C. Inconsistency of a known fact unless something is assumed

Report this question

11In the example of fat Devadatta who does not eat by day, "being fat while not eating by day" is the:

  1. Paksha
  2. Upapadya (fact to be explained)
  3. Sapaksha
  4. Upapadaka (the postulate)
Show answer

Answer: B. Upapadya (fact to be explained)

Report this question

12Mimamsakas postulate "apurva" to explain how a sacrifice yields its result later. This is an example of:

  1. Pratyaksha
  2. Anupalabdhi
  3. Upamana
  4. Arthapatti
Show answer

Answer: D. Arthapatti

Report this question

13Kumarila Bhatta treats anupalabdhi as the pramana for knowing:

  1. Abhava (non-existence)
  2. Similarity
  3. Vyapti
  4. Verbal meaning
Show answer

Answer: A. Abhava (non-existence)

Report this question

14The Prabhakara Mimamsa explains the knowledge of absence as:

  1. Verbal testimony
  2. A separate pramana
  3. Mere perception of the locus
  4. Inference
Show answer

Answer: C. Mere perception of the locus

Report this question

15Dharmakirti's three types of reasons (hetu) are:

  1. Pratyaksha, Anumana, Shabda
  2. Svabhava, Karya, Anupalabdhi
  3. Paksha, Sapaksha, Vipaksha
  4. Purvavat, Sheshavat, Samanyatodrishta
Show answer

Answer: B. Svabhava, Karya, Anupalabdhi

Report this question

16"Yogya anupalabdhi" means:

  1. Non-perception of an imperceptible object
  2. Perception of an absent object
  3. Non-perception of a past event
  4. Non-perception of what would be perceived if it were present
Show answer

Answer: D. Non-perception of what would be perceived if it were present

Report this question

17"The horn of a hare does not exist" illustrates:

  1. Atyantabhava
  2. Anyonyabhava
  3. Pragabhava
  4. Pradhvamsabhava
Show answer

Answer: A. Atyantabhava

18"A pot is not a cloth" illustrates:

  1. Atyantabhava
  2. Pradhvamsabhava
  3. Anyonyabhava
  4. Pragabhava
Show answer

Answer: C. Anyonyabhava

Report this question

19The non-existence of a pot after it is broken is:

  1. Anyonyabhava
  2. Pragabhava
  3. Atyantabhava
  4. Pradhvamsabhava

Answer: D. Pradhvamsabhava

Report this question

20In the Nyaya Sutra, "vada" is:

  1. Deceitful argument
  2. Honest discussion aimed at ascertaining truth
  3. Wrangling to win by any means
  4. Cavilling without establishing a counter-thesis
Show answer

Answer: B. Honest discussion aimed at ascertaining truth

Report this question

21In the Nyaya Sutra, "vitanda" is:

  1. Cavilling that merely attacks the opponent's thesis without establishing one's own
  2. Inference for oneself
  3. Discussion for truth
  4. Teaching by a reliable person
Show answer

Answer: A. Cavilling that merely attacks the opponent's thesis without establishing one's own

Report this question

22The Nyaya Sutra enumerates how many padarthas (categories of discussion)?

  1. Six
  2. Twelve
  3. Sixteen
  4. Seven
Show answer

Answer: C. Sixteen

23The number of prameyas (objects of valid knowledge) listed in the Nyaya Sutra is:

  1. Six
  2. Sixteen
  3. Seven
  4. Twelve
Show answer

Answer: D. Twelve

24According to Mimamsa, the validity (pramanya) of knowledge is:

  1. Neither svatah nor paratah
  2. Svatah (self-evident)
  3. Paratah
  4. Known only by inference
Show answer

Answer: B. Svatah (self-evident)

25The theory that the shell-silver illusion is "anirvachaniya" (indescribable as real or unreal) belongs to:

  1. Advaita Vedanta

  4. Nyaya
