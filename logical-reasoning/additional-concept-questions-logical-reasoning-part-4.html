25 practice questions with answers

1A conditional "If P then Q" is false:

  1. When P is true and Q is false
  2. When both are true
  3. When both are false
  4. When P is false and Q is true
Show answer

Answer: A. When P is true and Q is false

Report this question

2A statement that is true under all possible truth-values is a:

  1. Fallacy
  2. Contingent statement
  3. Tautology
  4. Contradiction
Show answer

Answer: C. Tautology

Report this question

3A statement that is false under all possible truth-values is a:

  1. Valid argument
  2. Contingent statement
  3. Tautology
  4. Self-contradiction
Show answer

Answer: D. Self-contradiction

Report this question

4By De Morgan's law, "not (P and Q)" is equivalent to:

  1. Not P and not Q
  2. Not P or not Q
  3. P or Q
  4. If P then Q
Show answer

Answer: B. Not P or not Q

Report this question

5Mill's Method of Agreement holds that the circumstance common to all instances of a phenomenon is probably its:

  1. Cause
  2. Residue
  3. Variation
  4. Effect
Show answer

Answer: A. Cause

6Mill's Method of Difference compares instances in which a phenomenon:

  1. Varies in degree
  2. Occurs in all cases
  3. Occurs and does not occur, other circumstances being the same
  4. Never occurs
Show answer

Answer: C. Occurs and does not occur, other circumstances being the same

Report this question

7Combining the methods of agreement and difference gives the:

  1. Method of Concomitant Variation
  2. Joint Method
  3. Method of Residues
  4. Method of Analogy

Answer: B. Joint Method

8Subtracting from a phenomenon the part known to be caused by earlier antecedents, to find the cause of the remainder, is the:

  1. Method of Agreement

  4. Method of Residues
