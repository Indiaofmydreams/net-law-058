25 practice questions with answers

1An analogy is an argument based on:

  1. Contradiction between things
  2. A universal law
  3. Similarity between two or more things
  4. Authority of a speaker
Show answer

Answer: C. Similarity between two or more things

Report this question

2Argument from analogy is a type of:

  1. Deductive reasoning
  2. Categorical syllogism
  3. Formal fallacy
  4. Inductive reasoning
Show answer

Answer: D. Inductive reasoning

Report this question

3In an argument from analogy, the conclusion is:

  1. Necessarily true
  2. Probable
  3. Certain
  4. Self-evident
Show answer

Answer: B. Probable

Report this question

4An argument from analogy is evaluated as:

  1. Strong or weak
  2. Distributed or undistributed
  3. Sound or unsound
  4. Valid or invalid
Show answer

Answer: A. Strong or weak

Report this question

5The argument "Earth has life; Mars is similar to Earth in many ways; so Mars probably has life" is:

  1. A deductive syllogism
  2. A dilemma
  3. An argument from analogy
  4. A disjunctive syllogism
Show answer

Answer: C. An argument from analogy

Report this question

6An analogical argument is strengthened when the number of relevant similarities:

  1. Remains zero
  2. Increases
  3. Decreases
  4. Is irrelevant
Show answer

Answer: B. Increases

Report this question

7An analogical argument is weakened by:

  1. More examples of similarity
  2. Greater relevance of shared properties
  3. Relevant similarities
  4. Relevant dissimilarities
Show answer

Answer: D. Relevant dissimilarities

Report this question

8A "false analogy" arises when:

  1. The similarities are superficial or irrelevant
  2. The conclusion is certain
  3. The similarities are relevant and many
  4. The premises are true
Show answer

Answer: A. The similarities are superficial or irrelevant

Report this question

9Which strengthens an argument from analogy?

  1. Reducing the number of cases compared
  2. Discovering a relevant difference
  3. Discovering an additional relevant similarity
  4. Choosing irrelevant properties
Show answer

Answer: C. Discovering an additional relevant similarity
