About this question set

This set has 25 multiple-choice questions on Pramanas: Pratyaksha, Anumana, Upamana, Shabda, Arthapatti and Anupalabdhi from the UGC NET Paper 1 syllabus, unit 6, Logical Reasoning. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

25 practice questions with answers

1In the Nyaya Sutra definition of pratyaksha, "avyapadeshya" means:

  1. Erroneous
  2. Inferential
  3. Not dependent on verbal designation
  4. Doubtful
Show answer

Answer: C. Not dependent on verbal designation

Report this question

2"Vyavasayatmaka" in the definition of pratyaksha means:

  1. Doubtful
  2. Determinate or definite
  3. Verbal
  4. Remembered
Show answer

Answer: B. Determinate or definite

Report this question

3The term "avyabhicari" in the definition of pratyaksha excludes:

  1. Memory
  2. Inference
  3. Valid cognition
  4. Erroneous cognition such as a mirage
Show answer

Answer: D. Erroneous cognition such as a mirage

Report this question

4Dignaga defines pratyaksha as:

  1. Kalpanapodha (free from conceptual construction)
  2. Yogaja
  3. Avyabhicari
  4. Vyavasayatmaka
Show answer

Answer: A. Kalpanapodha (free from conceptual construction)

Report this question

5Which qualifier did Dharmakirti add to Dignaga's definition of pratyaksha?

  1. Savikalpaka
  2. Sannidhi
  3. Abhranta (non-erroneous)
  4. Apta
Show answer

Answer: C. Abhranta (non-erroneous)

Report this question

6Nyayabindu was written by:

  1. Nagarjuna
  2. Dharmakirti
  3. Dignaga
  4. Vasubandhu

Answer: B. Dharmakirti

7Pramanasamuccaya was written by:

  1. Dharmakirti

  3. Vasubandhu

8For Buddhist logicians, the object of pratyaksha is:

  1. Svalakshana
  2. Jati
  3. Abhava
  4. Samanyalakshana
Show answer

9For Buddhist logicians, the object of anumana is:

  1. Paramanu
  2. Svalakshana
  3. Samanyalakshana
  4. Kshanika
Show answer

Answer: C. Samanyalakshana

Report this question

10Samkhya defines pratyaksha as the ascertainment of:

  1. Scriptural meaning
  2. Each object through its contact with the senses
  3. Universals only
  4. Absence

Answer: B. Each object through its contact with the senses

11Which school regards only nirvikalpaka pratyaksha as a valid pramana?

  1. Advaita
  2. Mimamsa
  3. Nyaya
  4. Buddhism

  1. Manas
  2. Chakshus
  3. Shrotra
  4. Tvak

  1. Water
  2. Fire
  3. Earth
  4. Ether

14According to Nyaya, the organ of hearing (shrotra) is constituted of:

  1. Fire
  2. Air
  3. Water
  4. Akasha

Answer: D. Akasha

15In Samkhya, the sense organs are derived from:

  1. Elements
  2. Ahamkara

  4. Purusha

16The number of alaukika (extraordinary) sannikarshas in Nyaya is:

  1. Three
  2. Four
  3. Six
  4. Two

17The two types of yogaja pratyaksha are:

  1. Savikalpaka and Nirvikalpaka
  2. Svartha and Parartha
  3. Yukta and Yunjana
  4. Laukika and Alaukika
Show answer

Answer: C. Yukta and Yunjana

18"Anuvyavasaya" refers to:

  1. Verbal testimony
  2. Inference of fire
  3. Doubt
  4. Introspective cognition of a cognition ("I know that I know the pot")

19In Jainism, which are classified as pratyaksha (direct) knowledge?

  1. Mati and Shruta
  2. Avadhi, Manahparyaya and Kevala
  3. Anumana and Agama
  4. Smriti and Tarka
Show answer

Answer: B. Avadhi, Manahparyaya and Kevala

20The number of forms of paroksha knowledge in Jainism is:

  1. Five
  2. Six
  3. Three
  4. Two
Show answer

Answer: A. Five

21Which of the following is NOT a form of paroksha knowledge in Jainism?

  1. Smriti
  2. Agama
  3. Avadhi
  4. Tarka
Show answer

22According to Tarkasamgraha, prama is:

  1. Viparyaya
  2. Samshaya
  3. Smriti
  4. Yathartha anubhava (right experience)
Show answer

Answer: D. Yathartha anubhava (right experience)

Report this question

23Tarkasamgraha divides cognition (buddhi) into:

  1. Laukika and Alaukika
  2. Smriti and Anubhava
  3. Prama and Pramana
  4. Vaidika and Laukika
Show answer

Answer: B. Smriti and Anubhava

Report this question

24According to Tarkasamgraha, ayathartha anubhava (erroneous experience) includes:

  1. Samshaya, Viparyaya and Tarka
  2. Pratyaksha, Anumana and Upamana
  3. Shabda and Arthapatti
  4. Smriti and Prama
Show answer

Answer: A. Samshaya, Viparyaya and Tarka

Report this question

25Smriti is not counted as a pramana in Nyaya mainly because it:

  1. Is always false
  2. Is produced by the senses
  3. Is a reproduction of an earlier experience rather than a fresh cognition
  4. Depends on verbal testimony

Answer: C. Is a reproduction of an earlier experience rather than a fresh cognition
