About this question set

This set has 15 multiple-choice questions on Communication from the UGC NET Paper 1 syllabus, unit 4, Communication. Try each question first, then tap Show answer to check the key and read the explanation. 15 of the 15 questions carry a written explanation.

For the concepts and case law behind these questions, read the Communication notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

15 practice questions with answers

1Kinesics is the study of:

  1. Time
  2. Body movements
  3. Space
  4. Touch only
Show answer and explanation

Answer: B. Body movements

Gestures and posture.

Report this question

2Proxemics deals with:

  1. Dress
  2. Voice tone
  3. Use of space and distance
  4. Time
Show answer and explanation

Answer: C. Use of space and distance

Personal space.

Report this question

3Which is an example of mass media?

  1. Letter
  2. Television
  3. Face-to-face talk
  4. Phone call
Show answer and explanation

Answer: B. Television

Reaches large audiences.

Report this question

4'Encoding' is done by the:

  1. Observer
  2. Receiver
  3. Sender
  4. Channel
Show answer and explanation

Answer: C. Sender

The sender converts ideas into a message.

Report this question

5'Decoding' is done by the:

  1. Receiver
  2. Printer
  3. Editor
  4. Sender
Show answer and explanation

Answer: A. Receiver

The receiver interprets the message.

Report this question

6McLuhan's famous phrase says 'The medium is the:'

  1. Noise
  2. Message
  3. Feedback
  4. Channel
Show answer and explanation

Answer: B. Message

Marshall McLuhan, 1964.

Report this question

7Public opinion is significantly shaped by:

  1. Only school
  2. Only family
  3. Only law
  4. Mass media
Show answer and explanation

Answer: D. Mass media

Media influence is wide.

8Which is a formal channel of communication?

  1. Gossip
  2. Grapevine
  3. Rumour
  4. Official memo
Show answer and explanation

Answer: D. Official memo

Follows organisational hierarchy.

Report this question

9Effective listening requires:

  1. Distraction
  2. Interruptions
  3. Attention and feedback
  4. Assumptions
Show answer and explanation

Answer: C. Attention and feedback

Active listening.

10Match: A Kinesics, B Proxemics, C Chronemics with (1) Body movement (2) Space (3) Time

  1. A-2, B-1, C-3
  2. A-1, B-2, C-3
  3. A-3, B-2, C-1
  4. A-1, B-3, C-2
Show answer and explanation

Answer: B. A-1, B-2, C-3

Branches of non-verbal communication.

11Consider the statements: 1. Communication is a one-way process only. 2. Feedback makes communication two-way.

  1. Only statement 1 is correct
  2. Only statement 2 is correct
  3. Both statements are correct
  4. Neither statement is correct
Show answer and explanation

Answer: B. Only statement 2 is correct

Feedback creates two-way flow.

12Consider the statements: 1. Group communication involves more than two people. 2. Intercultural communication requires cultural sensitivity.

  3. Both statements are correct
  4. Neither statement is correct
