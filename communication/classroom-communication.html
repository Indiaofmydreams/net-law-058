About this question set

This set has 20 multiple-choice questions on Classroom Communication from the UGC NET Paper 1 syllabus, unit 4, Communication. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Communication notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

20 practice questions with answers

1A lecture with no student response is an example of which interaction pattern?

  1. Two-way
  2. One-way
  3. Multi-way
  4. Circular
Show answer

Answer: B. One-way

Report this question

2A teacher asking a question, a student answering and the teacher reacting is:

  1. One-way
  2. Circular
  3. Two-way
  4. Multi-way
Show answer

Answer: C. Two-way

Report this question

3Group work where students interact with each other and with the teacher is:

  1. Multi-way
  2. One-way
  3. Two-way
  4. Linear

Answer: A. Multi-way
