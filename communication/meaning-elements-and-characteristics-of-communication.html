About this question set

This set has 14 multiple-choice questions on Meaning, Elements and Characteristics of Communication from the UGC NET Paper 1 syllabus, unit 4, Communication. 14 practice questions with answers

1The word "communication" comes from the Latin word "communis", which means:

  1. Common
  2. To speak
  3. To send
  4. To listen
Show answer

Answer: A. Common

Report this question

2"Communication is the process of passing information and understanding from one person to another." This definition is given by:

  1. Harold Lasswell
  2. Keith Davis
  3. David Berlo
  4. Aristotle
Show answer

Answer: B. Keith Davis

Report this question

3Communication is best described as:

  1. Only speaking
  2. Process of sharing information, ideas and feelings
  3. One-way transmission of orders
  4. Only mass media
Show answer

Answer: B. Process of sharing information, ideas and feelings

Report this question

4Which of the following is NOT an element of communication?

  1. Sender
  2. Receiver
  3. Feedback
  4. Syllabus
Show answer

Answer: D. Syllabus

Report this question

5Converting a message into symbols or code is called:

  1. Encoding
  2. Decoding
  3. Feedback
  4. Noise
Show answer

Answer: A. Encoding

Report this question

6The process of interpreting a received message is done by the:

  1. Sender
  2. Channel
  3. Receiver
  4. Noise source
Show answer

Answer: C. Receiver

Report this question

7Any disturbance that interferes with the message in the communication process is called:

  1. Noise
  2. Feedback
  3. Context
  4. Channel
Show answer

Answer: A. Noise

Report this question

8Feedback in communication helps to:

  1. Remove the message
  2. Increase noise
  3. Know whether the message was understood
  4. Replace the channel
Show answer

Answer: C. Know whether the message was understood

Report this question

9The medium through which a message travels is called the:

  1. Code
  2. Receiver
  3. Source
  4. Channel
Show answer

Answer: D. Channel

Report this question

10The physical, social and cultural setting in which communication occurs is its:

  1. Noise
  2. Context
  3. Feedback
  4. Channel
Show answer

Answer: B. Context

Report this question

11"Communication is irreversible" means:

  1. A message cannot be taken back once communicated
  2. A message can always be deleted
  3. Only written messages are permanent
  4. The receiver cannot respond
Show answer

Answer: A. A message cannot be taken back once communicated

Report this question

12Which of the following is a characteristic of communication?

  1. It is static
  2. It is purposeful
  3. It is a one-time event
  4. It is free of context
Show answer

Answer: B. It is purposeful

Report this question

13Two-way communication differs from one-way communication because it involves:

  1. A sender
  2. A message
  3. Encoding
  4. Feedback
Show answer

Answer: D. Feedback

Report this question

14Who is regarded as the "father of communication studies"?

  1. Harold Lasswell
  2. Claude Shannon
  3. Wilbur Schramm
  4. David Berlo
Show answer

Answer: C. Wilbur Schramm
