About this question set

This set has 18 multiple-choice questions on Non-Verbal Communication from the UGC NET Paper 1 syllabus, unit 4, Communication. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Communication notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

1Edward Hall's "intimate" distance extends up to about:

  1. 4 feet
  2. 12 feet
  3. 25 feet
  4. 18 inches
Show answer

Answer: D. 18 inches

  1. Personal zone
  2. Intimate zone
  3. Public zone
  4. Social zone

  1. Intimate zone
