About this question set

This set has 10 multiple-choice questions on Barriers to Communication: General from the UGC NET Paper 1 syllabus, unit 4, Communication. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Communication notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

10 practice questions with answers

1Anything that prevents or distorts a message from reaching the receiver as intended is a:

  1. Channel
  2. Barrier to communication
  3. Feedback
  4. Code
Show answer

Answer: B. Barrier to communication

Report this question

2Barriers to communication can occur:

  1. Only at the sender's end
  2. Only at the receiver's end
  3. At any stage of the communication process
  4. Only in the channel
Show answer

Answer: C. At any stage of the communication process

Report this question

3Which of the following is NOT a category of communication barriers?

  1. Mathematical
  2. Physical
  3. Semantic
  4. Psychological
Show answer

Answer: A. Mathematical

Report this question

4The most common effect of communication barriers is:

  1. Faster decisions
  2. Better relationships
  3. Higher efficiency
  4. Misunderstanding and distortion of the message
Show answer

Answer: D. Misunderstanding and distortion of the message

Report this question

5Barriers arising from the surroundings in which communication takes place are:

  1. Semantic
  2. Physical or environmental
  3. Personal
  4. Organizational
Show answer

Answer: B. Physical or environmental

6Barriers related to the meaning of words and symbols are:

  1. Physical
  2. Technological
  3. Organizational
  4. Semantic or language
Show answer

Answer: D. Semantic or language

7Barriers arising from the emotional state of the sender or receiver are:

  1. Physical
  2. Technological
  3. Psychological
  4. Semantic

Answer: C. Psychological

8Barriers arising from cultural and status differences are:

  1. Socio-cultural
  2. Physical
  3. Semantic
  4. Technological

9Barriers arising from the structure and hierarchy of an institution are:

  1. Organizational
  2. Personal
  3. Physical
  4. Semantic
