About this question set

This set has 14 multiple-choice questions on Semantic or Language Barriers from the UGC NET Paper 1 syllabus, unit 4, Communication. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Communication notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

14 practice questions with answers

1Use of technical terms unfamiliar to the receiver is called:

  1. Feedback
  2. Jargon
  3. Redundancy
  4. Encoding
Show answer

Answer: B. Jargon

Report this question

2A doctor using medical terminology with a layperson illustrates a:

  1. Physical barrier
  2. Organizational barrier
  3. Technological barrier
  4. Semantic barrier due to jargon
Show answer

Answer: D. Semantic barrier due to jargon

Report this question

3The word "light" (not heavy / not dark) illustrates a barrier due to:

  1. Noise
  2. Different meanings of words
  3. Distance
  4. Hierarchy
Show answer

Answer: B. Different meanings of words

Report this question

4"Visiting relatives can be boring" is an example of:

  1. Jargon
  2. Time pressure
  3. Prejudice
  4. Ambiguity
Show answer

Answer: D. Ambiguity

Report this question

5Poor vocabulary on the part of the sender:

  1. Makes it hard to express ideas clearly
  2. Improves clarity
  3. Removes ambiguity
  4. Increases feedback
Show answer

Answer: A. Makes it hard to express ideas clearly

Report this question

6When sender and receiver attach different meanings to the same words, it is called:

  1. Bypassing
  2. Filtering
  3. Feedback
  4. Framing
Show answer

Answer: A. Bypassing

Report this question

7Slang is most likely to create barriers for:

  1. Close friends
  2. Outsiders and non-native speakers
  3. The sender only
  4. Peers who use it
Show answer

Answer: B. Outsiders and non-native speakers

Report this question

8The idiom "kick the bucket" may cause misunderstanding for:

  1. Native speakers only
  2. Teachers only
  3. Nobody
  4. Non-native speakers who take it literally
Show answer

Answer: D. Non-native speakers who take it literally

Report this question

9Words like "soon" or "as early as possible" create:

  1. Concreteness
  2. Clarity
  3. Vagueness and ambiguity
  4. Completeness
Show answer

Answer: C. Vagueness and ambiguity

Report this question

10Semantic barriers can be reduced by using:

  1. Technical terms
  2. Long sentences
  3. Simple, familiar words
  4. Slang
Show answer

Answer: C. Simple, familiar words

Report this question

11A language barrier arises when:

  1. The message is printed
  2. Sender and receiver do not share a common language or proficiency
  3. Distance is short
  4. Noise is low
Show answer

Answer: B. Sender and receiver do not share a common language or proficiency

Report this question

12Literal word-for-word translation may distort meaning, creating a:

  1. Physical barrier
  2. Technological barrier
  3. Semantic barrier
  4. Organizational barrier
Show answer

Answer: C. Semantic barrier

Report this question

13Which of the following is a semantic barrier?

  1. Ambiguous wording
  2. Loud machinery
  3. Power failure
  4. Information overload
Show answer

Answer: A. Ambiguous wording

Report this question

14Which pair consists only of semantic barriers?

  1. Jargon, ambiguity
  2. Noise, distance
  3. Fear, anger
  4. Hierarchy, overload
Show answer

Answer: A. Jargon, ambiguity
