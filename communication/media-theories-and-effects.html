About this question set

This set has 22 multiple-choice questions on Media Theories and Effects from the UGC NET Paper 1 syllabus, unit 4, Communication. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Communication notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

22 practice questions with answers

1The hypodermic needle theory assumes the audience is:

  1. Active and selective
  2. Immune to media
  3. Passive and directly influenced
  4. Independent
Show answer

Answer: C. Passive and directly influenced

Report this question

2Another name for the hypodermic needle theory is the:

  1. Two-step flow theory
  2. Uses and gratifications theory
  3. Cultivation theory
  4. Magic bullet theory
Show answer

Answer: D. Magic bullet theory

Report this question

3The 1938 "War of the Worlds" radio broadcast is often linked with:

  1. Two-step flow
  2. Agenda-setting
  3. Spiral of silence
  4. Hypodermic needle theory
Show answer

Answer: D. Hypodermic needle theory

Report this question

4The two-step flow theory was proposed by:

  1. McCombs
  2. Gerbner
  3. Lazarsfeld, with Berelson and Gaudet
  4. Noelle-Neumann
Show answer

Answer: C. Lazarsfeld, with Berelson and Gaudet

Report this question

5In the two-step flow, information flows from the media to:

  1. Everyone directly
  2. Opinion leaders, who pass it to others
  3. Governments only
  4. Advertisers
Show answer

Answer: B. Opinion leaders, who pass it to others

Report this question

6The two-step flow theory originated from a study of the:

  1. 1938 radio drama
  2. 1940 US presidential election campaign
  3. 1968 election
  4. 1991 war
Show answer

Answer: B. 1940 US presidential election campaign

Report this question

7Opinion leaders are:

  1. Government officers
  2. Newspaper owners only
  3. Advertisers
  4. Individuals who influence others' opinions and relay media content
Show answer

Answer: D. Individuals who influence others' opinions and relay media content

Report this question

8The multi-step flow theory suggests that:

  1. Media effects are direct
  2. Media influence passes through several layers of people
  3. The audience is passive
  4. Only television matters
Show answer

Answer: B. Media influence passes through several layers of people

Report this question

9The agenda-setting theory was proposed by:

  1. McCombs and Shaw
  2. Katz and Blumler
  3. Gerbner
  4. Lazarsfeld
Show answer

Answer: A. McCombs and Shaw

Report this question

10According to agenda-setting, the media are most successful in telling people:

  1. What to think
  2. How to vote
  3. What to think about
  4. What to buy
Show answer

Answer: C. What to think about

Report this question

11The idea that the press tells people "what to think about" is attributed to:

  1. Gerbner
  2. Bernard Cohen
  3. Noelle-Neumann
  4. Katz

12The uses and gratifications theory focuses on:

  1. What media do to people
  2. Media ownership
  3. What people do with media
  4. Media law

Answer: C. What people do with media

Report this question

13The uses and gratifications approach is associated with:

  1. Katz, Blumler and Gurevitch
  2. Lazarsfeld
  3. McCombs and Shaw
  4. Gerbner
Show answer

Answer: A. Katz, Blumler and Gurevitch

Report this question

14Watching a comedy show to relax meets the need for:

  1. Escapism or tension release
  2. Surveillance
  3. Social prestige
  4. Voting

Answer: A. Escapism or tension release

15The cultivation theory was proposed by:

  1. Lazarsfeld
  2. McCombs
  3. Noelle-Neumann
  4. Gerbner

Answer: D. Gerbner

16Cultivation theory studies the long-term effects of:

  1. Newspaper reading
  2. Television viewing
  3. Radio listening
  4. Book reading
Show answer

Answer: B. Television viewing

17"Mean world syndrome" refers to the belief that:

  1. Light viewers fear crime
  2. Radio listeners are violent
  3. Heavy TV viewers perceive the world as more dangerous than it is
  4. Readers are pessimistic

18The spiral of silence theory was proposed by:

  1. Gerbner
  2. Lazarsfeld
  3. McCombs
  4. Elisabeth Noelle-Neumann
Show answer

Answer: D. Elisabeth Noelle-Neumann

Report this question

19In the spiral of silence, people with minority opinions tend to:

  1. Speak louder
  2. Join the majority loudly
  3. Remain silent for fear of isolation
  4. Ignore the media

20The media dependency theory was proposed by:

  1. Ball-Rokeach and DeFleur
  2. Katz and Lazarsfeld
  3. Gerbner
  4. Shaw

21Dependency on media is greatest during:

  1. Stable, calm periods only

  4. Social change, conflict or crisis
