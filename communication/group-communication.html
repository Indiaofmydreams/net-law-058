About this question set

This set has 20 multiple-choice questions on Group Communication from the UGC NET Paper 1 syllabus, unit 4, Communication. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Communication notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

20 practice questions with answers

1A group created by an organization to achieve specific tasks, such as a committee, is a:

  1. Informal group
  2. Primary group
  3. Formal group
  4. Reference group
Show answer

Answer: C. Formal group

Report this question

2A group formed on the basis of friendship and common interests, without official sanction, is a:

  1. Informal group
  2. Formal group
  3. Task force
  4. Committee
Show answer

Answer: A. Informal group
