About this question set

This set has 20 multiple-choice questions on Models of Communication from the UGC NET Paper 1 syllabus, unit 4, Communication. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

20 practice questions with answers

1Aristotle's model of communication consists of:

  1. Source, message, channel, receiver
  2. Who, what, channel, whom, effect
  3. Speaker, speech, occasion, audience, effect
  4. Sender, transmitter, receiver, destination, noise
Show answer

Answer: C. Speaker, speech, occasion, audience, effect

Report this question

2Aristotle's model is:

  1. Circular
  2. Linear and speaker-centred
  3. Transactional
  4. Helical
Show answer

Answer: B. Linear and speaker-centred

3Which of the following is NOT one of Aristotle's modes of persuasion?

  1. Mythos
  2. Ethos
  3. Pathos
  4. Logos
Show answer

Answer: A. Mythos
