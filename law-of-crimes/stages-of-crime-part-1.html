About this question set

This set has 25 multiple-choice questions on Stages of Crime from the UGC NET Law (058) syllabus, unit 4, Law of Crimes. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

25 practice questions with answers

1The four stages of crime in sequential order are:

  1. Preparation → Attempt → Intention → Completion
  2. Attempt → Preparation → Intention → Commission
  3. Intention → Preparation → Attempt → Commission
  4. Commission → Intention → Preparation → Attempt
Show answer

Answer: C. Intention → Preparation → Attempt → Commission

Report this question

2At which stage does criminal liability generally begin under IPC/BNS?

  1. Intention
  2. Preparation
  3. Attempt
  4. Completion
Show answer

Answer: C. Attempt

3Attempt under IPC is defined under:

  1. Section 107
  2. Section 120A
  3. Section 511
  4. Section 34
Show answer

Answer: C. Section 511

4Under BNS 2023, attempt to commit offences is covered under:

  1. Section 61
  2. Section 62
  3. Section 63
  4. Section 64

Answer: B. Section 62

5Abetment under IPC is defined in:

  1. Section 120B
  2. Section 34
  3. Section 107
  4. Section 149

Answer: C. Section 107

  1. Section 49
  2. Section 45
  3. Section 50
  4. Section 48

7Abetment can be committed by:

  1. Instigation only
  2. Conspiracy only
  3. Intentional aiding only
  4. Instigation, conspiracy, or intentional aiding
Show answer

Answer: D. Instigation, conspiracy, or intentional aiding

8Criminal conspiracy under IPC is defined in:

  1. Section 120B
  2. Section 107
  3. Section 120A
  4. Section 34

9Criminal conspiracy requires a minimum of how many persons?

  1. 2
  2. 1
  3. 5
  4. 3

10Which of the following is an inchoate (incomplete) crime?

  1. Murder
  2. Criminal conspiracy
  3. Theft
  4. Robbery
Show answer

Answer: B. Criminal conspiracy

11Preparation is generally not punishable except in cases such as:

  1. Preparation to commit theft
  2. Preparation to wage war against the State (Section 122 IPC / Section 148 BNS)
  3. Preparation to commit cheating
  4. Preparation to cause hurt
Show answer

Answer: B. Preparation to wage war against the State (Section 122 IPC / Section 148 BNS)

Report this question

12In Abhayanand Mishra v. State of Bihar, the Supreme Court held that the accused had crossed preparation and reached the stage of:

  1. Intention
  2. Commission
  3. Conspiracy
  4. Attempt
Show answer

Answer: D. Attempt

13An abettor is punishable under IPC:

  1. Only if the main offence is committed
  2. Even if the main offence is not committed, in certain cases
  3. Only if he is present at the scene
  4. Only if he physically participates
Show answer

Answer: B. Even if the main offence is not committed, in certain cases

14The landmark case on criminal conspiracy in India is:

  1. State of HP v. Nirmala Devi
  2. K.M. Nanavati case
  3. Kehar Singh v. State (Delhi Administration)
  4. Bachan Singh case
Show answer

Answer: C. Kehar Singh v. State (Delhi Administration)

15The 'last act' test for attempt was propounded in:

  1. Queen v. Collins
  2. R v. Eagleton
  3. Abhayanand Mishra v. State of Bihar
  4. Malkiat Singh v. State of Punjab
Show answer

Answer: B. R v. Eagleton

Report this question

16The proximity test for distinguishing attempt from preparation requires:

  1. The accused must be physically present at the scene
  2. The accused must have motive
  3. The accused must be very near to completing the offence
  4. The accused must have already caused harm
Show answer

Answer: C. The accused must be very near to completing the offence

Report this question

17In Malkiat Singh v. State of Punjab (1969), the Supreme Court applied which test to distinguish attempt from preparation?

  1. The social danger test
  2. The last proximate act test
  3. The equivocality test
  4. The locus poenitentiae (opportunity to repent) test
Show answer

Answer: D. The locus poenitentiae (opportunity to repent) test

Report this question

18Criminal conspiracy under Section 120A IPC is complete when:

  1. An overt act is committed
  2. The main offence is committed
  3. Two or more persons agree to do an illegal act or a legal act by illegal means
  4. The accused is arrested
Show answer

Answer: C. Two or more persons agree to do an illegal act or a legal act by illegal means

Report this question

19Which of the following is the key distinction between criminal conspiracy (Section 120A) and abetment by conspiracy (Section 107)?

  1. They are identical
  2. Section 120A requires 5 persons; Section 107 requires 2
  3. Section 107 abetment by conspiracy requires an overt act in pursuance; Section 120A does not necessarily require an overt act
  4. Section 107 applies only to murder
Show answer

Answer: C. Section 107 abetment by conspiracy requires an overt act in pursuance; Section 120A does not necessarily require an overt act

Report this question

20Impossible attempt (e.g., attempting to pick an empty pocket) is punishable in India:

  1. Yes, under Section 511 IPC / Section 62 BNS
  2. No, since it is factually impossible
  3. Only if the accused knew it was impossible
  4. Only under BNS 2023, not under IPC
Show answer

Answer: A. Yes, under Section 511 IPC / Section 62 BNS

Report this question

21In State of Maharashtra v. Mohd. Yakub (1980), the Supreme Court while discussing attempt held:

  1. Attempt requires completion of the last act
  2. Preparation and attempt are the same
  3. The word 'attempt' should be construed broadly - any act done towards commission with intent is an attempt
  4. Attempt is not punishable under IPC
Show answer

Answer: C. The word 'attempt' should be construed broadly - any act done towards commission with intent is an attempt

Report this question

22Abetment of suicide is separately punishable under:

  1. Section 309 IPC
  2. Section 107 IPC
  3. Section 304A IPC
  4. Section 306 IPC / Section 108 BNS
Show answer

Answer: D. Section 306 IPC / Section 108 BNS

Report this question

23Under BNS 2023, petty organised crime (Section 112) covers:

  1. Organised crime by a group including theft, snatching, cheating, unauthorised selling of tickets, betting/gambling - punishable with 1-7 years + fine
  2. Only terrorism
  3. Only drug trafficking
  4. Only counterfeiting
Show answer

Answer: A. Organised crime by a group including theft, snatching, cheating, unauthorised selling of tickets, betting/gambling - punishable with 1-7 years + fine

Report this question

24Abetment of suicide of a child below 18 or insane person under BNS 2023 is punishable under:

  1. Section 108 BNS
  2. Section 107 BNS - with death or life imprisonment
  3. Section 48 BNS
  4. Section 106 BNS
Show answer

Answer: B. Section 107 BNS - with death or life imprisonment

Report this question

25When a person abets an offence and a DIFFERENT offence is actually committed as a probable consequence, the abettor is:

  1. Liable for the offence actually committed if it was a probable consequence - Section 111 IPC / Section 54 BNS
  2. Liable only for the offence he abetted
  3. Not liable for any offence
  4. Liable only if he specifically intended the different offence
Show answer

Answer: A. Liable for the offence actually committed if it was a probable consequence - Section 111 IPC / Section 54 BNS
