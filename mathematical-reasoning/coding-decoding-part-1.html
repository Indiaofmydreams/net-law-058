About this question set

This set has 18 multiple-choice questions on Coding-Decoding from the UGC NET Paper 1 syllabus, unit 5, Mathematical Reasoning and Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 18 of the 18 questions carry a written explanation.

For the concepts and case law behind these questions, read the Mathematical Reasoning notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

18 practice questions with answers

1If CAT is coded as DBU, then DOG is coded as:

  1. ENH
  2. CNF
  3. EOH
  4. EPH
Show answer and explanation

Answer: D. EPH

Each letter moves +1, so D→E, O→P, G→H.

Report this question

2If FRIEND is coded as GSJFOE, then SCHOOL is coded as:

  1. TCIPPM
  2. TDIOPM
  3. TDIPPM
  4. RDIPPM
Show answer and explanation

Answer: C. TDIPPM

Each letter moves +1, so S→T, C→D, H→I, O→P, O→P, L→M.

Report this question

3If BEAD is coded as CGDH, then FACE is coded as:

  1. GCFI
  2. GDFI
  3. HCFI
  4. GCEI
Show answer and explanation

Answer: A. GCFI

The shifts are +1, +2, +3, +4, so F→G, A→C, C→F, E→I.

Report this question

4If A = Z, B = Y, C = X and so on, then CAT is coded as:

  1. YZG
  2. XZG
  3. XZH
  4. XYG
Show answer and explanation

Answer: B. XZG

The mirror-alphabet code sends C→X, A→Z, T→G.

Report this question

5If DELHI is written as IHLED, then MUMBAI is written as:

  1. IAMBUM
  2. MUMABI
  3. IABUMM
  4. IABMUM
Show answer and explanation

Answer: D. IABMUM

The whole word is reversed.

Report this question

6If A = 1, B = 2, C = 3 and so on, then BAG is coded as:

  1. 1-2-7
  2. 2-1-6
  3. 2-1-7
  4. 2-2-7
Show answer and explanation

Answer: C. 2-1-7

Letter-to-position code, with B = 2, A = 1, G = 7.

Report this question

7If red is called blue, blue is called green, green is called yellow and yellow is called white, what is the colour of the sky called?

  1. Green
  2. Blue
  3. Yellow
  4. Red
Show answer and explanation

Answer: A. Green

The sky is blue, and blue is called green.

Report this question

8If milk is called water, water is called tea, tea is called coffee and coffee is called juice, what do we get from a cow?

  1. Coffee
  2. Water
  3. Milk
  4. Tea
Show answer and explanation

Answer: B. Water

A cow gives milk, and milk is called water.

Report this question

9In a code, 'ka lo mi' means 'good big house', 'lo pa' means 'big car' and 'mi ta' means 'house wall'. What is the code for 'good'?

  1. lo
  2. mi
  3. pa
  4. ka
Show answer and explanation

Answer: D. ka

'lo' is the common code for "big" and 'mi' the common code for "house", so the leftover code in the first statement is 'ka', meaning "good".

Report this question

10In a code, 'sun moon star' is 'ak bl cm', 'moon star dust' is 'bl cm dn' and 'star dust cloud' is 'cm dn eo'. What is the code for 'dust'?

  1. cm
  2. eo
  3. dn
  4. bl
Show answer and explanation

Answer: C. dn

'star' is common to all three statements, so it is 'cm'. 'Dust' is common to statements 2 and 3 apart from 'cm', so it is 'dn'.

Report this question

11If + means ×, − means ÷, × means − and ÷ means +, then 12 + 3 − 4 × 5 ÷ 2 = ?

  1. 6
  2. 9
  3. 4
  4. 8
Show answer and explanation

Answer: A. 6

Replace the symbols to get 12 × 3 ÷ 4 − 5 + 2 = 9 − 5 + 2 = 6.

Report this question

12If P means +, Q means −, R means × and S means ÷, then 20 R 3 P 8 S 2 Q 4 = ?

  1. 64
  2. 60
  3. 56
  4. 52
Show answer and explanation

Answer: B. 60

20 × 3 + 8 ÷ 2 − 4 = 60 + 4 − 4 = 60.

Report this question

13If ROSE is written as TQUG, then LILY is written as:

  1. MKNA
  2. NJNA
  3. NKNB
  4. NKNA
Show answer and explanation

Answer: D. NKNA

Each letter moves +2, so L→N, I→K, L→N, Y→A.

Report this question

14If TRAIN is coded as UQBHO, then PLANE is coded as:

  1. PKBMF
  2. QLBMF
  3. QKBMF
  4. QKBNF
Show answer and explanation

Answer: C. QKBMF

The shifts alternate +1, −1, +1, −1, +1.

Report this question

15If CAT is coded as 24 and DOG as 26, then BAT is coded as:

  1. 23
  2. 25
  3. 22
  4. 21
Show answer and explanation

Answer: A. 23

The sum of letter positions, so B + A + T = 2 + 1 + 20 = 23.

Report this question

16Statement I: In a code where each letter is replaced by the next letter, BAD becomes CBE.
Statement II: In the same code, ZOO becomes APP.

  1. I true, II false
  2. Both true
  3. I false, II true
  4. Both false
Show answer and explanation

Answer: B. Both true

+1 shift, where Z wraps around to A.

Report this question

17If KHOOR stands for HELLO (a shift of +3 forward in coding), then FRGH stands for:

  1. CORE
  2. DOME
  3. COPE
  4. CODE
Show answer and explanation

Answer: D. CODE

Decoding means −3, so F→C, R→O, G→D, H→E.

Report this question

18If BRAIN is coded as AQZHM, then MIND is coded as:

  1. LIMC
  2. MHMC
  3. LHMC
  4. LHNC
Show answer and explanation

Answer: C. LHMC

Each letter moves −1, so M→L, I→H, N→M, D→C.
