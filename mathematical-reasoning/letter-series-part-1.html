About this question set

This set has 19 multiple-choice questions on Letter Series from the UGC NET Paper 1 syllabus, unit 5, Mathematical Reasoning and Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 19 of the 19 questions carry a written explanation.

For the concepts and case law behind these questions, read the Mathematical Reasoning notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

19 practice questions with answers

1Complete the series: A, C, E, G, ?

  1. K
  2. J
  3. H
  4. I
Show answer and explanation

Answer: D. I

Skip one letter each time, so G (7) + 2 = I (9).

Report this question

2Complete the series: C, F, I, L, ?

  1. P
  2. M
  3. O
  4. N
Show answer and explanation

Answer: C. O

Positions 3, 6, 9, 12, so the next is 15, which is O.

Report this question

3Complete the series: Z, X, V, T, ?

  1. R
  2. P
  3. Q
  4. S
Show answer and explanation

Answer: A. R

Move back 2 each time, so T (20) − 2 = 18, which is R.

Report this question

4Complete the series: A, B, D, G, K, ?

  1. Q
  2. P
  3. O
  4. N
Show answer and explanation

Answer: B. P

The jumps are +1, +2, +3, +4, so the next is +5 and K (11) + 5 = 16, which is P.

Report this question

5Complete the series: AZ, BY, CX, DW, ?

  1. EU
  2. FV
  3. EW
  4. EV
Show answer and explanation

Answer: D. EV

The first letter moves forward and the second moves backward by one each time.

Report this question

6Complete the series: ACE, FHJ, KMO, ?

  1. QSU
  2. OQS
  3. PRT
  4. PQR
Show answer and explanation

Answer: C. PRT

Each group has alternate letters, and each group starts 5 letters after the last group's first letter (A, F, K, P).

Report this question

7Complete the series: ABD, DEG, GHJ, ?

  1. JKM
  2. HIK
  3. KLM
  4. JLM
Show answer and explanation

Answer: A. JKM

Each group follows the pattern +1, +2 and starts at the previous group's last letter.

Report this question

8Complete the series: AB, DE, GH, JK, ?

  1. NO
  2. MN
  3. LM
  4. OP
Show answer and explanation

Answer: B. MN

The pairs begin 3 letters apart (A, D, G, J, M).

Report this question

9Complete the series: Z, Y, W, T, P, ?

  1. L
  2. J
  3. M
  4. K
Show answer and explanation

Answer: D. K

The steps back are 1, 2, 3, 4, so the next is 5 and P (16) − 5 = 11, which is K.

Report this question

10Complete the series: ac, bd, ce, df, ?

  1. dg
  2. fh
  3. eg
  4. fg
Show answer and explanation

Answer: C. eg

The first letter goes a, b, c, d, e and the second goes c, d, e, f, g.

Report this question

11Fill in the blanks: a b _ a b c _ b c a _ c

  1. c, a, b
  2. b, c, a
  3. c, b, a
  4. a, b, c
Show answer and explanation

Answer: A. c, a, b

The repeating unit "abc" gives a b c a b c a b c a b c.

Report this question

12If A = 1, B = 2, C = 3 and so on, the value of CAB is:

  1. 5
  2. 6
  3. 8
  4. 7
Show answer and explanation

Answer: B. 6

3 + 1 + 2 = 6.

Report this question

13Which letter is 5th from the end of the English alphabet?

  1. X
  2. W
  3. U
  4. V
Show answer and explanation

Answer: D. V

Counting back from Z, the 5th is Z, Y, X, W, V, so it is V (position 22 = 27 − 5).

Report this question

14How many letters are there between G and P in the English alphabet?

  1. 7
  2. 9
  3. 8
  4. 10
Show answer and explanation

Answer: C. 8

The letters between are H to O, which is 16 − 7 − 1 = 8.

Report this question

15Which letter is exactly midway between D and N?

  1. I
  2. K
  3. J
  4. H
Show answer and explanation

Answer: A. I

The midpoint of positions 4 and 14 is 9, which is I.

Report this question

16In a reversed alphabet (A↔Z, B↔Y, …), the letter opposite to D is:

  1. X
  2. W
  3. V
  4. U
Show answer and explanation

Answer: B. W

Opposite position = 27 − 4 = 23, which is W.

Report this question

17In the word EXAMINATION, how many letters appear twice?

  1. 4
  2. 2
  3. 1
  4. 3
Show answer and explanation

Answer: D. 3

A, I and N each occur twice.

Report this question

18If the letters of the word BRAIN are arranged alphabetically, which letter is in the middle?

  1. B
  2. N
  3. I
  4. A
Show answer and explanation

Answer: C. I

The order is A, B, I, N, R, and the 3rd is I.

Report this question

19Arrange the words in dictionary order and pick the third word: Table, Tablet, Tabloid, Tableau, Tabular

  1. Tablet
  2. Tabloid
  3. Table
  4. Tableau
Show answer and explanation

Answer: A. Tablet

The order is Table, Tableau, Tablet, Tabloid, Tabular, compared letter by letter.
