About this question set

This set has 18 multiple-choice questions on Coding-Decoding from the UGC NET Paper 1 syllabus, unit 5, Mathematical Reasoning and Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 18 of the 18 questions carry a written explanation.

18 practice questions with answers

1If FOUR is coded as 6-15-21-18, then EIGHT is coded as:

  1. 5-8-7-9-20
  2. 5-9-8-7-20
  3. 5-9-7-8-19
  4. 5-9-7-8-20
Show answer and explanation

Answer: D. 5-9-7-8-20

Replace each letter by its alphabet position: E = 5, I = 9, G = 7, H = 8, T = 20.

2Statement I: In mirror-alphabet coding (A↔Z, B↔Y), the letter M is coded as N.
Statement II: In mirror coding, the sum of the positions of a letter and its code is always 27.

  1. Both true
  2. I false, II true
  3. Both false
  4. I true, II false
Show answer and explanation

Answer: A. Both true

M (13) pairs with 27 − 13 = 14, which is N.

Report this question

3Arrange the following words in dictionary order: 1. Tomorrow 2. Tomato 3. Tombstone 4. Token

  1. 2, 3, 1, 4
  2. 4, 2, 3, 1
  3. 2, 4, 3, 1
  4. 4, 3, 2, 1
Show answer and explanation

Answer: B. 4, 2, 3, 1

Compare letter by letter, so Token < Tomato < Tombstone < Tomorrow.

Report this question

4If BOOK is coded as ERRN, then PAGE is coded as:

  1. SCJH
  2. TDJH
  3. SDJH
  4. SDIH
Show answer and explanation

Answer: C. SDJH

Each letter moves +3, so P→S, A→D, G→J, E→H.

Report this question

5If A = 26, B = 25, C = 24 and so on (Z = 1), then BAD is coded as:

  1. 2-1-4
  2. 25-26-23
  3. 24-26-23
  4. 25-26-22
Show answer and explanation

Answer: B. 25-26-23

The value of a letter is 27 minus its position, so B = 25, A = 26, D = 23.

Report this question

6If tea is called coffee, coffee is called milk, milk is called juice, juice is called water and water is called soup, which is used to quench thirst?

  1. Juice
  2. Milk
  3. Water
  4. Soup
Show answer and explanation

Answer: D. Soup

Thirst is quenched by water, and water is called soup.

Report this question

7If CAB = 6 and DAD = 9, then DEF = ?

  1. 15
  2. 14
  3. 16
  4. 12
Show answer and explanation

Answer: A. 15

Add the alphabet positions (3 + 1 + 2 = 6 and 4 + 1 + 4 = 9), so DEF = 4 + 5 + 6 = 15.

Report this question

8If '×' means '+', '+' means '÷', '÷' means '−' and '−' means '×', then 12 + 3 × 5 − 2 ÷ 4 = ?

  1. 14
  2. 8
  3. 10
  4. 12
Show answer and explanation

Answer: C. 10

Substitute to get 12 ÷ 3 + 5 × 2 − 4 = 4 + 10 − 4 = 10.

Report this question

9If P means +, Q means −, R means × and S means ÷, then 8 S 2 R 5 P 6 Q 4 = ?

  1. 24
  2. 22
  3. 20
  4. 26
Show answer and explanation

Answer: B. 22

8 ÷ 2 × 5 + 6 − 4 = 20 + 6 − 4 = 22.

Report this question

10In a code, 'bring me a pen' is 'ta ki lo ne', 'give me a book' is 'ki ne sa de' and 'pen is a gift' is 'lo ne zu ma'. The code for 'a' is:

  1. ne
  2. ta
  3. ki
  4. lo
Show answer and explanation

Answer: A. ne

The code common to all three statements is 'ne', and the only word common to all three statements is 'a'.

Report this question

11If WATER is coded as 23-1-20-5-18, then RIVER is coded as:

  1. 17-9-22-5-18
  2. 18-9-21-5-18
  3. 18-8-22-5-18
  4. 18-9-22-5-18
Show answer and explanation

Answer: D. 18-9-22-5-18

Replace each letter by its alphabet position, so R = 18, I = 9, V = 22, E = 5, R = 18.

Report this question

12If in a code the first and last letters of a word are interchanged, then 'BASKET' is written as:

  1. TABKES
  2. EASKTB
  3. TASKEB
  4. BASKET
Show answer and explanation

Answer: C. TASKEB

Swap B and T and keep the middle letters (ASKE) in place.

Report this question

13In a code, 'A × B' means A is the sister of B, 'A + B' means A is the mother of B and 'A − B' means A is the father of B. Which expression means "M is the maternal aunt of N"?

  1. M + O × N
  2. M × O + N
  3. M × O − N
  4. M − O × N
Show answer and explanation

Answer: B. M × O + N

M is the sister of O, and O is the mother of N, so M is N's mother's sister. In (C) O would be the father, which makes M a paternal aunt.

Report this question

14If BAG is coded as 217, then HEAD is coded as:

  1. 8415
  2. 5814
  3. 8541
  4. 8514
Show answer and explanation

Answer: D. 8514

Replace each letter by its position, so H = 8, E = 5, A = 1, D = 4.

Report this question

15Statement I: If MANGO is coded as NBOHP, then ZONE is coded as APOF.
Statement II: In the same code, Z is coded as A.

  1. Both true
  2. Both false
  3. I false, II true
  4. I true, II false
Show answer and explanation

Answer: A. Both true

This is a +1 shift in which Z wraps around to A.

Report this question

16Assertion (A): In a code where each letter is replaced by the letter 3 places ahead, X is coded as A.
Reason (R): The alphabet is treated as cyclic, so A follows Z.

  1. Both true, but R is not the correct explanation
  2. A false, R true
  3. Both true, and R is the correct explanation of A
  4. A true, R false
Show answer and explanation

Answer: C. Both true, and R is the correct explanation of A

X (24) + 3 = 27, which wraps around to A.

Report this question

17Match each coding rule with its code for FIRE:
List I: (a) GJSF (b) EHQD (c) ERIF (d) 6-9-18-5
List II: (i) −1 shift (ii) Alphabet positions (iii) +1 shift (iv) Reversal

  1. a-i, b-iii, c-iv, d-ii
  2. a-iii, b-i, c-iv, d-ii
  3. a-iii, b-i, c-ii, d-iv
  4. a-iv, b-i, c-iii, d-ii
Show answer and explanation

Answer: B. a-iii, b-i, c-iv, d-ii

GJSF is +1, EHQD is −1, ERIF is the word reversed, and 6-9-18-5 gives the positions.

Report this question

18Arrange the steps to decode a letter code in order:
1. Identify the shift pattern
2. Compare coded and original letters
3. Apply the pattern to the new word
4. Verify with the given example

  1. 2, 1, 3, 4
  2. 2, 3, 1, 4
  3. 1, 2, 3, 4
  4. 4, 3, 2, 1
Show answer and explanation

Answer: A. 2, 1, 3, 4

Compare, find the pattern, apply it, then verify.
