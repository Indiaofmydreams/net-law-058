About this question set

This set has 25 multiple-choice questions on Conventional and Non-Conventional Learning Programmes from the UGC NET Paper 1 syllabus, unit 10, Higher Education System. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

1Formal education is best described as:

  2. Only vocational learning
  3. Unstructured, incidental learning
