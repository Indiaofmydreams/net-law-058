About this question set

This set has 15 multiple-choice questions on Levels of Teaching: Deep Dive from the UGC NET Paper 1 syllabus, unit 1, Teaching Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 15 of the 15 questions carry a written explanation.

For the concepts and case law behind these questions, read the Teaching Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

15 practice questions with answers

1The concept of levels of teaching was most systematically described in relation to:

  1. Classroom interaction and cognitive demand placed on learners
  2. Physical arrangement of classrooms
  3. Curriculum design
  4. Teacher evaluation
Show answer and explanation

Answer: A. Classroom interaction and cognitive demand placed on learners

Concept: Levels of teaching = qualitative differences in the cognitive engagement required. Memory = lowest demand. Reflective = highest demand.

Report this question

2At the Memory level of teaching, the teacher's main activity is:

  1. Facilitating inquiry
  2. Presenting information for storage and reproduction
  3. Promoting peer discussion
  4. Creating problem-solving situations
Show answer and explanation

Answer: B. Presenting information for storage and reproduction

Concept: Memory level = teacher is transmitter. Information flows one way. Student stores and reproduces. Teacher-centred.

Report this question

3At the Understanding level, the student is expected to:

  1. Solve novel problems never encountered before
  2. Create original theories
  3. Grasp relationships, principles, and conceptual connections
  4. Only memorise facts given by the teacher
Show answer and explanation

Answer: C. Grasp relationships, principles, and conceptual connections

Concept: Understanding = conceptual grasp. Goes beyond storage to meaning-making. Can explain WHY, not just WHAT.

Report this question

4The Reflective level of teaching corresponds most closely to which movement in education?

  1. Progressivism and Critical Pedagogy
  2. Behaviourism
  3. Essentialism
  4. Perennialism
Show answer and explanation

Answer: A. Progressivism and Critical Pedagogy

Concept: Reflective = inquiry, problem-solving, critical thinking = progressive education (Dewey). Critical pedagogy (Freire) also emphasises reflective consciousness.

Report this question

5A teacher who asks "What would happen if the law of gravity were suddenly reversed?" is teaching at which level?

  1. Memory level
  2. Understanding level
  3. Reflective level
  4. None of the above
Show answer and explanation

Answer: C. Reflective level

Concept: Hypothetical, novel, open-ended = reflective. No single right answer. Requires creative and critical thinking.

Report this question

6Which of the following teaching strategies is MOST appropriate at the Understanding level?

  1. Drilling and repetition
  2. Concept mapping and discussion
  3. Rote recitation
  4. Silent reading and memorisation
Show answer and explanation

Answer: B. Concept mapping and discussion

Concept: Understanding = conceptual connections. Concept maps show relationships. Discussion develops conceptual clarity. Both go beyond simple recall.

Report this question

7At which level of teaching does the learner exhibit "transfer of learning" to new situations?

  1. Memory level only
  2. Memory level with sufficient practice
  3. Transfer does not occur at any level
  4. Understanding level primarily and Reflective level fully
Show answer and explanation

Answer: D. Understanding level primarily and Reflective level fully

Concept: Transfer = applying knowledge to new contexts. Memory level = context-specific only. Understanding = near transfer. Reflective = far transfer to novel problems.

Report this question

8"Herbartian teaching" is most closely associated with which level of teaching?

  1. Application level
  2. Reflective level
  3. Understanding level
  4. Memory level
Show answer and explanation

Answer: D. Memory level

Concept: Herbart's 5 formal steps (Preparation, Presentation, Association, Generalisation, Application) were systematic but still emphasised structured knowledge transmission — most aligned with Memory-Understanding.
Note: Herbart is associated with Memory level in Morrison's framework specifically because the formal steps focus on structured presentation and association, not critical inquiry.

Report this question

9Which of the following best illustrates learning at the Memory level?

  1. A student debates the pros and cons of liberalisation
  2. A student explains why the Indian economy shifted to liberalisation in 1991
  3. A student designs an alternative economic model
  4. A student recites the preamble of the Indian Constitution
Show answer and explanation

Answer: D. A student recites the preamble of the Indian Constitution

Concept: Recites = reproduces = Memory level. Explains WHY = Understanding. Debates = Reflective. Designs = also Reflective.

Report this question

10At the Reflective level, evaluation of student learning would most appropriately use:

  1. Open-ended problems, case studies, projects
  2. Fill-in-the-blank tests
  3. True/false questions
  4. Multiple choice recall tests
Show answer and explanation

Answer: A. Open-ended problems, case studies, projects

Concept: Reflective = HOTS = requires assessment tools that allow creativity and critical reasoning. MCQs and fill-in-blanks test Memory level primarily.

Report this question

11Which statement correctly describes the role of motivation at the three levels of teaching?

  1. Extrinsic motivation suffices for Memory; intrinsic motivation is essential for Reflective
  2. Motivation plays no role in Reflective level learning
  3. Motivation is irrelevant at all three levels
  4. Intrinsic motivation is only needed at Memory level
Show answer and explanation

Answer: A. Extrinsic motivation suffices for Memory; intrinsic motivation is essential for Reflective

Concept: Rote learning can be driven by fear of exam or reward. But reflective, critical engagement requires genuine curiosity and intrinsic interest — cannot be forced.

Report this question

12The type of questioning most characteristic of Memory level teaching is:

  1. Why and How questions
  2. What if and Suppose questions
  3. What and Who questions (factual recall)
  4. Compare and contrast questions
Show answer and explanation

Answer: C. What and Who questions (factual recall)

Concept: Memory level questions = What is? Who is? When did? — single correct factual answer. Understanding = Why/How. Reflective = What if/Suppose/Design.

Report this question

13In Morrison's model, the "Understanding level" requires which psychological process?

  1. Insight and meaningful learning
  2. Associative memory
  3. Stimulus-response bonding
  4. Conditioned reflex
Show answer and explanation

Answer: A. Insight and meaningful learning

Concept: Understanding = Gestalt psychology's "insight" = sudden grasp of the whole structure. Meaning is constructed, not just stored.

Report this question

14A student who can reproduce a theorem but cannot apply it to a new problem is operating at:

  1. Reflective level
  2. Memory level
  3. Application level
  4. Understanding level
Show answer and explanation

Answer: B. Memory level

Concept: Reproduces = Memory. Cannot apply = has not reached Understanding. Classic exam trap — knowing a formula ≠ understanding it.

Report this question

15Which level of teaching is MOST aligned with Vygotsky's concept of the Zone of Proximal Development?

  1. Memory level — because facts can be drilled
  2. Understanding level — because scaffolding builds conceptual bridges
  3. Reflective level — because ZPD involves independent problem-solving ultimately
  4. Both B and C, as scaffolding at Understanding leads to independent Reflective thinking
Show answer and explanation

Answer: D. Both B and C, as scaffolding at Understanding leads to independent Reflective thinking

Concept: ZPD = gap between assisted and independent performance. Scaffolded Understanding leads to autonomous Reflective thinking — the ZPD process spans both levels.
