About this question set

This set has 23 multiple-choice questions on Skill-Based Education from the UGC NET Paper 1 syllabus, unit 10, Higher Education System. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.
