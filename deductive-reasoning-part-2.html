About this question set

This set has 25 multiple-choice questions on Deductive Reasoning from the UGC NET Paper 1 syllabus, unit 5, Mathematical Reasoning and Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 25 of the 25 questions carry a written explanation.

For the concepts and case law behind these questions, read the Mathematical Reasoning notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

25 practice questions with answers

1"All S are P" is a:

  1. Particular affirmative
  2. Particular negative
  3. Universal affirmative
  4. Universal negative
Show answer and explanation

Answer: C. Universal affirmative

"All" is universal and the statement is affirmative, so it is an A proposition.

Report this question

2"Some S are not P" is symbolised as:

  1. E
  2. I
  3. A
  4. O
Show answer and explanation

Answer: D. O

A is universal affirmative, E universal negative, I particular affirmative and O particular negative.

Report this question

3In an A proposition, the distributed term is:

  1. Subject only
  2. Neither
  3. Both
  4. Predicate only
Show answer and explanation

Answer: A. Subject only

A universal affirmative speaks about the whole subject class, not the whole predicate class.

Report this question

4In an O proposition, the distributed term is:

  1. Subject only
  2. Predicate only
  3. Both
  4. Neither
Show answer and explanation

Answer: B. Predicate only

A particular negative excludes some S from the whole of P.

Report this question

5Which proposition distributes both subject and predicate?

  1. E
  2. A
  3. I
  4. O
Show answer and explanation

Answer: A. E

"No S is P" says the two classes are wholly separate.

Report this question

6Which proposition distributes neither term?

  1. O
  2. A
  3. I
  4. E
Show answer and explanation

Answer: C. I

"Some S are P" talks only about part of each class.

Report this question

7In the traditional square of opposition, A and O propositions are:

  1. Subalterns
  2. Subcontraries
  3. Contraries
  4. Contradictories
Show answer and explanation

Answer: D. Contradictories

They always have opposite truth values.

Report this question

8A and E propositions (same subject and predicate) are:

  1. Subcontraries
  2. Contraries
  3. Contradictories
  4. Subalterns
Show answer and explanation

Answer: B. Contraries

Both cannot be true, but both can be false.

Report this question

9I and O propositions are:

  1. Contradictories
  2. Contraries
  3. Subalterns
  4. Subcontraries
Show answer and explanation

Answer: D. Subcontraries

Both can be true, but both cannot be false.

Report this question

10The relation between A and I propositions (same subject and predicate) is:

  1. Subalternation
  2. Subcontrariety
  3. Contrariety
  4. Contradiction
Show answer and explanation

Answer: A. Subalternation

The universal implies the particular, so if A is true then I is true.

Report this question

11If "Some S are P" is false, then "No S is P" is:

  1. Undetermined
  2. False
  3. True
  4. Doubtful
Show answer and explanation

Answer: C. True

I and E are contradictories, so they have opposite truth values.

Report this question

12If "All S are P" is true, then "Some S are not P" is:

  1. True
  2. False
  3. Undetermined
  4. Doubtful
Show answer and explanation

Answer: B. False

A and O are contradictories.

Report this question

13The converse of "No S is P" is:

  1. Some P are S
  2. All P are S
  3. No S is non-P
  4. No P is S
Show answer and explanation

Answer: D. No P is S

E converts simply, with the subject and predicate swapped.

Report this question

14The converse by limitation (per accidens) of "All dogs are mammals" is:

  1. Some dogs are not mammals
  2. All mammals are dogs
  3. Some mammals are dogs
  4. No mammals are dogs
Show answer and explanation

Answer: C. Some mammals are dogs

A converts to I, because the predicate is undistributed.

Report this question

15The obverse of "All S are P" is:

  1. No S is non-P
  2. No S is P
  3. Some S is non-P
  4. All non-S are P
Show answer and explanation

Answer: A. No S is non-P

Change the quality (affirmative to negative) and replace the predicate with its complement.

Report this question

16"Not (P and Q)" is equivalent to:

  1. Not P and not Q
  2. Not P or not Q
  3. Not P only
  4. P or Q
Show answer and explanation

Answer: B. Not P or not Q

De Morgan's law, where negating "and" flips it to "or".

Report this question

17"Not (P or Q)" is equivalent to:

  1. Not P and not Q
  2. P or not Q
  3. P and Q
  4. Not P or not Q
Show answer and explanation

Answer: A. Not P and not Q

De Morgan's law, where negating "or" flips it to "and".

Report this question

18A conditional statement "If P then Q" is false only when:

  1. Both are false
  2. P is false and Q is true
  3. P is true and Q is false
  4. Both are true
Show answer and explanation

Answer: C. P is true and Q is false

A promise is broken only when the antecedent holds and the consequent fails.

Report this question

19The inclusive disjunction "P or Q" is false only when:

  1. P false, Q true
  2. Both are true
  3. P true, Q false
  4. Both are false
Show answer and explanation

Answer: D. Both are false

"or" needs at least one true component.

Report this question

20"P if and only if Q" is true when:

  1. P is true
  2. P and Q have the same truth value
  3. P and Q have different truth values
  4. Q is true
Show answer and explanation

Answer: B. P and Q have the same truth value

A biconditional means mutual implication, so the values must match.

Report this question

21A statement that is true under every possible truth assignment is called:

  1. Fallacy
  2. Contradiction
  3. Contingency
  4. Tautology
Show answer and explanation

Answer: D. Tautology

"P or not P" is the standard example.

Report this question

22A statement that is false under every possible truth assignment is called:

  1. Tautology
  2. Premise
  3. Contradiction
  4. Contingency
Show answer and explanation

Answer: C. Contradiction

"P and not P" is the standard example.

Report this question

23The correct order of the five members of the Nyaya syllogism is:

  1. Pratijna, Hetu, Udaharana, Upanaya, Nigamana
  2. Hetu, Pratijna, Udaharana, Upanaya, Nigamana
  3. Pratijna, Udaharana, Hetu, Nigamana, Upanaya
  4. Udaharana, Hetu, Pratijna, Nigamana, Upanaya
Show answer and explanation

Answer: A. Pratijna, Hetu, Udaharana, Upanaya, Nigamana

Proposition, reason, example, application, conclusion.

Report this question

24A sorites is:

  1. A single syllogism with a suppressed premise
  2. A chain of syllogisms with intermediate conclusions omitted
  3. A pair of contradictory statements
  4. An argument by analogy
Show answer and explanation

Answer: B. A chain of syllogisms with intermediate conclusions omitted

A chain-argument built from linked syllogisms.

Report this question

25An argument in which one premise or the conclusion is left unstated is called:

  1. Enthymeme
  2. Antinomy
  3. Dilemma
  4. Sorites
Show answer and explanation

Answer: A. Enthymeme

An abbreviated syllogism, such as "He is a doctor, so he is educated".
