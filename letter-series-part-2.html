About this question set

This set has 18 multiple-choice questions on Letter Series from the UGC NET Paper 1 syllabus, unit 5, Mathematical Reasoning and Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 18 of the 18 questions carry a written explanation.

For the concepts and case law behind these questions, read the Mathematical Reasoning notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

18 practice questions with answers

1Complete the series: J, L, O, S, X, ?

  1. C
  2. D
  3. B
  4. E
Show answer and explanation

Answer: B. D

The jumps are +2, +3, +4, +5, so the next is +6 and X (24) + 6 = 30, which wraps around to 4, or D.

2Statement I: In the series B, E, H, K, N, the letters are at an equal interval of 3.
Statement II: The next letter of the series is Q.

  1. Both false
  2. I true, II false
  3. I false, II true
  4. Both true
Show answer and explanation

Answer: D. Both true

Positions 2, 5, 8, 11, 14, and the next is 17, which is Q.

Report this question

3Complete the series: B, E, I, N, ?

  1. S
  2. U
  3. T
  4. R
Show answer and explanation

Answer: C. T

The jumps are +3, +4, +5, so the next is +6 and N (14) + 6 = 20, which is T.

Report this question

4Complete the series: Z, W, S, N, H, ?

  1. A
  2. C
  3. Z
  4. B
Show answer and explanation

Answer: A. A

The steps back are 3, 4, 5, 6, so the next is 7 and H (8) − 7 = 1, which is A.

Report this question

5Complete the series: AZB, CYD, EXF, ?

  1. FWG
  2. GWH
  3. HWI
  4. GVH
Show answer and explanation

Answer: B. GWH

The first and third letters move +2 each time (A, C, E, G and B, D, F, H), and the middle letter moves back one (Z, Y, X, W).

6Complete the series: ZA, YB, XC, WD, ?

  1. WE
  2. UE
  3. VE
  4. VF
Show answer and explanation

Answer: C. VE

The first letter goes backward and the second goes forward by one each time.

Report this question

7Which pair does NOT belong: AC, EG, IK, MO, QR?

  1. QR
  2. MO
  3. EG
  4. IK
Show answer and explanation

Answer: A. QR

Every other pair skips one letter (A–C, E–G, I–K, M–O), and QR does not (it should be QS).

Report this question

8If the letters of the word CHAIR are arranged alphabetically, which letter is second from the right?

  1. C
  2. R
  3. H
  4. I
Show answer and explanation

Answer: D. I

The order is A, C, H, I, R, so the second from the right is I.

9Which letter is the 4th to the right of the 12th letter from the left in the English alphabet?

  1. N
  2. P
  3. Q
  4. O
Show answer and explanation

Answer: B. P

The 12th letter is L, and moving 4 places right gives P (position 16).

10Complete the series: M, N, P, S, W, ?

  1. C
  2. A
  3. B
  4. D

11Complete the series: B, D, G, K, P, ?

  1. T
  2. V
  3. W
  4. U

Answer: B. V

The jumps are +2, +3, +4, +5, so the next is +6 and P (16) + 6 = 22, which is V.

12Complete the series: AB, EF, IJ, MN, ?

  1. PQ
  2. OP
  3. RS
  4. QR
Show answer and explanation

Answer: D. QR

The first letters go A, E, I, M, Q (+4 each time), and the second letter follows the first.

13Complete the series: ZYX, WVU, TSR, ?

  1. QPO
  2. PON
  3. ONM
  4. QRS
Show answer and explanation

Answer: A. QPO

Each group lists three consecutive letters backward, and each group starts 3 letters before the last.

14Complete the series: BDF, HJL, NPR, ?

  1. UWY
  2. TVX
  3. TUV
  4. SUW
Show answer and explanation

Answer: B. TVX

Each group has alternate letters, and the group starts move B, H, N, T (+6 each time).

15Complete the series: ace, bdf, ceg, ?

  1. dgh
  2. efg
  3. dfh
  4. eeh
Show answer and explanation

Answer: C. dfh

Every letter moves +1 from one group to the next.

16Fill in the blanks: a _ c d a b _ d a _ c d

  1. b, b, c
  2. d, c, b
  3. c, b, c
  4. b, c, b
Show answer and explanation

Answer: D. b, c, b

The repeating unit is "abcd", giving a b c d a b c d a b c d.

Report this question

17If the alphabet is written in reverse order (Z, Y, X … A), which letter is 8th to the right of J?

  1. B
  2. A
  3. C
  4. D
Show answer and explanation

Answer: A. B

To the right of J in the reversed order come I, H, G, F, E, D, C, B, and the 8th is B.

Report this question

18Which letter is 5th to the left of the 12th letter from the right end of the English alphabet?

  1. I
  2. L
  3. J
  4. K
Show answer and explanation

Answer: C. J

The 12th from the right is position 27 − 12 = 15, which is O. Moving 5 places left gives position 10, which is J.
