About this question set

This set has 25 multiple-choice questions on Natural Hazards and Disasters: Mitigation Strategies from the UGC NET Paper 1 syllabus, unit 9, People, Development and Environment. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

1Which of the following is a structural measure for flood control?

  1. Public awareness
  2. Land-use regulation
  3. Embankments and reservoirs
