About this question set

This set has 14 multiple-choice questions on Parts of an E-mail Message from the UGC NET Paper 1 syllabus, unit 8, Information and Communication Technology (ICT). Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the ICT notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

1Cc stands for:

  1. Cached copy
  2. Carbon copy
  3. Common copy
  4. Computer copy

  2. Broad carbon copy
  3. Backup carbon copy
  4. Blind carbon copy

Answer: D. Blind carbon copy

3Recipients added in the Bcc field are:

  1. Visible to everyone
  2. Hidden from the other recipients
  3. Unable to receive the message
  4. Sent only the attachments

Answer: B. Hidden from the other recipients

4The "To" field contains:

  1. The attachments
  2. Hidden recipients only
  3. The primary recipients
  4. The subject of the message

Answer: C. The primary recipients

5Recipients in the Cc field are:

  1. Unable to see the message
  2. Visible to all other recipients
  3. Used only for attachments
  4. Hidden from everyone

6The best use of Bcc is to:

  1. Send a message to many people without revealing their addresses
  2. Attach files
  3. Encrypt the message
  4. Hold a discussion

  1. Briefly states the topic of the message
  2. Holds the attachments
  3. Filters spam
  4. Stores the recipient's address

  1. A spam message
  2. The recipient's address
  3. A file sent along with the message, usually shown with a paperclip icon
  4. The subject line

  1. Only the sender
  2. Nobody
  3. Only new recipients
  4. The sender and all other recipients of the original message

11"Forward" is used to:

  1. Delete the original message
  2. Reply only to the sender
  3. Save a draft
  4. Send a received message to new recipients

12The prefix "Re:" in a subject line indicates:

  1. A reply
  2. Spam
  3. A draft
  4. A forwarded message
