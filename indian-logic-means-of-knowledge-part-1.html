About this question set

This set has 25 multiple-choice questions on Indian Logic: Means of Knowledge from the UGC NET Paper 1 syllabus, unit 6, Logical Reasoning. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

1The term "Pramana" means:

  1. Object of knowledge
  2. Doubt
  3. Valid knowledge
  4. Means of valid knowledge
Show answer

Answer: D. Means of valid knowledge

  1. Pramana
  2. Pramata
  3. Pramiti
  4. Prameya

  1. Prameya
