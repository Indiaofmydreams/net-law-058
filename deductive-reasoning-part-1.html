About this question set

This set has 25 multiple-choice questions on Deductive Reasoning from the UGC NET Paper 1 syllabus, unit 5, Mathematical Reasoning and Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 25 of the 25 questions carry a written explanation.

25 practice questions with answers

1Reasoning in which the conclusion follows necessarily from the premises is called:

  1. Analogical
  2. Inductive
  3. Deductive
  4. Abductive
Show answer and explanation

Answer: C. Deductive

Premises guarantee the conclusion, so it is certain, not probable.

Report this question

2"All humans are mortal. Socrates is a human. Therefore, Socrates is mortal." This argument is:

  1. Inductive and strong
  2. Deductive, valid and sound
  3. Analogical and weak
  4. Abductive and plausible
Show answer and explanation

Answer: B. Deductive, valid and sound

The form is valid and both premises are true, so it is sound.

Report this question

3A deductive argument is valid when:

  1. It is impossible for all premises to be true and the conclusion false
  2. The premises are true
  3. The conclusion is probable
  4. The conclusion is true
Show answer and explanation

Answer: A. It is impossible for all premises to be true and the conclusion false

Validity is about the logical form, not about the actual truth of the statements.

Report this question

4A sound argument is one that is:

  1. Strong with true premises
  2. Valid with a false premise
  3. Invalid with true premises
  4. Valid with all true premises
Show answer and explanation

Answer: D. Valid with all true premises

Sound = valid + true premises.

Report this question

5"All birds have wings. Penguins are birds. So penguins have wings." The conclusion is:

  1. Unrelated to the premises
  2. Merely possible
  3. Probable
  4. Necessary, given the premises
Show answer and explanation

Answer: D. Necessary, given the premises

A deductive conclusion is necessary relative to the premises.

Report this question

6Which of the following is the form of Modus Ponens?

  1. If P then Q; P; therefore Q
  2. If P then Q; Q; therefore P
  3. P or Q; P; therefore not Q
  4. If P then Q; not P; therefore not Q
Show answer and explanation

Answer: A. If P then Q; P; therefore Q

Affirm the antecedent, so the consequent follows.

Report this question

7Which of the following is the form of Modus Tollens?

  1. If P then Q; Q; therefore P
  2. If P then Q; not Q; therefore not P
  3. P or Q; not P; therefore Q
  4. If P then Q; P; therefore Q
Show answer and explanation

Answer: B. If P then Q; not Q; therefore not P

Deny the consequent, so the antecedent is denied.

Report this question

8"If it rains, the ground is wet. The ground is wet. Therefore, it rained." This commits:

  1. Valid Modus Ponens
  2. Valid disjunctive syllogism
  3. Fallacy of affirming the consequent
  4. Valid Modus Tollens
Show answer and explanation

Answer: C. Fallacy of affirming the consequent

The wet ground could have other causes, so the inference is invalid.

Report this question

9"If I study, I will pass. I did not study. So I will not pass." This is the fallacy of:

  1. Hasty generalisation
  2. Equivocation
  3. Denying the antecedent
  4. Begging the question
Show answer and explanation

Answer: C. Denying the antecedent

From "not P" you cannot infer "not Q".

Report this question

10"Either Ram is at home or at office. He is not at home. Therefore, he is at office." This is:

  1. Hypothetical syllogism
  2. Modus Tollens
  3. Dilemma
  4. Disjunctive syllogism
Show answer and explanation

Answer: D. Disjunctive syllogism

Eliminate one alternative, so the other follows.

Report this question

11If P then Q; if Q then R; therefore:

  1. P and R
  2. If P then R
  3. If R then P
  4. If Q then P
Show answer and explanation

Answer: B. If P then R

Hypothetical syllogism chains conditionals.

Report this question

12In a valid deductive argument with all true premises, the conclusion:

  1. Must be true
  2. May be false
  3. Is irrelevant
  4. Is probably true
Show answer and explanation

Answer: A. Must be true

Validity plus true premises forces a true conclusion.

Report this question

13All A are B; all B are C. Therefore:

  1. All A are C
  2. Some C are not A
  3. All C are A
  4. No A is C
Show answer and explanation

Answer: A. All A are C

This is the Barbara syllogism (AAA-1).

Report this question

14A standard categorical syllogism contains exactly how many terms?

  1. Two
  2. Three
  3. Five
  4. Four
Show answer and explanation

Answer: B. Three

Major, minor and middle terms. Four terms is a fallacy.

Report this question

15The term that appears in both premises but not in the conclusion is called the:

  1. Predicate term
  2. Minor term
  3. Middle term
  4. Major term
Show answer and explanation

Answer: C. Middle term

The middle term links the two premises.

Report this question

16Deductive reasoning is often described as:

  1. Inference to the best explanation
  2. Bottom-up reasoning
  3. Reasoning by similarity
  4. Top-down reasoning
Show answer and explanation

Answer: D. Top-down reasoning

It moves from general principle to specific case.

Report this question

17Statement I: Deductive reasoning is ampliative, as its conclusion adds new information beyond the premises.
Statement II: In a valid deductive argument, the conclusion is already contained in the premises.

  1. I false, II true
  2. Both false
  3. Both true
  4. I true, II false
Show answer and explanation

Answer: A. I false, II true

Deduction is non-ampliative, and induction is the ampliative type.

Report this question

18Assertion (A): A valid argument can have a false conclusion.
Reason (R): Validity depends on the form of the argument, not on the truth of its statements.

  1. A true, R false
  2. A false, R true
  3. Both true, but R is not the correct explanation
  4. Both A and R are true, and R is the correct explanation of A
Show answer and explanation

Answer: D. Both A and R are true, and R is the correct explanation of A

A valid argument with a false premise can yield a false conclusion.

Report this question

19"All cats are mammals. All dogs are mammals. Therefore, all cats are dogs." This commits the fallacy of:

  1. Affirming the antecedent
  2. Illicit major
  3. Undistributed middle
  4. Four terms
Show answer and explanation

Answer: C. Undistributed middle

The middle term "mammals" is not distributed in either premise.

Report this question

20Which of the following is an example of deductive reasoning?

  1. Two cities are alike, so what is true of one is true of the other
  2. All metals expand on heating; copper is a metal; so copper expands
  3. The sun has risen daily, so it will rise tomorrow
  4. The grass is wet, so it probably rained
Show answer and explanation

Answer: B. All metals expand on heating; copper is a metal; so copper expands

General rule, then a specific case, then a necessary conclusion. (C) is induction, (D) abduction and (A) analogy.

Report this question

21The contrapositive of "If P then Q" is:

  1. If not Q then not P
  2. If not P then not Q
  3. If Q then P
  4. P and not Q
Show answer and explanation

Answer: A. If not Q then not P

Swap and negate. The contrapositive is always equivalent to the original.

Report this question

22The converse of "If P then Q" is:

  1. If not P then not Q
  2. P and Q
  3. If not Q then not P
  4. If Q then P
Show answer and explanation

Answer: D. If Q then P

Swap the antecedent and consequent. (A) is the inverse.

Report this question

23Which statement is logically equivalent to "If a figure is a square, then it is a rectangle"?

  1. If a figure is not a square, it is not a rectangle
  2. If a figure is a rectangle, it is a square
  3. If a figure is not a rectangle, it is not a square
  4. Some rectangles are not squares
Show answer and explanation

Answer: C. If a figure is not a rectangle, it is not a square

The contrapositive is equivalent.

Report this question

24The negation of "All students are punctual" is:

  1. Some students are punctual
  2. Some students are not punctual
  3. All students are late
  4. No student is punctual
Show answer and explanation

Answer: B. Some students are not punctual

The negation of a universal statement is a particular negative statement.

Report this question

25Premises: All poets are dreamers. Some dreamers are teachers. Which conclusion follows?

  1. Some poets are teachers
  2. No definite conclusion follows
  3. All poets are teachers
  4. All teachers are poets
Show answer and explanation

Answer: B. No definite conclusion follows

The middle term is undistributed in the premises, so no valid conclusion follows.
