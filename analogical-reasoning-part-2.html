About this question set

This set has 14 multiple-choice questions on Analogical Reasoning from the UGC NET Paper 1 syllabus, unit 5, Mathematical Reasoning and Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 14 of the 14 questions carry a written explanation.

For the concepts and case law behind these questions, read the Mathematical Reasoning notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

14 practice questions with answers

1Arrange the steps of an analogical argument in order:
1. Identify similarities between source and target
2. Observe an additional property in the source
3. Conclude the target probably has it
4. Evaluate the relevance of similarities and dissimilarities

  1. 2, 1, 3, 4
  2. 1, 2, 3, 4
  3. 1, 3, 2, 4
  4. 3, 2, 1, 4
Show answer and explanation

Answer: B. 1, 2, 3, 4

Compare, find the extra property, infer, then evaluate.

Report this question

2In an analogical argument, the case whose property is already known is the:

  1. Source (analogue)
  2. Target
  3. Conclusion
  4. Middle term
Show answer and explanation

Answer: A. Source (analogue)

The property is carried over from the source to the target.

Report this question

3The case about which the analogical conclusion is drawn is called the:

  1. Major term
  2. Source
  3. Premise
  4. Target
Show answer and explanation

Answer: D. Target

The target is the case the conclusion is about.

Report this question

4Showing an argument invalid by presenting a parallel argument of the same form with true premises and a false conclusion is called:

  1. Reductio ad absurdum
  2. Refutation by logical analogy
  3. Abduction
  4. Perfect induction
Show answer and explanation

Answer: B. Refutation by logical analogy

Parallel form, true premises and a false conclusion expose the invalid form.

Report this question

5In Nyaya, Upamana is knowledge obtained through:

  1. Testimony
  2. Inference
  3. Comparison
  4. Perception
Show answer and explanation

Answer: C. Comparison

Upamana is knowledge through similarity, such as recognising a gavaya by its likeness to a cow.

Report this question

6Testing a scale-model aeroplane in a wind tunnel to predict the performance of the real aircraft is an example of:

  1. Analogical reasoning
  2. Perfect induction
  3. Abduction
  4. Syllogism
Show answer and explanation

Answer: A. Analogical reasoning

The model is the source and the real aircraft is the target.

Report this question

7A strong analogical argument requires that the shared properties are:

  1. Numerous but trivial
  2. Chosen at random
  3. Merely visible
  4. Causally or logically relevant to the property inferred
Show answer and explanation

Answer: D. Causally or logically relevant to the property inferred

Relevance is the key test.

Report this question

8Which of the following is the weakest analogical argument?

  1. Two students have similar grades and study habits; one cleared the exam; so the other probably will
  2. Cats and cars both move; cats purr; so cars purr
  3. Two plants grown in identical conditions; one bloomed; so the other probably will
  4. Two houses have the same builder, design and materials; one is earthquake-resistant; so the other probably is
Show answer and explanation

Answer: B. Cats and cars both move; cats purr; so cars purr

The shared property (movement) has no bearing on purring.

Report this question

9An analogical argument may be strengthened by:

  1. Ignoring the differences
  2. Using only one similarity
  3. Increasing the diversity of similar cases and reducing relevant differences
  4. Adding irrelevant similarities
Show answer and explanation

Answer: C. Increasing the diversity of similar cases and reducing relevant differences

More relevant evidence and fewer relevant differences.

Report this question

10Analogical reasoning differs from enumerative induction in that it:

  1. Compares particular cases rather than generalising to a class
  2. Uses all members of a class
  3. Uses no premises
  4. Is deductive
Show answer and explanation

Answer: A. Compares particular cases rather than generalising to a class

It goes from particular to particular.

Report this question

11Statement I: Analogies are useful in explaining unfamiliar concepts in teaching.
Statement II: An analogy always proves its conclusion.

  1. I false, II true
  2. Both false
  3. Both true
  4. I true, II false
Show answer and explanation

Answer: D. I true, II false

Analogies illustrate and suggest, but do not prove.

Report this question

12Assertion (A): An analogical argument is weakened if a relevant dissimilarity is found.
Reason (R): Such a dissimilarity reduces the probability that the target shares the inferred property.

  1. A false, R true
  2. Both true, but R is not the correct explanation
  3. Both true, and R is the correct explanation of A
  4. A true, R false
Show answer and explanation

Answer: C. Both true, and R is the correct explanation of A

Relevant differences lower the probability of the conclusion.

Report this question

13Match List I with List II:
List I: (a) Source (b) Target (c) Relevant similarity (d) Disanalogy
List II: (i) Basis supporting the inference (ii) Case known to have the property (iii) Case to which the property is attributed (iv) Relevant difference that weakens the argument

  1. a-i, b-iii, c-ii, d-iv
  2. a-ii, b-iii, c-i, d-iv
  3. a-iii, b-ii, c-i, d-iv
  4. a-ii, b-i, c-iii, d-iv
Show answer and explanation

Answer: B. a-ii, b-iii, c-i, d-iv

These are the parts of an analogical argument.

Report this question

14"The brain is like a computer, so memories can be wiped perfectly like files." This analogy fails mainly because:

  1. Relevant dissimilarities exist between a brain and a computer
  2. It is a deductive argument
  3. The premises are numerous
  4. It is too short
Show answer and explanation

Answer: A. Relevant dissimilarities exist between a brain and a computer

A false analogy ignores relevant differences.
