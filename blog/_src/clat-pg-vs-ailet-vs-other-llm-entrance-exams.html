Quick answer
  • CLAT PG: Consortium of NLUs, reported 120 passage-based MCQs, 2 hours, -0.25. Feeds many NLUs.
  • AILET LLM: NLU Delhi only, reported 100 MCQs, 120 minutes, -0.25.
  • Other routes: university-specific tests, national tests or score-based admission, each with its own notice.
  • The syllabus overlaps heavily, so most aspirants prepare once and sit both.

"Should I do CLAT PG or AILET?" is usually the wrong question, because the preparation overlaps and the tests open different doors. A better one is which doors you want open. This guide compares the main LL.M. entrances, using patterns as reported. Every exam publishes its own notification each cycle, so confirm the details on the official sites before you apply.

Which is better for LLM, CLAT PG or AILET?

CLAT PG is the shared entrance for the participating National Law Universities, so one score can serve many applications. Its score is also used by some other institutions and public-sector recruiters. AILET is NLU Delhi's own test and leads to NLU Delhi's LL.M. only. If NLU Delhi is on your list, AILET is necessary. If you want a range of NLUs, CLAT PG is.

What other LLM entrance exams are there?

Beyond these two, LL.M. admission in India runs through several other routes:

  • University-specific tests run by individual central and state universities.
  • National test scores used by some universities, such as CUET PG, depending on the cycle.
  • Score or merit-based admission at some private universities, sometimes with an interview.

We do not list individual institutions here, because their routes change from year to year. Check each university's current notification for the test, eligibility and dates.

How to decide which exams to take

  1. List your target universities and note which test each accepts. Start with the participating NLUs.
  2. Check eligibility for each. See CLAT PG eligibility and the AILET LLM guide.
  3. Check dates in each notification so there is no clash, and budget the fees.
  4. Prepare the common core once: Constitutional Law, Jurisprudence, Criminal Law, Contract, Torts and the rest of the core subjects.
  5. Add exam-specific practice: passage drills for CLAT PG, and quick recall tests for AILET.

Preparing for both together

A sensible split is about 70 percent common law preparation and 30 percent exam-specific practice. Use the CLAT PG practice arena and the AILET practice arena, and see how long you need. Seats and fees differ by university, so also read NLU LLM seats and fees before you set your priorities.
