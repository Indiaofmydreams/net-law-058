About this question set

This set has 15 multiple-choice questions on Data Interpretation from the UGC NET Paper 1 syllabus, unit 7, Data Interpretation. Try each question first, then tap Show answer to check the key and read the explanation. 15 of the 15 questions carry a written explanation.

For the concepts and case law behind these questions, read the Data Interpretation notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

Topics in this set

  • General concepts (15)

15 practice questions with answers

1In a pie chart of 360°, 30% corresponds to:

  1. 90°
  2. 100°
  3. 108°
  4. 120°
Show answer and explanation

Answer: C. 108°

0.3 × 360.

Report this question

2The mean of 4, 8, 12, 16 is:

  1. 8
  2. 10
  3. 12
  4. 14
Show answer and explanation

Answer: B. 10

40 ÷ 4.

Report this question

3A bar chart is best suited for:

  1. Showing a trend over decades only
  2. Comparing categories
  3. Writing text
  4. Mapping places
Show answer and explanation

Answer: B. Comparing categories

Bars compare values.

Report this question

4A scatter plot shows:

  1. Relationship between two variables
  2. A timeline
  3. A family tree
  4. Parts of a whole
Show answer and explanation

Answer: A. Relationship between two variables

Points plotted on two axes.

Report this question

5A frequency polygon is derived from:

  1. A table of names
  2. A map
  3. A histogram
  4. A pie chart
Show answer and explanation

Answer: C. A histogram

Join midpoints of bar tops.

Report this question

6Data on religion or caste is:

  1. Interval
  2. Quantitative
  3. Continuous
  4. Qualitative
Show answer and explanation

Answer: D. Qualitative

Categorical data.

Report this question

7Height measured in centimetres is:

  1. Nominal data
  2. Qualitative data
  3. Discrete data
  4. Continuous data
Show answer and explanation

Answer: D. Continuous data

Can take any value in a range.

Report this question

8Number of students in a class is:

  1. Continuous data
  2. Discrete data
  3. Nominal data
  4. Ordinal data
Show answer and explanation

Answer: B. Discrete data

Countable whole numbers.

Report this question

9Cumulative frequency is obtained by:

  1. Adding frequencies successively
  2. Subtracting frequencies
  3. Multiplying frequencies
  4. Dividing frequencies
Show answer and explanation

Answer: A. Adding frequencies successively

Running total.

Report this question

10An ogive is a graph of:

  1. Class width
  2. Sample size
  3. Cumulative frequency
  4. Mode
Show answer and explanation

Answer: C. Cumulative frequency

Used to find median graphically.

Report this question

11Which measure is least affected by extreme values?

  1. Median
  2. Mean
  3. Sum
  4. Range
Show answer and explanation

Answer: A. Median

Median depends on position.

Report this question

12Secondary data is obtained from:

  1. Experiments
  2. Direct observation
  3. Existing sources such as reports and census
  4. The researcher's own survey
Show answer and explanation

Answer: C. Existing sources such as reports and census

Already collected data.

Report this question

13The Census in India is conducted every:

  1. 5 years
  2. 10 years
  3. 15 years
  4. 20 years
Show answer and explanation

Answer: B. 10 years

Decennial census.

Report this question

14Consider the statements: 1. The mean is affected by outliers. 2. The median is the middle value of ordered data.

  1. Only statement 1 is correct
  2. Only statement 2 is correct
  3. Both statements are correct
  4. Neither statement is correct
Show answer and explanation

Answer: C. Both statements are correct

Both are correct.

Report this question

15Assertion (A): Graphs make data easier to interpret.
Reason (R): Visual representation shows patterns and trends quickly.

  1. Both A and R are true, and R is the correct explanation of A
  2. Both A and R are true, but R is not the correct explanation of A
  3. A is true, but R is false
  4. A is false, but R is true
Show answer and explanation

Answer: A. Both A and R are true, and R is the correct explanation of A

R explains A.
