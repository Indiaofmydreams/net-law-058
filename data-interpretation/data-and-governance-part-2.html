About this question set

This set has 22 multiple-choice questions on Data and Governance from the UGC NET Paper 1 syllabus, unit 7, Data Interpretation. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Data Interpretation notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

22 practice questions with answers

1Under the Digital Personal Data Protection Act, 2023, the individual to whom the data relates is the:

  1. Data Fiduciary
  2. Data Processor
  3. Data Principal
  4. Data Auditor
Show answer

Answer: C. Data Principal

Report this question

2Under the same Act, the entity that decides the purpose and means of processing personal data is the:

  1. Data Principal
  2. Data Protection Board
  3. Data Subject
  4. Data Fiduciary
Show answer

Answer: D. Data Fiduciary

Report this question

3The right to privacy was declared a fundamental right in:

  1. Kesavananda Bharati case
  2. Maneka Gandhi case
  3. A.K. Gopalan case
  4. K.S. Puttaswamy v. Union of India
Show answer

Answer: D. K.S. Puttaswamy v. Union of India

  1. Only encrypting data
  2. Removing personal identifiers so individuals cannot be identified

7Data-driven decision-making means:

  2. Following precedent only

8Arrange the steps of a data-based policy cycle in order:
I. Collect and analyse relevant data
II. Identify the policy problem
III. Implement the policy
IV. Monitor and evaluate outcomes

  1. II, I, III, IV
  2. I, II, III, IV
  3. II, III, I, IV
  4. I, III, II, IV

Answer: A. II, I, III, IV
