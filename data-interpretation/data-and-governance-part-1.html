About this question set

This set has 23 multiple-choice questions on Data and Governance from the UGC NET Paper 1 syllabus, unit 7, Data Interpretation. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Data Interpretation notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

  2. Procurement through GeM
