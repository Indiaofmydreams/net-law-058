20 practice questions with answers

1Piaget's theory of cognitive development is called:

  1. Genetic Epistemology
  2. Connectionism
  3. Social Learning Theory
  4. Behaviourism
Show answer

Answer: A. Genetic Epistemology

Report this question

2"Schema" in Piaget's theory refers to:

  1. A grading system
  2. A classroom arrangement
  3. A lesson plan
  4. A mental framework or cognitive structure used to organise and interpret information
Show answer

Answer: D. A mental framework or cognitive structure used to organise and interpret information

Report this question

3When a child encounters new information that fits into an existing schema, the process is called:

  1. Equilibration
  2. Disequilibrium
  3. Assimilation
  4. Accommodation
Show answer

Answer: C. Assimilation

Report this question

4When a child modifies an existing schema or creates a new one to deal with new information that doesn't fit, the process is called:

  1. Equilibration
  2. Accommodation
  3. Centration
  4. Assimilation
Show answer

Answer: B. Accommodation

Report this question

5"Equilibration" in Piaget's theory is best described as:

  1. The drive to balance assimilation and accommodation to achieve cognitive stability
  2. Balance between teacher and student roles
  3. Equal distribution of grades
  4. Physical balance during motor development
Show answer

Answer: A. The drive to balance assimilation and accommodation to achieve cognitive stability

Report this question

6A child sees a horse for the first time and calls it a "big dog." This is an example of:

  1. Equilibration
  2. Assimilation
  3. Accommodation
  4. Disequilibrium
Show answer

Answer: B. Assimilation

Report this question

7The same child is corrected and learns the animal is a horse — a new category. This is an example of:

  1. Assimilation
  2. Equilibration
  3. Centration
  4. Accommodation
Show answer

Answer: D. Accommodation

Report this question

8The Sensorimotor stage of Piaget spans which age range?

  1. 0–2 years
  2. 2–7 years
  3. 7–11 years
  4. 12 years and above
Show answer

Answer: A. 0–2 years

Report this question

9"Object permanence" is a milestone achieved during which Piagetian stage?

  1. Formal Operational
  2. Concrete Operational
  3. Preoperational
  4. Sensorimotor
Show answer

Answer: D. Sensorimotor

Report this question

10A 4-year-old child insists that a tall thin glass has more water than a short wide glass even after watching the water being poured from one to the other. This demonstrates lack of:

  1. Conservation
  2. Object permanence
  3. Seriation
  4. Hypothetical reasoning
Show answer

Answer: A. Conservation

Report this question

11The inability of a child in the Preoperational stage to see the world from another's point of view is called:

  1. Irreversibility
  2. Animism
  3. Centration
  4. Egocentrism
Show answer

Answer: D. Egocentrism

Report this question

12"Animism" in the Preoperational stage refers to:

  1. Understanding of ecosystems
  2. Interest in animals
  3. Fear of death
  4. Attributing life and feelings to inanimate objects
Show answer

Answer: D. Attributing life and feelings to inanimate objects

Report this question

13A child in the Concrete Operational stage can:

  1. Perform logical operations on concrete objects and understand conservation
  2. Only imitate what they see
  3. Think abstractly and hypothetically
  4. Form no logical relationships
Show answer

Answer: A. Perform logical operations on concrete objects and understand conservation

Report this question

14Which Piagetian concept describes a child's tendency to focus on only one aspect of a situation while ignoring others?

  1. Centration
  2. Irreversibility
  3. Egocentrism
  4. Animism
Show answer

Answer: A. Centration

Report this question

15"Seriation" is the ability to:

  1. Understand language sequence
  2. Arrange objects in a logical order such as by size or weight
  3. Classify objects by colour only
  4. Memorise serial numbers
Show answer

Answer: B. Arrange objects in a logical order such as by size or weight

Report this question

16The educational implication of Piaget's theory that is MOST directly applied in primary school teaching is:

  1. Advancing all students at the same pace
  2. Teaching all concepts verbally
  3. Using concrete materials, hands-on activities, and discovery learning before introducing abstract concepts
  4. Using abstract symbols before concrete materials
Show answer

Answer: C. Using concrete materials, hands-on activities, and discovery learning before introducing abstract concepts

Report this question

17According to Piaget, a teacher's role is primarily that of:

  1. Examiner
  2. Facilitator who creates an enriched environment for the child to discover and construct knowledge
  3. Disciplinarian
  4. Information giver
Show answer

Answer: B. Facilitator who creates an enriched environment for the child to discover and construct knowledge

Report this question

18Piaget's concept of "readiness" implies that:

  1. All children are ready to learn anything at any age
  2. Children should be ready before they come to school
  3. Learning should be matched to the child's current stage of cognitive development — teaching too early is ineffective
  4. Readiness is determined by IQ alone
Show answer

Answer: C. Learning should be matched to the child's current stage of cognitive development — teaching too early is ineffective

Report this question

19A university professor is teaching research methodology. According to Piaget, students at this level should be in which stage and capable of what?

  1. Concrete Operational — using physical objects
  2. Formal Operational — abstract reasoning, hypothesis formation, and deductive logic
  3. Preoperational — learning through play
  4. Sensorimotor — learning through physical action
Show answer

Answer: B. Formal Operational — abstract reasoning, hypothesis formation, and deductive logic

Report this question

20Piaget differed from Vygotsky primarily in that:

  1. Piaget emphasised social interaction; Vygotsky emphasised individual discovery
  2. Piaget rejected the concept of stages
  3. Both held identical views
  4. Piaget emphasised individual cognitive development through stages; Vygotsky emphasised social and cultural context in learning
Show answer

Answer: D. Piaget emphasised individual cognitive development through stages; Vygotsky emphasised social and cultural context in learning
