15 practice questions with answers

1Edgar Dale's "Cone of Experience" places which experience at the BASE (most concrete)?

  1. Verbal symbols
  2. Visual symbols
  3. Radio/television
  4. Direct purposeful experience
Show answer and explanation

Answer: D. Direct purposeful experience

Concept: Most concrete = bottom of cone = best retention. Most abstract = top (verbal symbols). Bottom = Do. Middle = Observe. Top = Abstract symbols.

Report this question

2According to Dale's Cone of Experience, verbal symbols (words, text) are placed at:

  1. Middle — moderate abstraction
  2. Outside the cone entirely
  3. Bottom — most concrete
  4. Top — most abstract
Show answer and explanation

Answer: D. Top — most abstract

Concept: Traditional teaching relies most heavily on verbal symbols (lectures, textbooks) — ironically the LEAST effective for retention per Dale.

Report this question

3Computer-Assisted Instruction (CAI) includes which of the following modes?

  1. Blackboard, Flannel board, Bulletin board
  2. Lecture, Seminar, Discussion, Project
  3. Drill, Tutorial, Simulation, Game
  4. Television, Radio, OHP, Charts
Show answer and explanation

Answer: C. Drill, Tutorial, Simulation, Game

Concept: CAI modes — students interact with computer programs. Drill = practice. Tutorial = guided learning. Simulation = virtual lab. Game = motivation.

4INFLIBNET stands for:

  1. Indian National Facility for Library Integration
  2. Institutional Framework for Library and Net Access
  3. Integrated Library and Network for India
  4. Information and Library Network
Show answer and explanation

Answer: D. Information and Library Network

Concept: INFLIBNET = UGC initiative for inter-university library connectivity. Provides access to e-journals, e-books to university researchers.

Report this question

5NDLI stands for:

  1. Network for Digital Library Infrastructure
  2. National Distance Learning Initiative
  3. National Digital Library of India
  4. National Data and Learning Institute
Show answer and explanation

Answer: C. National Digital Library of India

Concept: NDLI = single-window portal for digital educational resources from school to research level. IIT Kharagpur manages it.

6A Smart Board / Interactive Whiteboard is an example of which category of teaching aid?

  1. ICT-based teaching aid
  2. Audio aid only
  3. Non-projected visual aid
  4. Traditional aid
Show answer and explanation

Answer: A. ICT-based teaching aid

Concept: Smart boards combine touch screen, internet, projector = ICT-based. They allow real-time interaction and multimedia.

7LMS (Learning Management System) examples include:

  1. Moodle, Blackboard, Canvas
  2. MS Word, Excel, PowerPoint
  3. Google Maps, YouTube, WhatsApp
  4. MATLAB, SPSS, Python
Show answer and explanation

Answer: A. Moodle, Blackboard, Canvas

Concept: LMS = digital platform to manage, deliver, track learning. Moodle is the most popular open-source LMS.

Report this question

8Which of the following is a NON-projected teaching aid?

  1. Slide Projector
  2. LCD Projector
  3. Blackboard
  4. OHP
Show answer and explanation

Answer: C. Blackboard

Concept: Non-projected = no projection needed = blackboard, charts, models, specimens. Projected = requires light projection device.

9Computer Adaptive Testing (CAT) means:

  1. Tests are taken on a computer
  2. The difficulty of questions adjusts dynamically based on the test-taker's previous responses
  3. Tests are corrected by computer software
  4. The computer randomly selects questions
Show answer and explanation

Answer: B. The difficulty of questions adjusts dynamically based on the test-taker's previous responses

Concept: CAT is the most sophisticated form of CBT. If you answer correctly, next question is harder; if wrong, easier. GRE uses CAT.

10ICT in education stands for:

  1. Integrated Curriculum and Teaching
  2. Interactive Classroom Technology
  3. Instructional Content and Technology
  4. Information and Communication Technology
Show answer and explanation

Answer: D. Information and Communication Technology

Concept: ICT = umbrella term for all digital tools in education. Internet, computers, mobile devices, multimedia = ICT.

11The OHP (Overhead Projector) projects:

  1. Live video feeds
  2. Transparencies / acetate sheets
  3. Slide films
  4. Digital presentations
Show answer and explanation

Answer: B. Transparencies / acetate sheets

Concept: OHP = traditional projected aid using transparent sheets. Now largely replaced by LCD projectors. Still asked in NET.

Report this question

12Which of the following best describes E-Learning?

  1. Learning in an electric-lit classroom
  2. Learning using electrical engineering tools
  3. Learning facilitated by electronic technology, especially internet-based delivery
  4. Learning using electronic textbooks only
Show answer and explanation

Answer: C. Learning facilitated by electronic technology, especially internet-based delivery

Concept: E-Learning = broad term covering online courses, digital content, virtual classrooms, CBT, MOOCs.

Report this question

13Virtual classroom differs from a traditional classroom primarily in:

  1. Size of the group
  2. Physical co-presence is replaced by digital connectivity
  3. The absence of a teacher
  4. There is no interaction
Show answer and explanation

Answer: B. Physical co-presence is replaced by digital connectivity

Concept: Virtual = synchronous online = same time, different place. Zoom/Google Meet = virtual classroom platforms.

Report this question

14Which teaching aid is most effective for teaching abstract concepts in science?

  1. Lecture alone
  2. Models and specimens (3D)
  3. Charts
  4. Textbooks
Show answer and explanation

Answer: B. Models and specimens (3D)

Concept: Dale's Cone — 3D models = more concrete than 2D charts or text. Abstract science concepts become tangible.

15Podcast as a teaching tool primarily addresses which type of learner?

  1. Auditory learner
  2. Visual learner
  3. Read/Write learner
  4. Kinesthetic learner
Show answer and explanation

Answer: A. Auditory learner

Concept: Podcast = audio-only = auditory learner advantage. VARK model: Visual, Auditory, Reading/Writing, Kinesthetic.
