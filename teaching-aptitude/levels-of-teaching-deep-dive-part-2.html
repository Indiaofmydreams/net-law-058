About this question set

This set has 15 multiple-choice questions on Levels of Teaching: Deep Dive from the UGC NET Paper 1 syllabus, unit 1, Teaching Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 15 of the 15 questions carry a written explanation.

For the concepts and case law behind these questions, read the Teaching Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

15 practice questions with answers

1At the Memory level, forgetting is:

  1. Non-existent
  2. Permanent retention
  3. Rapid, especially without rehearsal
  4. Slow and gradual
Show answer and explanation

Answer: C. Rapid, especially without rehearsal

Concept: Rote-learned material without meaning decays rapidly (Ebbinghaus forgetting curve). Meaningful learning (Understanding/Reflective) is retained far longer.

Report this question

2"The learner at the reflective level uses past experience as raw material for creating new knowledge" — this view is most consistent with:

  1. Essentialism
  2. Constructivism
  3. Behaviourism
  4. Perennialism
Show answer and explanation

Answer: B. Constructivism

Concept: Constructivism = prior knowledge + experience → new knowledge construction. Reflective level = constructivist ideal.

Report this question

3Which of the following correctly describes the TEACHER'S role at each level?

  1. Memory = Facilitator; Understanding = Transmitter; Reflective = Examiner
  2. Memory = Transmitter; Understanding = Guide; Reflective = Facilitator/Co-inquirer
  3. Memory = Co-inquirer; Understanding = Transmitter; Reflective = Guide
  4. All three levels require the same teacher role
Show answer and explanation

Answer: B. Memory = Transmitter; Understanding = Guide; Reflective = Facilitator/Co-inquirer

Concept: As levels rise, teacher's role shifts from active transmitter to passive facilitator. This shift is a recurring NET question pattern.

Report this question

4The question "Can you give me an example of Newton's third law from your daily life?" tests the student at:

  1. Pure Reflective level
  2. Understanding and Application level
  3. Memory level
  4. Psychomotor level
Show answer and explanation

Answer: B. Understanding and Application level

Concept: Generating own examples = demonstrating understanding + applying concept to real context. Higher than recall, not yet full reflective inquiry.

Report this question

5Which level of teaching best prepares learners for research?

  1. Memory level
  2. Understanding level
  3. Reflective level
  4. All levels equally
Show answer and explanation

Answer: C. Reflective level

Concept: Research = original inquiry, hypothesis formation, critical analysis = exactly what Reflective level develops. Memory and Understanding are prerequisites, not sufficient.

Report this question

6Teaching that remains confined to the Memory level in higher education is criticised because:

  1. It fails to develop independent thinking and produces intellectually passive graduates
  2. It requires too much time
  3. It is too difficult for students
  4. It overloads the teacher
Show answer and explanation

Answer: A. It fails to develop independent thinking and produces intellectually passive graduates

Concept: Paulo Freire called this "banking education." Rote-focused higher education produces dependent, uncritical thinkers — the opposite of what universities should produce.

Report this question

7The concept of "Bloom's Taxonomy" and "Levels of Teaching" (Morrison) are related in that:

  1. Both describe qualitative progression in cognitive demand — from lower to higher order thinking
  2. They deal with different domains entirely
  3. They are contradictory frameworks
  4. Bloom applies only to school; Morrison applies only to university
Show answer and explanation

Answer: A. Both describe qualitative progression in cognitive demand — from lower to higher order thinking

Concept: Memory ≈ Remember/Understand. Understanding ≈ Apply/Analyse. Reflective ≈ Evaluate/Create. The two frameworks are complementary.

Report this question

8"Insight learning" described by Kohler through his ape experiments is most relevant to which level of teaching?

  1. Memory level
  2. Understanding level
  3. Reflective level
  4. None of the above
Show answer and explanation

Answer: B. Understanding level

Concept: Kohler's ape (Sultan) suddenly grasped the solution to reach a banana = insight = sudden reorganisation of perception = Understanding level. Reflective goes further — creating solutions to completely novel problems.

Report this question

9A teacher who only asks factual recall questions throughout a semester is:

  1. Limiting students to the Memory level of learning
  2. Following constructivist principles
  3. Promoting reflective thinking
  4. Practising excellent higher education pedagogy
Show answer and explanation

Answer: A. Limiting students to the Memory level of learning

Concept: Question type determines level of cognitive engagement. Only factual questions = Memory level ceiling for students.

Report this question

10Which teaching level is MOST associated with "surface learning"?

  1. Memory level
  2. Application level
  3. Reflective level
  4. Understanding level
Show answer and explanation

Answer: A. Memory level

Concept: Surface learning (Marton & Säljö) = rote, reproduction, no depth = Memory level. Deep learning = meaning-making = Understanding. Deepest = Reflective.

Report this question

11At the reflective level, students are expected to demonstrate:

  1. Originality, synthesis of multiple sources, and critical evaluation
  2. Speed of recall
  3. Compliance with teacher's views
  4. Handwriting quality
Show answer and explanation

Answer: A. Originality, synthesis of multiple sources, and critical evaluation

Concept: Reflective = Create + Evaluate in Bloom's terms. Original thought, multiple perspectives, independent judgement.

Report this question

12Morrison's "Understanding Level" corresponds most closely to which of Ausubel's concepts?

  1. Discovery learning
  2. Meaningful verbal learning
  3. Social learning
  4. Rote learning
Show answer and explanation

Answer: B. Meaningful verbal learning

Concept: Ausubel's meaningful learning = new information anchored to existing cognitive structure (assimilation). This is exactly what Understanding level achieves — making content meaningful.

Report this question

13The MINIMUM level of teaching that is acceptable for higher education, according to educational standards, is:

  1. Memory level
  2. Reflective level
  3. No minimum standard exists
  4. Understanding level
Show answer and explanation

Answer: D. Understanding level

Concept: Memory level is considered insufficient for university education. Understanding level is the minimum acceptable; Reflective is the ideal. This is a value-laden but commonly tested position in NET.

Report this question

14"Deep learning" in higher education, as described by researchers like Marton, Biggs, and Entwistle, is MOST closely aligned with:

  1. Memory level
  2. Understanding and Reflective levels
  3. Examination-focused learning
  4. Drill and practice
Show answer and explanation

Answer: B. Understanding and Reflective levels

Concept: Deep approach = intention to understand + relating ideas + critical evaluation = Understanding + Reflective. Surface approach = Memory level.

Report this question

15Which of the following classroom scenarios represents a SHIFT from Understanding level to Reflective level?

  1. Teacher explains a concept; students listen
  2. Students use a concept to explain a new real-world problem they have never encountered in class
  3. Teacher gives a quiz on previously taught content
  4. Students discuss a concept in groups
Show answer and explanation

Answer: B. Students use a concept to explain a new real-world problem they have never encountered in class

Concept: Novel problem + transfer + independent application = Reflective level. Discussion alone = Understanding. Novel = the key word for Reflective.
