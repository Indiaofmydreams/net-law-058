About this question set

This set has 24 multiple-choice questions on Evaluation Systems from the UGC NET Paper 1 syllabus, unit 1, Teaching Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 24 of the 24 questions carry a written explanation.

For the concepts and case law behind these questions, read the Teaching Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

24 practice questions with answers

1Who is called the "Father of Evaluation" in education?

  1. Benjamin Bloom
  2. Ralph Tyler
  3. Lee Cronbach
  4. Michael Scriven
Show answer and explanation

Answer: B. Ralph Tyler

Concept: Tyler's Rationale (1949) = first systematic model of curriculum and evaluation. Evaluation = measuring achievement of objectives.

Report this question

2The terms "Formative" and "Summative" evaluation were coined by:

  1. Michael Scriven
  2. Benjamin Bloom
  3. Lee Cronbach
  4. Ralph Tyler
Show answer and explanation

Answer: A. Michael Scriven

Concept: Scriven coined both terms in 1967. Tyler = father of evaluation, but Scriven = formative/summative distinction.

Report this question

3Summative evaluation is primarily used for:

  1. Improving instruction while it is in progress
  2. Diagnosing learning difficulties
  3. Placing students in appropriate courses
  4. Certifying, grading, and ranking students
Show answer and explanation

Answer: D. Certifying, grading, and ranking students

Concept: Summative = final, certifying, high-stakes. End-semester exam = summative. No improvement loop.

Report this question

4Diagnostic evaluation is conducted to:

  1. Identify and analyse the causes of persistent learning difficulties
  2. Certify student performance
  3. Measure end-of-course achievement
  4. Place students in groups
Show answer and explanation

Answer: A. Identify and analyse the causes of persistent learning difficulties

Concept: Diagnostic goes DEEPER than formative — finds WHY a student struggles, not just that they struggle. Used for remediation.

Report this question

5Placement evaluation is used to:

  1. Evaluate teachers
  2. Certify completion of a degree
  3. Determine the appropriate level, group, or course for a learner before instruction
  4. Provide mid-course feedback
Show answer and explanation

Answer: C. Determine the appropriate level, group, or course for a learner before instruction

Concept: Placement = entry behaviour test. Conducted BEFORE instruction. Used for streaming, grouping, readiness assessment.

Report this question

6In Norm-Referenced Evaluation (NRE), a student's performance is compared to:

  1. A pre-set standard or criterion
  2. The performance of the peer group (norm)
  3. The teacher's expectations
  4. Their own previous performance
Show answer and explanation

Answer: B. The performance of the peer group (norm)

Concept: NRE = competitive, creates rank, percentile. Normal distribution expected. Competitive entrance exams = NRE.

Report this question

7In Criterion-Referenced Evaluation (CRE), success is determined by:

  1. Getting the highest marks in the class
  2. Teacher's subjective judgement
  3. Achieving a pre-defined standard of performance
  4. Ranking higher than peers
Show answer and explanation

Answer: C. Achieving a pre-defined standard of performance

Concept: CRE = mastery model. Pass/fail based on criterion, not class average. Driving test, NET qualifying score = CRE.

Report this question

8Which type of evaluation best suits Mastery Learning?

  1. Norm-Referenced Evaluation
  2. Placement Evaluation
  3. Criterion-Referenced Evaluation
  4. Summative Evaluation
Show answer and explanation

Answer: C. Criterion-Referenced Evaluation

Concept: Mastery = reach criterion = CRE. Not about rank. Bloom's Mastery Learning Model uses CRE.

Report this question

9CBCS (Choice Based Credit System) was introduced by UGC in Indian universities from:

  1. 2015
  2. 2010
  3. 2020
  4. 2005
Show answer and explanation

Answer: A. 2015

Concept: UGC introduced CBCS from 2015–16. It replaced the traditional annual/semester exam-only system with credit-based grading.

Report this question

10In CBCS, SGPA stands for:

  1. Semester Grade Point Average
  2. Subject Grade Performance Assessment
  3. Standard Grade Point Achievement
  4. Standardised Grade Point Analysis
Show answer and explanation

Answer: A. Semester Grade Point Average

Concept: SGPA = GPA for one semester. CGPA = cumulative across all semesters. UGC uses a 10-point grading scale.

Report this question

11In UGC's 10-point grading scale under CBCS, Grade "O" (Outstanding) corresponds to:

  1. 8 grade points
  2. 9 grade points
  3. 7 grade points
  4. 10 grade points
Show answer and explanation

Answer: D. 10 grade points

Mnemonic: O=10, A+=9, A=8, B+=7, B=6, C=5, P=4, F=0 → "Outstanding tops the 10-point scale"

Report this question

12Portfolio assessment is best described as:

  1. A single high-stakes examination
  2. A peer assessment tool
  3. A collection of student's work over time that demonstrates growth and achievement
  4. A standardised multiple-choice test
Show answer and explanation

Answer: C. A collection of student's work over time that demonstrates growth and achievement

Concept: Portfolio = ongoing, holistic, authentic. Shows progress not just a snapshot. Used in arts, writing, professional courses.

Report this question

13Authentic Assessment involves:

  1. Online automated testing
  2. Assessment by external examiners only
  3. Traditional written examinations only
  4. Assessment through real-world tasks that mirror actual application
Show answer and explanation

Answer: D. Assessment through real-world tasks that mirror actual application

Concept: Authentic = performance-based = projects, demonstrations, presentations. Tests what students can DO, not just recall.

Report this question

14Rubric in assessment means:

  1. A set of criteria with descriptors for different performance levels
  2. A grading curve
  3. A teacher's mark book
  4. A multiple-choice answer sheet
Show answer and explanation

Answer: A. A set of criteria with descriptors for different performance levels

Concept: Rubric = scoring guide. Makes assessment transparent, consistent, criterion-referenced. Reduces subjectivity.

Report this question

15Open Book Examination (OBE) primarily tests:

  1. Handwriting and presentation
  2. Speed of writing
  3. Higher-order thinking — application, analysis, evaluation
  4. Memorisation and recall
Show answer and explanation

Answer: C. Higher-order thinking — application, analysis, evaluation

Concept: If books are allowed, mere recall is useless. Only HOTS questions are meaningful = OBE promotes Bloom's higher levels.

Report this question

16Continuous and Comprehensive Evaluation (CCE) was introduced by:

  1. AICTE for technical education
  2. MCI for medical education
  3. UGC for universities
  4. NCERT/CBSE for school education
Show answer and explanation

Answer: D. NCERT/CBSE for school education

Concept: CCE = formative + summative + scholastic + co-scholastic. Introduced in school education. Holistic assessment approach.

Report this question

17Which of the following statements about Outcome-Based Education (OBE) is correct?

  1. OBE focuses on content coverage, not learning results
  2. OBE defines learning outcomes first, then aligns curriculum, teaching, and assessment to achieve them
  3. OBE uses only summative evaluation
  4. OBE ignores student performance
Show answer and explanation

Answer: B. OBE defines learning outcomes first, then aligns curriculum, teaching, and assessment to achieve them

Concept: OBE = backward design. Start with outcomes → design curriculum → assess achievement. Central to NEP 2020 and NAAC.

Report this question

18The difference between "measurement" and "evaluation" is:

  1. They are identical processes
  2. Measurement assigns numbers; evaluation involves interpretation and value judgement
  3. Evaluation comes before measurement
  4. Measurement involves qualitative judgement; evaluation is quantitative
Show answer and explanation

Answer: B. Measurement assigns numbers; evaluation involves interpretation and value judgement

Concept: Measurement = quantification (score). Assessment = interpretation. Evaluation = judgement of worth. Evaluation is broadest.

Report this question

19UGC NET examination conducted by NTA is an example of which type of evaluation?

  1. Portfolio-based
  2. Diagnostic
  3. Formative
  4. Criterion-Referenced and Summative
Show answer and explanation

Answer: D. Criterion-Referenced and Summative

Concept: NET = final, certifying (Summative) + based on qualifying cut-off (Criterion-Referenced). Both apply.

Report this question

20Self-assessment in education primarily promotes:

  1. Summative grading
  2. Metacognition and learner autonomy
  3. Teacher's efficiency
  4. Competitive ranking
Show answer and explanation

Answer: B. Metacognition and learner autonomy

Concept: Self-assessment = learners judge own work = metacognition = reflects on own thinking. Aligns with Andragogy (self-direction).

Report this question

21Peer assessment means:

  1. Teachers assessing each other
  2. Automated computer assessment
  3. External evaluators assessing students
  4. Students assessing fellow students' work using defined criteria
Show answer and explanation

Answer: D. Students assessing fellow students' work using defined criteria

Concept: Peer assessment = collaborative, develops critical thinking, communication, and metacognition. Common in higher education.

Report this question

22Which of the following is an innovation in evaluation most aligned with NEP 2020?

  1. Annual examinations only
  2. Elimination of internal assessment
  3. Multiple exit options with certificates, diplomas, degrees
  4. Single entrance test for all courses
Show answer and explanation

Answer: C. Multiple exit options with certificates, diplomas, degrees

Concept: NEP 2020 introduced multiple entry-exit in 4-year degree programs. 1 year = Certificate, 2 years = Diploma, 3 years = Degree, 4 years = Honours.

Report this question

23Which evaluation type is conducted BEFORE instruction to assess entry behaviour?

  1. Summative
  2. Diagnostic
  3. Formative
  4. Placement
Show answer and explanation

Answer: D. Placement

Concept: Placement = before = entry assessment. Diagnostic = during = difficulty analysis. Formative = during = improvement. Summative = after = certification.

Report this question

24The National Assessment and Accreditation Council (NAAC) assesses universities on how many criteria?

  1. 7
  2. 8
  3. 5
  4. 6
Show answer and explanation

Answer: A. 7

Concept: NAAC's 7 criteria: 1-Curricular Aspects, 2-Teaching-Learning, 3-Research, 4-Infrastructure, 5-Student Support, 6-Governance, 7-Institutional Values. Often tested.
