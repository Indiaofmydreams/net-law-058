22 practice questions with answers

1Rubric-based assessment improves evaluation by:

  1. Eliminating the need for teachers
  2. Making it faster for teachers
  3. Making assessment transparent, consistent, criterion-based, and reducing subjectivity
  4. Automatically computing grades
Show answer and explanation

Answer: C. Making assessment transparent, consistent, criterion-based, and reducing subjectivity

Concept: Rubric = scoring guide with criteria + performance descriptors. Students know in advance what "excellent" vs. "adequate" looks like. Reduces teacher bias and inconsistency.

Report this question

2A student receives a rubric before submitting an assignment. The pedagogical benefit is:

  1. The rubric reduces the assignment's difficulty
  2. The student understands the expected standards, can self-assess, and direct their effort accordingly
  3. The student knows the teacher's preferences
  4. The student can negotiate marks
Show answer and explanation

Answer: B. The student understands the expected standards, can self-assess, and direct their effort accordingly

Applied concept: Rubric shared in advance = transparency + self-regulation + goal clarity. Student work improves because expectations are explicit. Aligns with Assessment FOR and AS Learning.

Report this question

3Continuous and Comprehensive Evaluation (CCE) is described as "comprehensive" because:

  1. It assesses both scholastic (academic) and co-scholastic (values, attitudes, co-curricular) aspects of student development
  2. It covers all subjects
  3. It requires comprehensive written examinations
  4. It is very long
Show answer and explanation

Answer: A. It assesses both scholastic (academic) and co-scholastic (values, attitudes, co-curricular) aspects of student development

Concept: CCE = comprehensive = beyond academics. Includes personality, values, participation, sports, arts. Aims for holistic assessment consistent with affective and psychomotor domains.

Report this question

4CCE is described as "continuous" because:

  1. Assessment is spread throughout the academic year through multiple tools, not concentrated in one final exam
  2. Teachers evaluate continuously without rest
  3. The examination hall is open continuously
  4. Students are tested every minute
Show answer and explanation

Answer: A. Assessment is spread throughout the academic year through multiple tools, not concentrated in one final exam

Concept: Continuous = distributed across time = reduces exam pressure = reduces rote preparation for one high-stakes event = promotes sustained learning.

Report this question

5"Authentic assessment" is most closely aligned with which level of Bloom's taxonomy?

  1. Understand only
  2. No alignment with Bloom's
  3. Remember only
  4. Higher order levels — Apply, Analyse, Evaluate, Create — using real-world tasks
Show answer and explanation

Answer: D. Higher order levels — Apply, Analyse, Evaluate, Create — using real-world tasks

Concept: Authentic = real-world performance. MCQ recall tests = Remember. Authentic tasks = demonstrate HOTS. Performance-based, project-based, case-based = authentic.

Report this question

6A medical student is assessed by performing a clinical examination on a patient under supervision. This is:

  1. Authentic/Performance-based assessment
  2. Placement evaluation
  3. Formative written examination
  4. Norm-referenced pencil test
Show answer and explanation

Answer: A. Authentic/Performance-based assessment

Applied concept: Real patient + real clinical skill = authentic. Tests what the student can actually DO, not just what they know about doing it. Most valid form of professional assessment.

Report this question

7Which of the following statements about formative evaluation is INCORRECT?

  1. It occurs during the learning process
  2. It helps teachers adjust instruction
  3. It provides feedback for improvement
  4. It results in final grades and certificates
Show answer and explanation

Answer: D. It results in final grades and certificates

Concept: This is what summative evaluation does, NOT formative. Formative = no high-stakes grade. Formative = feedback only. Classic trap question.

Report this question

8Self-evaluation by students promotes which of the following?

  1. Teacher dependency
  2. Norm-referenced comparison
  3. Competitive behaviour
  4. Metacognition, self-regulation, and ownership of learning
Show answer and explanation

Answer: D. Metacognition, self-regulation, and ownership of learning

Concept: Self-evaluation = student judges own work = metacognition (thinking about learning) = self-regulation = andragogy principle of self-direction. Highest form of learner autonomy.

Report this question

9"Inter-rater reliability" in evaluation refers to:

  1. The degree of agreement between two or more independent evaluators assessing the same work
  2. Reliability of online examination platforms
  3. The consistency of one rater across different occasions
  4. The relationship between evaluation and examination
Show answer and explanation

Answer: A. The degree of agreement between two or more independent evaluators assessing the same work

Concept: Inter-rater reliability = if two teachers grade the same essay independently, do they give similar marks? Low inter-rater reliability = subjective, unfair. Rubrics improve inter-rater reliability.

Report this question

10The concept of "washback" is MOST relevant to which type of evaluation?

  1. Self-assessment
  2. Portfolio assessment
  3. Peer evaluation
  4. High-stakes summative examinations that shape curriculum and teaching
Show answer and explanation

Answer: D. High-stakes summative examinations that shape curriculum and teaching

Concept: High-stakes exams have most powerful washback. If NET tests only recall → coaching institutes teach only recall. If NET tested critical thinking → pedagogy would shift.

Report this question

11Evaluation in the "Choice Based Credit System" is innovative because:

  1. It uses only oral examination
  2. It combines continuous internal assessment with end-semester examination, uses grade points instead of percentages, and includes diverse assessment tools
  3. It uses only one final examination
  4. It eliminates all examinations
Show answer and explanation

Answer: B. It combines continuous internal assessment with end-semester examination, uses grade points instead of percentages, and includes diverse assessment tools

Concept: CBCS evaluation = hybrid. Internal (assignments, mid-term, projects) + external (end-semester) = grade point = no single high-stakes moment.

Report this question

12Which of the following is an "innovation in evaluation systems" as per UGC NET syllabus?

  1. Traditional annual examinations
  2. Open book examination, portfolio assessment, peer assessment, computer-adaptive testing
  3. Oral viva alone
  4. Only MCQ-based tests
Show answer and explanation

Answer: B. Open book examination, portfolio assessment, peer assessment, computer-adaptive testing

Concept: Innovations = move away from closed-book, single-sitting, marks-based traditional exams toward diverse, performance-based, technology-enabled, learner-centred approaches.

Report this question

13Open Book Examination (OBE) is primarily a test of:

  1. Ability to locate information quickly
  2. Higher-order thinking — applying, analysing, evaluating information from the books
  3. Memory and recall
  4. Speed of reading
Show answer and explanation

Answer: B. Higher-order thinking — applying, analysing, evaluating information from the books

Concept: OBE design must have HOTS questions. If questions can be answered by simply copying from the book, OBE fails its purpose. Good OBE = synthesis + evaluation questions.

Report this question

14Which type of evaluation is most useful for a university wanting to improve its teaching-learning processes continuously?

  1. Summative evaluation of students once per year
  2. Increasing the difficulty of examinations
  3. External inspection only
  4. A combination of formative evaluation (ongoing feedback) and institutional self-assessment
Show answer and explanation

Answer: D. A combination of formative evaluation (ongoing feedback) and institutional self-assessment

Applied concept: Continuous improvement = formative philosophy applied at institutional level. NAAC's Internal Quality Assurance Cell (IQAC) = institutional formative evaluation.

Report this question

15The NAAC's Internal Quality Assurance Cell (IQAC) in a university functions as:

  1. An internal formative evaluation mechanism for continuously monitoring and improving institutional quality
  2. A financial audit committee
  3. The external examination board
  4. A disciplinary committee
Show answer and explanation

Answer: A. An internal formative evaluation mechanism for continuously monitoring and improving institutional quality

Concept: IQAC = UGC mandate = every NAAC-accredited institution must have IQAC. Functions like institutional formative evaluation — ongoing feedback, Annual Quality Assurance Reports (AQAR).

Report this question

16"360-degree assessment" or "multi-source feedback" in educational evaluation involves:

  1. Feedback gathered from multiple sources — teacher, peers, self, and sometimes alumni or employers
  2. Students assessed only by their teacher
  3. Assessment at 360-degree camera angles
  4. Assessment in all 360 classrooms of a university
Show answer and explanation

Answer: A. Feedback gathered from multiple sources — teacher, peers, self, and sometimes alumni or employers

Concept: 360-degree = multiple perspectives. Teacher alone = limited view. Peer + self + teacher + external = comprehensive picture of learner development. Used in professional education.

Report this question

17Outcome-Based Education (OBE) links evaluation to:

  1. Achievement of clearly defined learning outcomes — assessment is aligned to outcomes
  2. Teacher's personal judgement
  3. Attendance records
  4. Time spent in classroom
Show answer and explanation

Answer: A. Achievement of clearly defined learning outcomes — assessment is aligned to outcomes

Concept: OBE's constructive alignment (Biggs) — Define outcome → Design teaching → Assess achievement of that outcome. Assessment validity = how well it measures the stated outcome.

Report this question

18A university designs its examinations by first listing what graduates should be able to DO on completion, and then working backward to design curriculum and assessment. This approach is called:

  1. Norm-referenced design
  2. Tyler's content-centred rationale
  3. Backward design / Outcome-Based Education
  4. Traditional content-based design
Show answer and explanation

Answer: C. Backward design / Outcome-Based Education

Concept: Backward design (Wiggins & McTighe, 1998) = start with end goal (outcomes) → design assessment → design instruction. OBE uses this logic. NEP 2020 mandates this.

Report this question

19A student consistently scores 65% in internal assessments but fails the end-semester examination. A teacher who uses this information to provide targeted help before the next semester is applying:

  1. Norm-referenced comparison
  2. Diagnostic and formative information to improve future learning outcomes
  3. Summative evaluation for grading
  4. Placement evaluation
Show answer and explanation

Answer: B. Diagnostic and formative information to improve future learning outcomes

Applied concept: Using assessment data to identify and address a specific learning gap = diagnostic + formative use of data. The teacher is functioning as a responsive, data-driven educator.

Report this question

20"Evaluation anxiety" in students is most likely caused by:

  1. Portfolio assessment
  2. Too much formative feedback
  3. Peer evaluation
  4. Overemphasis on high-stakes summative examinations as the sole determinant of academic worth
Show answer and explanation

Answer: D. Overemphasis on high-stakes summative examinations as the sole determinant of academic worth

Concept: Single high-stakes exam = all eggs in one basket = extreme anxiety. Diversified evaluation (CCE, portfolio, formative) = distributes pressure = reduces anxiety = promotes learning.

Report this question

21Which of the following correctly describes the relationship between evaluation and teaching?

  1. Evaluation is integral to teaching — it informs, guides, and improves teaching before, during, and after instruction
  2. Evaluation replaces teaching in higher education
  3. Evaluation is a post-teaching activity only
  4. Evaluation and teaching are completely separate activities
Show answer and explanation

Answer: A. Evaluation is integral to teaching — it informs, guides, and improves teaching before, during, and after instruction

Concept: Modern view = evaluation embedded throughout the teaching-learning cycle. Pre-instruction (placement) + during (formative) + after (summative) = continuous loop of improvement.

Report this question

22A teacher who reflects: "My students struggled with application questions in the test — I need to redesign my teaching to include more problem-solving activities next time" is demonstrating:

  1. Summative evaluation mindset
  2. Placement evaluation practice
  3. The correct use of evaluation data for reflective teaching improvement
  4. Norm-referenced thinking
Show answer and explanation

Answer: C. The correct use of evaluation data for reflective teaching improvement

Applied concept: Assessment → reflection → instructional adjustment = the evaluation-teaching feedback loop. This is the highest expression of teaching at the Reflective Level. Data-driven, learner-centred, improvement-oriented teaching.
