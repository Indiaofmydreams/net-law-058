About this question set

This set has 14 multiple-choice questions on Levels of Teaching from the UGC NET Paper 1 syllabus, unit 1, Teaching Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 14 of the 14 questions carry a written explanation.

For the concepts and case law behind these questions, read the Teaching Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

14 practice questions with answers

1The three levels of teaching — Memory, Understanding, and Reflective — were given by:

  1. H.C. Morrison
  2. John Dewey
  3. Ralph Tyler
  4. Bloom
Show answer and explanation

Answer: A. H.C. Morrison

Concept: Morrison's three levels is one of the most asked topics. Memory = lowest, Reflective = highest.

Report this question

2Which level of teaching is based on rote learning?

  1. Understanding level
  2. Memory level
  3. Reflective level
  4. Application level
Show answer and explanation

Answer: B. Memory level

Mnemonic: MUR (low to high) — M*emory → U*nderstanding → R*eflective. Mud goes up to River.

Report this question

3At which level of teaching does the student develop the ability to think critically and solve novel problems?

  1. Memory level
  2. Understanding level
  3. Reflective level
  4. Both A and B
Show answer and explanation

Answer: C. Reflective level

Concept: Reflective level = highest = critical thinking + creative problem solving. This is the TARGET of higher education.

Report this question

4The teaching strategy most appropriate for the Memory level is:

  1. Drill and practice / Lecture
  2. Seminar and discussion
  3. Project method
  4. Problem-solving
Show answer and explanation

Answer: A. Drill and practice / Lecture

Concept: Memory level needs repetition and recall. Problem-solving = Reflective. Discussion = Understanding.

Report this question

5At the Understanding level of teaching, learning is described as:

  1. Reproductive
  2. Reconstructive
  3. Creative
  4. Imitative
Show answer and explanation

Answer: B. Reconstructive

Concept: Memory = Reproductive (repeats). Understanding = Reconstructive (rebuilds meaning). Reflective = Creative (new ideas).

Report this question

6Which philosopher's ideas are most closely associated with the Reflective level of teaching?

  1. Skinner
  2. John Dewey
  3. Herbart
  4. Morrison
Show answer and explanation

Answer: B. John Dewey

Concept: Dewey's "reflective thinking" and problem-solving philosophy directly underpins the Reflective level.

Report this question

7The question "What is the boiling point of water?" tests students at which level of teaching?

  1. Application level
  2. Reflective level
  3. Understanding level
  4. Memory level
Show answer and explanation

Answer: D. Memory level

Concept: Factual recall question = Memory level. No reasoning, no application.

Report this question

8"Why does water boil at a lower temperature at high altitudes?" — this question tests which level?

  1. Memory level
  2. Understanding level
  3. Reflective level
  4. None of the above
Show answer and explanation

Answer: B. Understanding level

Concept: Understanding WHY requires conceptual grasp of air pressure and boiling points. Above recall but not fully reflective.

Report this question

9"Design an experiment to determine how altitude affects the boiling point of a liquid" — this represents:

  1. Understanding level
  2. Reflective level
  3. Memory level
  4. Rote level
Show answer and explanation

Answer: B. Reflective level

Concept: Design + novel experiment = creative problem-solving = Reflective level.

Report this question

10At the memory level of teaching, the role of the teacher is primarily that of a:

  1. Guide
  2. Facilitator
  3. Co-learner
  4. Information giver / Transmitter
Show answer and explanation

Answer: D. Information giver / Transmitter

Concept: Memory level = teacher-centred = teacher as transmitter. Reflective = teacher as facilitator.

Report this question

11The maximum cognitive engagement of learners is required at:

  1. Memory level
  2. Understanding level
  3. Reflective level
  4. All levels equally
Show answer and explanation

Answer: C. Reflective level

Concept: Reflective = highest cognitive demand. Requires synthesis, evaluation, creativity — all HOTS.

Report this question

12Morrison's Mastery Learning is associated with which level?

  1. Memory level only
  2. Reflective level only
  3. Understanding level primarily
  4. All three equally
Show answer and explanation

Answer: C. Understanding level primarily

Concept: Morrison's Mastery Model — Pre-test → Teach → Test → Reteach → Test again — was designed for conceptual understanding, not just recall.

Report this question

13Which of the following correctly arranges the levels of teaching from lowest to highest?

  1. Understanding → Memory → Reflective
  2. Memory → Understanding → Reflective
  3. Memory → Reflective → Understanding
  4. Reflective → Memory → Understanding
Show answer and explanation

Answer: B. Memory → Understanding → Reflective

Mnemonic: MUR → Think of "My Understanding Rises"

Report this question

14The concept of "insight learning" is most aligned with which level of teaching?

  1. Imitation level
  2. Understanding level
  3. Reflective level
  4. Memory level
Show answer and explanation

Answer: B. Understanding level

Concept: Insight = sudden grasp of a concept's structure (Gestalt psychology). Understanding level involves grasping relationships. Reflective goes further to applying insight in novel problems.
