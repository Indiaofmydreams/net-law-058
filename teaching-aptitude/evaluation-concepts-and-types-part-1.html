23 practice questions with answers

1The word "evaluation" in education is derived from the Latin word:

  1. "Evaluto" meaning to rank
  2. "Evalu" meaning to count
  3. "Valere" meaning worth or value
  4. "Valuation" meaning financial assessment
Show answer and explanation

Answer: C. "Valere" meaning worth or value

Concept: Evaluate = to find the value/worth of. Evaluation = judgement of worth based on evidence. Not just measurement — includes value judgement.

Report this question

2Who defined evaluation as "the process of determining to what extent educational objectives are being realised"?

  1. Ralph Tyler
  2. Lee Cronbach
  3. Michael Scriven
  4. Benjamin Bloom
Show answer and explanation

Answer: A. Ralph Tyler

Direct memory: Tyler's definition = most cited in UGC NET. Father of evaluation. Objective-centred view.

Report this question

3The correct sequence from narrowest to broadest concept is:

  1. Measurement → Testing → Evaluation → Assessment
  2. Assessment → Evaluation → Measurement → Testing
  3. Evaluation → Assessment → Measurement → Testing
  4. Testing → Measurement → Assessment → Evaluation
Show answer and explanation

Answer: D. Testing → Measurement → Assessment → Evaluation

Concept:
Testing = one specific instrument
Measurement = quantification using any instrument
Assessment = interpretation of measurement
Evaluation = value judgement based on all evidence
Mnemonic: "Tests Measure Academic Excellence" (T→M→A→E, narrow to broad)

Report this question

4"Measurement" in education is:

  1. Only done through standardised tests
  2. The same as evaluation
  3. Always qualitative
  4. The process of quantifying a characteristic — assigning numbers according to rules
Show answer and explanation

Answer: D. The process of quantifying a characteristic — assigning numbers according to rules

Concept: Measurement = quantification. Score = 75/100 = measurement. Whether that is "good" = evaluation. Measurement does not interpret — it only counts.

Report this question

5"Assessment" differs from "evaluation" in that:

  1. Assessment has no practical use
  2. Assessment gathers and interprets evidence of learning; evaluation adds a value judgement about worth or quality
  3. Assessment is done externally; evaluation is internal
  4. There is no difference
Show answer and explanation

Answer: B. Assessment gathers and interprets evidence of learning; evaluation adds a value judgement about worth or quality

Concept: Assessment = evidence collection + interpretation. Evaluation = assessment + judging worth (pass/fail, good/poor, accept/reject). Evaluation is the broader, final act.

Report this question

6Formative evaluation was defined as "evaluation in the service of curriculum development" by:

  1. Ralph Tyler
  2. Benjamin Bloom
  3. Michael Scriven
  4. Lee Cronbach
Show answer and explanation

Answer: C. Michael Scriven

Direct memory: Scriven (1967) coined both formative and summative evaluation. His context = curriculum evaluation. Bloom then applied it to classroom instruction.

Report this question

7Benjamin Bloom's contribution to formative evaluation was:

  1. Coining the term
  2. Replacing summative evaluation entirely
  3. Applying formative evaluation to classroom mastery learning — using it to diagnose and correct learning during instruction
  4. Introducing computer-based formative tests
Show answer and explanation

Answer: C. Applying formative evaluation to classroom mastery learning — using it to diagnose and correct learning during instruction

Concept: Bloom (1971) took Scriven's concept and operationalised it for classroom use in his Mastery Learning model. He showed how formative assessment drives corrective instruction.

Report this question

8A teacher gives a 5-minute "exit ticket" quiz at the end of each class to check student understanding. This is an example of:

  1. Formative evaluation
  2. Summative evaluation
  3. Diagnostic evaluation
  4. Placement evaluation
Show answer and explanation

Answer: A. Formative evaluation

Applied concept: Exit ticket = quick formative check. Immediate, ongoing, low-stakes. Teacher uses results to adjust next class. Classic formative tool.

Report this question

9Which of the following is an example of SUMMATIVE evaluation?

  1. Teacher's observation during class
  2. Assignment returned with feedback for improvement
  3. Weekly quiz
  4. Final board examination at end of year
Show answer and explanation

Answer: D. Final board examination at end of year

Applied concept: Final board exam = after instruction completes = summative. It certifies, does not improve ongoing instruction.

Report this question

10Diagnostic evaluation is DIFFERENT from formative evaluation in that:

  1. Diagnostic is only for gifted students
  2. Diagnostic is done after instruction; formative during
  3. Both are identical
  4. Diagnostic goes deeper — it identifies the specific causes and patterns of persistent learning failure, not just the fact of failure
Show answer and explanation

Answer: D. Diagnostic goes deeper — it identifies the specific causes and patterns of persistent learning failure, not just the fact of failure

Concept: Formative = is the student learning? Diagnostic = WHY is the student not learning? What specific misconception or gap? Diagnostic informs remedial teaching.

Report this question

11A student repeatedly makes the same type of arithmetic error in calculus problems. A diagnostic test would help to:

  1. Identify the specific arithmetic skill gap causing the persistent error and prescribe remediation
  2. Recommend the student drop the course
  3. Punish the student for carelessness
  4. Give the student a lower grade
Show answer and explanation

Answer: A. Identify the specific arithmetic skill gap causing the persistent error and prescribe remediation

Applied concept: Diagnostic = find specific error pattern + prescribe targeted remediation. Not punitive — corrective.

Report this question

12Placement evaluation is conducted at which point in the instructional process?

  1. At the end of the course
  2. Mid-way through the course
  3. After the final examination
  4. Before instruction begins
Show answer and explanation

Answer: D. Before instruction begins

Concept: Placement = entry point assessment. Determines learner's readiness, prior knowledge, appropriate level or group. Happens BEFORE teaching starts.

Report this question

13A university conducts an entrance examination to determine whether students should be placed in the regular programme or a remedial bridge course. This is:

  1. Formative evaluation
  2. Summative evaluation
  3. Placement evaluation
  4. Self-evaluation
Show answer and explanation

Answer: C. Placement evaluation

Applied concept: Entrance exam → determine appropriate placement = Placement evaluation. Not certifying (summative), not ongoing (formative), not cause-finding (diagnostic).

Report this question

14Norm-Referenced Testing (NRT) is designed to:

  1. Diagnose learning difficulties
  2. Spread students along a normal distribution and compare each student to the group
  3. Measure whether all students have reached a minimum standard
  4. Assess attitude and values
Show answer and explanation

Answer: B. Spread students along a normal distribution and compare each student to the group

Concept: NRT = competitive = bell curve = only a proportion can score high. Designed to DISCRIMINATE between students. Useful for selection.

Report this question

15Criterion-Referenced Testing (CRT) is designed to:

  1. Compare students across different institutions
  2. Rank students from highest to lowest
  3. Measure relative intelligence
  4. Determine whether each student has achieved a specific predetermined standard of performance
Show answer and explanation

Answer: D. Determine whether each student has achieved a specific predetermined standard of performance

Concept: CRT = mastery = has this student learned what they needed to? No ranking. Each student evaluated against the standard independently.

Report this question

16A driving licence test is an example of:

  1. Formative Test
  2. Norm-Referenced Test
  3. Criterion-Referenced Test
  4. Diagnostic Test
Show answer and explanation

Answer: C. Criterion-Referenced Test

Applied concept: You either meet the driving standard or you don't. It doesn't matter if 50% or 90% passed — the criterion (safe driving skills) determines pass/fail. Not competitive.

Report this question

17A competitive entrance examination like JEE Advanced that selects the top 1% is an example of:

  1. Formative Test
  2. Diagnostic Test
  3. Criterion-Referenced Test
  4. Norm-Referenced Test
Show answer and explanation

Answer: D. Norm-Referenced Test

Applied concept: JEE Advanced = must score better than others = relative performance = NRT. The cut-off is not absolute — it depends on how others perform.

Report this question

18The "washback effect" or "backwash effect" of evaluation refers to:

  1. The practice of washing examination scripts
  2. Reversal of examination results
  3. Negative effects of examination stress
  4. The influence of assessment design on teaching and learning — how the examination shapes what and how teachers teach and students learn
Show answer and explanation

Answer: D. The influence of assessment design on teaching and learning — how the examination shapes what and how teachers teach and students learn

Concept: If exam only tests recall → teachers teach for recall. If exam tests application → teaching shifts to application. Washback can be positive (good assessment drives good teaching) or negative (rote exam drives rote teaching).

Report this question

19"High-stakes testing" refers to:

  1. Tests with high table stakes in gambling
  2. Tests whose results have significant consequences — admission, graduation, employment, certification
  3. Tests conducted at high altitudes
  4. Tests with very high passing marks
Show answer and explanation

Answer: B. Tests whose results have significant consequences — admission, graduation, employment, certification

Concept: High-stakes = UGC NET, NEET, JEE, board exams. Results determine life outcomes. Low-stakes = class quiz. High-stakes creates pressure; good design is critical.

Report this question

20The evaluation philosophy of "Assessment FOR Learning" versus "Assessment OF Learning" distinguishes:

  1. Formative evaluation (FOR learning — improves ongoing learning) vs. Summative evaluation (OF learning — judges final achievement)
  2. Internal vs. external assessment
  3. Written vs. oral assessment
  4. Teacher assessment vs. student self-assessment
Show answer and explanation

Answer: A. Formative evaluation (FOR learning — improves ongoing learning) vs. Summative evaluation (OF learning — judges final achievement)

Concept: Dylan Wiliam's influential framework. FOR = formative = tool for improvement. OF = summative = tool for judgement. A third: Assessment AS Learning = self-assessment.

Report this question

21"Assessment AS Learning" is associated with:

  1. Summative certification
  2. Teacher-directed testing
  3. Peer grading only
  4. Student self-assessment and metacognition — student monitors and regulates own learning
Show answer and explanation

Answer: D. Student self-assessment and metacognition — student monitors and regulates own learning

Concept: Assessment AS Learning = the most advanced concept. Student uses assessment to understand their own thinking process. Highest form of learner-centred evaluation. Promotes metacognition.

Report this question

22Which type of evaluation is most associated with "grades and certification"?

  1. Formative
  2. Diagnostic
  3. Placement
  4. Summative
Show answer and explanation

Answer: D. Summative

Concept: Summative = sum total = final judgement = grades, degrees, certificates. Report card, degree certificate, NET result = all summative outcomes.

Report this question

23Portfolio assessment is superior to traditional examination in assessing:

  1. Speed of information recall
  2. Competitive ranking
  3. Factual knowledge breadth
  4. Growth over time, process of learning, creativity, and diverse competencies
Show answer and explanation

Answer: D. Growth over time, process of learning, creativity, and diverse competencies

Concept: Portfolio = shows journey, not just destination. Traditional exam = snapshot. Portfolio = video of growth. Best for arts, writing, research, and professional education.
