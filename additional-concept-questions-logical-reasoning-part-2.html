About this question set

This set has 25 multiple-choice questions on Additional Concept Questions: Logical Reasoning from the UGC NET Paper 1 syllabus, unit 6, Logical Reasoning. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.
