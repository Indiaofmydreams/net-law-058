About this question set

25 practice questions with answers

1Computer-Based Testing (CBT) is defined as:

  1. Testing of computer programming skills only
  2. Testing conducted using calculators
  3. Testing using television screens
  4. Administration of examinations through computers where questions are presented and responses recorded digitally
Show answer and explanation

Answer: D. Administration of examinations through computers where questions are presented and responses recorded digitally

Concept: CBT = digital examination. Paper-pencil replaced by computer screen + keyboard/mouse. UGC NET itself shifted to CBT mode via NTA from 2018.

Report this question

2UGC NET examination is currently conducted in CBT mode by:

  1. Individual universities
  2. CBSE
  3. NTA (National Testing Agency)
  4. UGC directly
Show answer and explanation

Answer: C. NTA (National Testing Agency)

Direct memory: NTA established in 2017. Conducts UGC NET, JEE, NEET, CUET in CBT mode. UGC NET shifted to NTA-CBT mode from December 2018.

Report this question

3Computer Adaptive Testing (CAT) differs from standard CBT in that:

  1. CAT adjusts question difficulty dynamically based on the examinee's previous responses
  2. CAT is conducted in a group; CBT is individual
  3. CAT tests only computer skills
  4. CAT uses paper; CBT uses computer
Show answer and explanation

Answer: A. CAT adjusts question difficulty dynamically based on the examinee's previous responses

Concept: CAT = intelligent testing. Answer correctly → next question harder. Answer wrongly → next question easier. Efficient — fewer questions needed for accurate ability estimation. GRE uses CAT.

Report this question

4The theoretical model underlying Computer Adaptive Testing is:

  1. Norm-Referenced Evaluation
  2. Item Response Theory (IRT)
  3. Bloom's Taxonomy
  4. Classical Test Theory (CTT)
Show answer and explanation

Answer: B. Item Response Theory (IRT)

Concept: IRT = statistical model describing relationship between person's ability and probability of answering item correctly. CAT uses IRT to select optimal next item from item bank.

Report this question

5An "Item Bank" in the context of CBT refers to:

  1. A bank of answer scripts
  2. A storage facility for question papers
  3. A large pool of pre-tested, calibrated examination questions stored digitally for test assembly
  4. A financial bank for examination fees
Show answer and explanation

Answer: C. A large pool of pre-tested, calibrated examination questions stored digitally for test assembly

Concept: Item bank = prerequisite for CBT and CAT. Questions pre-validated for difficulty, discrimination, and content coverage. CAT selects from item bank in real time.

Report this question

6Which of the following is an ADVANTAGE of CBT over traditional paper-pencil tests?

  1. It requires no electricity
  2. Instant results, randomised question sets, automated scoring, and reduced paper waste
  3. It tests handwriting and presentation skills
  4. It is cheaper to conduct in rural areas with no computers
Show answer and explanation

Answer: B. Instant results, randomised question sets, automated scoring, and reduced paper waste

Concept: CBT advantages: speed (instant scoring), integrity (randomisation prevents copying), efficiency (no paper, printing, manual checking), accessibility (can include multimedia).

Report this question

7Randomisation of questions in CBT helps in:

  1. Improving candidate performance
  2. Reducing the number of questions
  3. Preventing candidates sitting next to each other from copying answers
  4. Making the test harder
Show answer and explanation

Answer: C. Preventing candidates sitting next to each other from copying answers

Concept: Each candidate gets a different order of questions or different question set from the item bank = malpractice prevention. Critical advantage of CBT over paper exams.

Report this question

8"Proctored Online Examination" means:

  1. Examination taken with open internet access
  2. Online examination with live invigilation through webcam, AI monitoring, and screen recording
  3. Examination taken anywhere without supervision
  4. Examination in a physical hall with computer terminals
Show answer and explanation

Answer: B. Online examination with live invigilation through webcam, AI monitoring, and screen recording

Concept: Remote proctoring = AI + human invigilator monitors candidate via webcam. Detects eye movement, face recognition, background sounds. Became common post-COVID.

Report this question

9A major DISADVANTAGE of CBT in the Indian context is:

  1. Digital divide — candidates from rural areas or with limited computer literacy are disadvantaged
  2. CBT produces inaccurate results
  3. Questions are too easy on computers
  4. CBT cannot test multiple choice questions
Show answer and explanation

Answer: A. Digital divide — candidates from rural areas or with limited computer literacy are disadvantaged

Concept: CBT assumes computer literacy and access. Candidates unfamiliar with computers struggle with the interface regardless of content knowledge. Equity concern for India.

Report this question

10NTA provides a "mock test" facility before CBT examinations primarily to:

  1. Reduce the actual examination duration
  2. Reveal actual examination questions
  3. Test candidates' computer programming skills
  4. Familiarise candidates with the computer interface, navigation, and question format
Show answer and explanation

Answer: D. Familiarise candidates with the computer interface, navigation, and question format

Concept: Mock test = practice on the actual CBT interface. Reduces interface anxiety. Ensures candidates are not disadvantaged by unfamiliarity with the digital format.

Report this question

11In CBT, "on-screen calculator" and "virtual keyboard" are provided to ensure:

  1. Candidates use only digital tools, maintaining test integrity
  2. Physical tools are unnecessary and test is paperless
  3. All candidates are on equal footing regardless of physical stationery
  4. Only A and C
Show answer and explanation

Answer: D. Only A and C

Concept: On-screen tools = paperless + ensures all candidates use same standardised tool. Prevents advantages from better physical calculators.

Report this question

12Which of the following examination types is currently NOT typically conducted in full CBT mode in India?

  1. JEE Main
  2. CUET
  3. UGC NET
  4. NEET UG
Show answer and explanation

Answer: D. NEET UG

Concept: NEET UG remains paper-pencil (OMR-based) as of recent years, given concerns about digital infrastructure equity for medical aspirants across India. JEE, NET, CUET = CBT.

Report this question

13The term "psychometrics" in CBT refers to:

  1. Measuring brain activity during exams
  2. The scientific measurement of mental abilities, knowledge, and skills — including statistical analysis of test items
  3. Testing of psychological disorders
  4. Psychiatric evaluation
Show answer and explanation

Answer: B. The scientific measurement of mental abilities, knowledge, and skills — including statistical analysis of test items

Concept: Psychometrics = science of psychological measurement. CBT uses psychometric principles: item analysis, reliability, validity, IRT, norm-setting.

Report this question

14"Test reliability" in CBT means:

  1. The test accurately measures what it claims to measure
  2. The test produces consistent results when administered repeatedly under similar conditions
  3. The test is physically reliable — no technical glitches
  4. The test results are final and cannot be challenged
Show answer and explanation

Answer: B. The test produces consistent results when administered repeatedly under similar conditions

Concept: Reliability = consistency. Validity = accuracy. A reliable test gives same score on re-test. A valid test measures what it intends to. Both essential for CBT quality.

Report this question

15"Test validity" in CBT refers to:

  1. Whether the test server is working
  2. Whether candidates have valid ID proof
  3. Whether the test centre is valid
  4. Whether the test actually measures what it is designed to measure
Show answer and explanation

Answer: D. Whether the test actually measures what it is designed to measure

Concept: Content validity = does it cover the syllabus? Construct validity = does it measure the right ability? Criterion validity = does it predict relevant outcomes? All aspects of validity.

Report this question

16In a CBT examination, a candidate gets 68 questions right out of 100. The "raw score" is 68. After "normalisation," what is the purpose of the normalised score?

  1. To reduce every candidate's score
  2. To eliminate borderline candidates
  3. To adjust scores for difficulty variation across different shifts/sessions, ensuring fairness
  4. To convert percentage to grade points
Show answer and explanation

Answer: C. To adjust scores for difficulty variation across different shifts/sessions, ensuring fairness

Concept: Normalisation (equating) = because different test sessions may have different difficulty levels. Normalised score = statistically adjusted so a candidate in an easier session is not advantaged over one in a harder session.

Report this question

17NTA uses which normalisation method for multi-shift CBT examinations?

  1. Raw score averaging
  2. Simple averaging
  3. Percentile-based normalisation
  4. Grade conversion
Show answer and explanation

Answer: C. Percentile-based normalisation

Direct memory: NTA uses percentile scores for normalisation. Percentile = percentage of candidates who scored BELOW a given candidate. Used in JEE Main, CUET.

Report this question

18The difference between "Percentile" and "Percentage" in examination context is:

  1. Percentage = marks out of total. Percentile = rank relative to others — what % of candidates scored below you
  2. Percentage is used in CBT only
  3. Percentile measures knowledge; percentage measures attitude
  4. They are the same
Show answer and explanation

Answer: A. Percentage = marks out of total. Percentile = rank relative to others — what % of candidates scored below you

Applied concept: 90 percentile does NOT mean 90%. It means you scored better than 90% of candidates. Frequently confused in NET questions.

Report this question

19A candidate who scores at the 95th percentile in a CBT exam has:

  1. Scored better than 95% of all candidates who appeared
  2. Answered 95 questions correctly
  3. Secured rank 95
  4. Scored 95% marks
Show answer and explanation

Answer: A. Scored better than 95% of all candidates who appeared

Applied concept: Percentile = relative standing. 95th percentile = only 5% candidates scored above this person. Very high standing.

Report this question

20CUET (Common University Entrance Test) was introduced by UGC and is conducted by NTA in which mode?

  1. Computer-Based Test (CBT) mode
  2. Hybrid paper + oral
  3. Paper-pencil only
  4. Oral interview only
Show answer and explanation

Answer: A. Computer-Based Test (CBT) mode

Direct memory: CUET = CBT. Introduced from 2022 for UG admissions to central universities. Conducted by NTA. Replaced individual university entrance tests.

Report this question

21Which of the following correctly describes "negative marking" in CBT?

  1. Marks added for wrong answers
  2. Deduction of marks for incorrect answers to discourage random guessing
  3. Reduction of time for every wrong answer
  4. Automatic disqualification for wrong answers
Show answer and explanation

Answer: B. Deduction of marks for incorrect answers to discourage random guessing

Concept: UGC NET = no negative marking (important!). JEE = -1 for wrong MCQ. Purpose = reduce guessing effect on scores. CBT can implement negative marking automatically.

Report this question

22CBT allows "review and change" of answers during the examination. This feature:

  1. Encourages carelessness
  2. Is a major advantage — candidates can flag uncertain answers and revisit before submitting
  3. Is available only in paper tests
  4. Reduces examination time
Show answer and explanation

Answer: B. Is a major advantage — candidates can flag uncertain answers and revisit before submitting

Concept: CBT "mark for review" = candidate flags question → continues → returns before time ends. Paper tests = scribbling and erasing. CBT = clean, structured review process.

Report this question

23Artificial Intelligence (AI) in proctoring during CBT can detect:

  1. Eye movement, facial recognition, multiple faces in frame, suspicious audio, and screen switching
  2. Only the candidate's voice
  3. The candidate's emotional state only
  4. Only whether the candidate is present
Show answer and explanation

Answer: A. Eye movement, facial recognition, multiple faces in frame, suspicious audio, and screen switching

Concept: AI proctoring = comprehensive surveillance. Multiple people = impersonation flag. Screen switch = external help flag. Eye movement away from screen = possible reference material.

Report this question

24The concept of "item difficulty" in CBT refers to:

  1. The number of options in the question
  2. The proportion of examinees who answer the item correctly — lower proportion = higher difficulty
  3. How long a question is
  4. The font size of the question
Show answer and explanation

Answer: B. The proportion of examinees who answer the item correctly — lower proportion = higher difficulty

Concept: Item difficulty index (p) = number correct/total attempted. p=0.8 = easy (80% got it right). p=0.2 = hard. Item analysis is core to CBT item bank quality.

Report this question

25Which of the following is NOT a type of question that CBT can accommodate?

  1. Matching type questions
  2. Descriptive essay questions requiring human evaluation
  3. Multiple choice questions
  4. Numerical answer type (NAT) questions
Show answer and explanation

Answer: B. Descriptive essay questions requiring human evaluation

Concept: CBT excels at objective, auto-scorable formats. Long descriptive essays requiring nuanced human judgement = challenge for CBT (though AI essay scoring is emerging). Currently, descriptive = human scored.
