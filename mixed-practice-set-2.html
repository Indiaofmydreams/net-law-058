About this question set

This set has 15 multiple-choice questions on Teaching Aptitude from the UGC NET Paper 1 syllabus, unit 1, Teaching Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 15 of the 15 questions carry a written explanation.

For the concepts and case law behind these questions, read the Teaching Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

  • General concepts (15)

15 practice questions with answers

1Which method is teacher-centred?

  1. Project method
  2. Discovery method
  3. Group discussion
  4. Lecture method
Show answer and explanation

Answer: D. Lecture method

The teacher is the main source of information.

Report this question

2Micro-teaching is used to:

  1. Develop specific teaching skills in a simplified setting
  2. Test students
  3. Teach large classes
  4. Replace the syllabus
Show answer and explanation

Answer: A. Develop specific teaching skills in a simplified setting

It is a short, focused practice session.

Report this question

3Which is an ICT-based teaching support?

  1. Learning management system
  2. Printed chart
  3. Chalk
  4. Wall map
Show answer and explanation

Answer: A. Learning management system

LMS platforms deliver and track online learning.

Report this question

4Computer-based testing is an example of:

  1. Oral examination
  2. Technology-enabled evaluation
  3. Teacher-made charts
  4. Rote learning
Show answer and explanation

Answer: B. Technology-enabled evaluation

Assessment delivered through computers.

Report this question

5Adult learners (andragogy) are typically:

  1. Self-directed and experience-based
  2. Only memory-driven
  3. Fully dependent
  4. Disinterested
Show answer and explanation

Answer: A. Self-directed and experience-based

Knowles's assumptions about adult learning.

Report this question

6A teacher asks learners to solve a real-life problem in groups. This is:

  1. Lecture
  2. Dictation
  3. Problem-based cooperative learning
  4. Rote learning
Show answer and explanation

Answer: C. Problem-based cooperative learning

Learners collaborate on authentic problems.

Report this question

7A student repeatedly scores low in one topic. The teacher should first conduct:

  1. Diagnostic assessment
  2. Ranking
  3. Annual exam
  4. Summative test
Show answer and explanation

Answer: A. Diagnostic assessment

It locates the exact learning difficulty.

Report this question

8A teacher gives immediate feedback after each answer. This mainly supports:

  1. Boredom
  2. Punishment
  3. Cramming
  4. Reinforcement of learning
Show answer and explanation

Answer: D. Reinforcement of learning

Timely feedback strengthens correct learning.

Report this question

9Match: A Heuristic method, B Lecture, C Demonstration with (1) Learning by discovery (2) Teacher talks (3) Showing a procedure

  1. A-2, B-1, C-3
  2. A-1, B-3, C-2
  3. A-3, B-2, C-1
  4. A-1, B-2, C-3
Show answer and explanation

Answer: D. A-1, B-2, C-3

Methods and their features.

Report this question

10Match: A Pedagogy, B Andragogy, C Heutagogy with (1) Teaching children (2) Teaching adults (3) Self-determined learning

  1. A-1, B-2, C-3
  2. A-3, B-2, C-1
  3. A-2, B-1, C-3
  4. A-1, B-3, C-2
Show answer and explanation

Answer: A. A-1, B-2, C-3

Approaches by learner type.

Report this question

11Consider the statements: 1. Learning outcomes should be measurable. 2. Evaluation means testing only.

  1. Only statement 1 is correct
  2. Only statement 2 is correct
  3. Both statements are correct
  4. Neither statement is correct
Show answer and explanation

Answer: A. Only statement 1 is correct

Evaluation is broader than testing.

Report this question

12Consider the statements: 1. Individual differences must be considered in teaching. 2. All learners learn at the same pace.

  1. Only statement 1 is correct
  2. Only statement 2 is correct
  3. Both statements are correct
  4. Neither statement is correct
Show answer and explanation

Answer: A. Only statement 1 is correct

Learners differ in pace and style.
