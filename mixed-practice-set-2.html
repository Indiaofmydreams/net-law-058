About this question set

This set has 25 multiple-choice questions on ICT from the UGC NET Paper 1 syllabus, unit 8, Information and Communication Technology (ICT). Try each question first, then tap Show answer to check the key and read the explanation. 5 of the 25 questions carry a written explanation.

For the concepts and case law behind these questions, read the ICT notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

Topics in this set

  • Data, Information and Knowledge (6)
  • AISHE, NIRF and SAMARTH (7)
  • Common Service Centres (CSCs) and BharatNet (7)
