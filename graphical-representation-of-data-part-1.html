About this question set

This set has 14 multiple-choice questions on Graphical Representation of Data from the UGC NET Paper 1 syllabus, unit 7, Data Interpretation. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Data Interpretation notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

14 practice questions with answers

1A frequency polygon is obtained by joining:

  1. Upper class limits
  2. Mid-points of the tops of histogram bars
  3. Lower class limits
  4. Cumulative frequencies
Show answer

Answer: B. Mid-points of the tops of histogram bars

Report this question

2A histogram with unequal class widths should be plotted using:

  1. Cumulative frequency
  2. Mid-values only
  3. Class width only
  4. Frequency density
Show answer

Answer: D. Frequency density

Report this question

3Frequency density equals:

  1. Frequency × class width
  2. Frequency ÷ class width
  3. Class width ÷ frequency
  4. Cumulative frequency
Show answer

Answer: B. Frequency ÷ class width

Report this question

4Which statement is correct?

  1. A histogram always has gaps between bars
  2. Both suit only qualitative data
  3. A bar chart suits only continuous data
  4. A histogram suits continuous data while a bar chart suits categories
Show answer

Answer: D. A histogram suits continuous data while a bar chart suits categories

Report this question

5Assertion (A): The bars of a histogram touch each other. Reason (R): The class intervals of continuous data are contiguous.

  1. Both true and R explains A
  2. Both true but R does not explain A
  3. A true, R false
  4. A false, R true
Show answer

Answer: A. Both true and R explains A

Report this question

6In a bar chart, the bars:

  1. Always touch each other
  2. Show only time
  3. Are drawn as angles
  4. Are separated by gaps and usually show categories
Show answer

Answer: D. Are separated by gaps and usually show categories

Report this question

7A component (stacked) bar chart shows:

  1. Cumulative frequency
  2. Angles
  3. The breakup of a total into its components within each bar
  4. Correlation
Show answer

Answer: C. The breakup of a total into its components within each bar

Report this question

8A multiple bar chart is used to:

  1. Compare two or more related variables side by side
  2. Show one total only
  3. Show cumulative frequency
  4. Show angles
Show answer

Answer: A. Compare two or more related variables side by side

Report this question

9Starting the vertical axis of a bar chart at a value far above zero:

  1. Has no effect
  2. Removes data
  3. Improves accuracy
  4. Exaggerates the differences between bars
Show answer

Answer: D. Exaggerates the differences between bars

Report this question

10In a bar chart, the value is read from the:

  1. Width of the bar
  2. Height or length of the bar
  3. Colour of the bar
  4. Gap between bars
Show answer

Answer: B. Height or length of the bar

Report this question

11A simple bar chart is a:

  1. Two-dimensional diagram
  2. Three-dimensional diagram
  3. One-dimensional diagram
  4. Cartogram
Show answer

Answer: C. One-dimensional diagram

Report this question

12A pie chart shows:

  1. Trend over time
  2. Correlation
  3. Cumulative frequency
  4. Parts as proportions of a whole
Show answer

Answer: D. Parts as proportions of a whole

Report this question

13The total angle at the centre of a pie chart is:

  1. 360°
  2. 180°
  3. 270°
  4. 90°
Show answer

Answer: A. 360°

Report this question

14A line chart is best suited to show:

  1. Shares of a whole
  2. Nominal categories only
  3. Trends over time
  4. Class intervals
Show answer

Answer: C. Trends over time
