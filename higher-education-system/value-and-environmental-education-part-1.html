About this question set

This set has 16 multiple-choice questions on Value and Environmental Education from the UGC NET Paper 1 syllabus, unit 10, Higher Education System. Try each question first, then tap Show answer to check the key. This set is an answer-key drill: check each answer, then revisit the notes for any you miss.

For the concepts and case law behind these questions, read the Higher Education System notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

  1. Rio, 1992
  2. Stockholm, 1972
  3. Paris, 2015
  4. Kyoto, 1997
