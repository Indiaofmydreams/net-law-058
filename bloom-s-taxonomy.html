About this question set

This set has 20 multiple-choice questions on Bloom's Taxonomy from the UGC NET Paper 1 syllabus, unit 1, Teaching Aptitude. Try each question first, then tap Show answer to check the key and read the explanation. 20 of the 20 questions carry a written explanation.

For the concepts and case law behind these questions, read the Teaching Aptitude notes. Once you are comfortable, test yourself under exam conditions with a full-length mock test.

20 practice questions with answers

1What is the highest level of Bloom's original (1956) Taxonomy of Educational Objectives?

  1. Evaluation
  2. Synthesis
  3. Analysis
  4. Application
Show answer and explanation

Answer: A. Evaluation

Mnemonic for original Bloom (low to high): K-C-A-A-S-E → "Kids Can Always Achieve Something Extraordinary"
Knowledge → Comprehension → Application → Analysis → Synthesis → Evaluation

Report this question

2In Anderson and Krathwohl's revised Bloom's Taxonomy (2001), what is the highest cognitive level?

  1. Create
  2. Analyse
  3. Evaluate
  4. Synthesise
Show answer and explanation

Answer: A. Create

Mnemonic for revised Bloom (low to high): R-U-A-A-E-C → "Really Understanding Always Allows Excellent Creations"
Remember → Understand → Apply → Analyse → Evaluate → Create

Report this question

3In Bloom's revised taxonomy, "Synthesis" of the original taxonomy was replaced by:

  1. Analyse
  2. Evaluate
  3. Create
  4. Apply
Show answer and explanation

Answer: C. Create

Concept: The key change in 2001 revision — Synthesis became Create AND moved to the top. Evaluation moved one level down.

Report this question

4Which level of Bloom's revised taxonomy does the following task represent: "Design a new experiment to test the hypothesis"?

  1. Evaluate
  2. Create
  3. Apply
  4. Analyse
Show answer and explanation

Answer: B. Create

Concept: Design, formulate, construct, compose = Create level. Any new product = Create.

Report this question

5"Justify your answer with evidence" — this task corresponds to which level of revised Bloom's?

  1. Create
  2. Remember
  3. Evaluate
  4. Apply
Show answer and explanation

Answer: C. Evaluate

Concept: Justify, judge, critique, defend, assess = Evaluate. Evaluation = making judgements with evidence.

Report this question

6Which of the following represents the LOWEST level in Bloom's revised taxonomy?

  1. Remember
  2. Analyse
  3. Understand
  4. Apply
Show answer and explanation

Answer: A. Remember

Concept: Remember = recall, identify, list, define. It is the floor of cognitive functioning.

Report this question

7The term HOTS stands for:

  1. Horizontal Objective Training Steps
  2. Humanistic Oriented Teaching Systems
  3. Higher Order Thinking Skills
  4. High Order Training Standards
Show answer and explanation

Answer: C. Higher Order Thinking Skills

Concept: HOTS = Analyse + Evaluate + Create in revised Bloom's. LOTS = Remember + Understand + Apply.

Report this question

8Which of the following action verbs belongs to the "Apply" level of Bloom's revised taxonomy?

  1. Solve
  2. Judge
  3. Explain
  4. List
Show answer and explanation

Answer: A. Solve

Concept: Apply verbs: Solve, demonstrate, use, compute, execute. "List" = Remember. "Explain" = Understand. "Judge" = Evaluate.

Report this question

9The Affective domain in Bloom's taxonomy was developed by:

  1. Simpson
  2. Bloom himself
  3. Krathwohl
  4. Dave
Show answer and explanation

Answer: C. Krathwohl

Concept: Krathwohl developed affective domain in 1964. Dave/Simpson = psychomotor. Bloom = cognitive (1956).

Report this question

10What is the highest level of the Affective domain?

  1. Valuing
  2. Characterisation by value
  3. Responding
  4. Organisation
Show answer and explanation

Answer: B. Characterisation by value

Mnemonic (Affective, low to high): R-R-V-O-C → "Really Responsible Values Organise Character"
Receiving → Responding → Valuing → Organisation → Characterisation

Report this question

11The Affective domain deals with:

  1. Attitudes, values, emotions
  2. Memory and recall
  3. Cognitive abilities
  4. Motor skills
Show answer and explanation

Answer: A. Attitudes, values, emotions

Concept: Affective = feelings, dispositions, appreciation. It is the domain most neglected in traditional teaching.

Report this question

12The Psychomotor domain was classified by Dave. The highest level in Dave's classification is:

  1. Articulation
  2. Manipulation
  3. Precision
  4. Naturalisation
Show answer and explanation

Answer: D. Naturalisation

Mnemonic (Psychomotor, Dave): I-M-P-A-N → "I Must Perfect All Neurons"
Imitation → Manipulation → Precision → Articulation → Naturalisation

Report this question

13"The student will be able to recall the definition of photosynthesis" — this objective belongs to which domain and level?

  1. Psychomotor — Imitation
  2. Cognitive — Remember
  3. Cognitive — Evaluate
  4. Affective — Receiving
Show answer and explanation

Answer: B. Cognitive — Remember

Concept: Recall = Remember (lowest cognitive). This is a classic example used in PYQs.

Report this question

14Writing specific, measurable learning objectives is based on which concept?

  1. Bloom's Taxonomy
  2. Dale's Cone of Experience
  3. Dewey's Experimentalism
  4. Gestalt Theory
Show answer and explanation

Answer: A. Bloom's Taxonomy

Concept: Bloom's taxonomy provides the framework for writing behavioural/learning objectives — each domain and level has specific action verbs.

Report this question

15In the original Bloom's Taxonomy, "Comprehension" corresponds to which level in the revised taxonomy?

  1. Apply
  2. Remember
  3. Understand
  4. Analyse
Show answer and explanation

Answer: C. Understand

Concept: Comprehension (original) = Understand (revised). This mapping question has appeared in PYQs.

Report this question

16Which of the following is a Higher Order Thinking task?

  1. Critique the methodology of a research paper
  2. Identify the capital of India
  3. Define the term "osmosis"
  4. List the steps of photosynthesis
Show answer and explanation

Answer: A. Critique the methodology of a research paper

Concept: Critique = Evaluate level = HOTS. Define/List/Identify = Remember = LOTS.

Report this question

17Bloom's Taxonomy revision was done in 2001. The major changes were:
- Nouns replaced by verbs
- Synthesis renamed Create and placed at top
- Evaluation moved below Create
Which of the above is/are correct?

  1. 1 only
  2. 1 and 2 only
  3. 2 and 3 only
  4. 1, 2, and 3
Show answer and explanation

Answer: D. 1, 2, and 3

Concept: All three changes are correct. Nouns (Knowledge, Comprehension) → Verbs (Remember, Understand). This is a PYQ-style assertion question.

Report this question

18A teacher asks students: "Compare and contrast the French Revolution and the Russian Revolution." This question primarily tests:

  1. Analyse
  2. Remember
  3. Understand
  4. Create
Show answer and explanation

Answer: A. Analyse

Concept: Compare and contrast = break down and find relationships = Analyse. Classic exam trap — students think "compare" = understand, but it's analyse.

Report this question

19Which domain is most neglected in Indian higher education according to educational researchers?

  1. Cognitive
  2. Psychomotor
  3. Affective
  4. All are equally addressed
Show answer and explanation

Answer: C. Affective

Concept: Most teaching and exams focus on cognitive. Affective domain (values, attitudes) is systematically ignored. This view is widely cited in NET study materials.

Report this question

20"The student assembles the equipment smoothly without referring to instructions." This represents which level of the psychomotor domain?

  1. Precision
  2. Imitation
  3. Naturalisation
  4. Articulation
Show answer and explanation

Answer: C. Naturalisation

Concept: Smooth, automatic, without instructions = fully internalised = Naturalisation (highest). If they needed to check = lower level.
